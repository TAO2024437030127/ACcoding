## 题目简述

大家都知道，斐波那契数列是满足如下性质的一个数列：

$$F_n = \left\{\begin{aligned} 1 \space (n \le 2) \\ F_{n-1}+F_{n-2} \space (n\ge 3) \end{aligned}\right.$$

请你求出 $F_n \bmod 10^9 + 7$ 的值。

输入格式
一行一个正整数 $n$。

输出格式
输出一行一个整数表示答案。

说明/提示
【数据范围】
对于 $60\%$ 的数据，$1\le n \le 92$；
对于 $100\%$ 的数据，$1\le n < 2^{63}$。

## 解题思路

关键观察：斐波那契递推是线性的，可以用矩阵快速幂在 O(log n) 时间内求出第 n 项。

1. 构造转移矩阵 M = [[0,1],[1,1]]，满足 [F_k, F_{k+1}]^T = M · [F_{k-1}, F_k]^T。
2. 因此 [F_n, F_{n+1}]^T = M^{n-1} · [F_1, F_2]^T = M^{n-1} · [1,1]^T。
3. 由于 M^{n-1} 的第二行第二列恰好等于 F_n（可验证 n=1 时 M^0 为单位阵，ans[1][1]=1=F_1），所以只需计算 M^{n-1} 并输出 ans[1][1]。
4. 快速幂中用单位阵作为累乘初值，按二进制位对矩阵做平方与乘法；乘法时用 __int128 防止两个模数相乘溢出 long long。
5. 正确性由矩阵乘法的结合律与归纳法保证：每次乘 M 相当于推进一项，二进制拆分保证恰好推进 n-1 次。

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
typedef long long ll;
const int Mod=1e9+7;
using mat=vector<vector<ll>>;
mat mal(mat &a,mat &b){
    int n=a.size();
    mat c(n,vector<ll>(n,0));
    for(int i=0;i<n;i++){
        for(int k=0;k<n;k++){
            if(a[i][k]){
                for(int j=0;j<n;j++){
                    c[i][j]=(c[i][j]+(__int128)a[i][k]*b[k][j])%Mod;
                }
            }
        }
    }
    return c;
    
}

mat qpow(mat a,ll p){
    int n=a.size();
    mat res(n,vector<ll>(n,0));
    for(int i=0;i<n;i++){
        res[i][i]=1;
    }
    while(p){
        if(p&1){
            res=mal(a,res);
        }
        a=mal(a,a);
        p>>=1;
    }
    return res;
}

int main(){
    mat m={{0,1},{1,1}};
    ll n;
    cin>>n;
    if(n==0)
    {
      cout<<0;return 0;
  
    }
    mat ans=qpow(m,n-1);
    cout<<ans[1][1];
    return 0;
}
```

## 复盘备注

易错点：
- 矩阵乘法中 a[i][k]*b[k][j] 可能达到约 10^18，直接乘再取模在 long long 下虽接近上限但用 __int128 更稳妥。
- 快速幂中 res=mal(a,res) 的顺序：矩阵乘法不交换，但此处 res 与 a 均为 M 的幂，可交换，故结果正确；若换一般矩阵需注意顺序。
- n=1 时 n-1=0，快速幂返回单位阵，ans[1][1]=1，正确；代码额外处理 n=0 属于防御性写法。
- 输入 n 用 long long 读入，因为 n < 2^63。

可优化点：2×2 矩阵可展开为 4 个变量手写乘法，减少 vector 开销。
