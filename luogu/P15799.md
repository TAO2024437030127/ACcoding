## 题目简述

对应的选择、判断题：<https://ti.luogu.com.cn/problemset/1209>

给定一个包含 $n$ 个互不相同的正整数的数组 $A$ 与一个包含 $m$ 个互不相同的正整数的数组 $B$，请你帮忙计算有多少个数在数组 $A$ 与数组 $B$ 中均出现。

输入格式
第一行包含两个整数 $n,m$。

第二行包含 $n$ 个正整数 $a_1,a_2,\cdots,a_n$ 表示数组 $A$。

第三行包含 $m$ 个正整数 $b_1,b_2,\cdots,b_m$ 表示数组 $B$。

输出格式
输出一个整数，表示在数组 $A$ 与数组 $B$ 中均出现的数的个数。

说明/提示
### 样例解释

样例 1 中，$4$、$3$ 在数组 $A$ 与 $B$ 中均出现。

### 数据范围

对于 $40\%$ 的数据，保证 $1 \leq n,m \leq 1000$。

对于 $100\%$ 的数据，保证 $1 \leq n,m \leq 10^5$，$1 \leq a_i,b_i \leq 10^9$。

## 样例

### 样例 1

输入：
```text
3 5
4 2 3
3 1 5 4 6
```

输出：
```text
2
```

## 解题思路

1. 由于数组内元素互不相同，问题本质是求两个集合的交集大小。
2. 将数组 A 的所有元素插入哈希集合（unordered_set），利用 O(1) 平均查找判断元素是否属于 A。
3. 依次读入数组 B 的每个元素，若在哈希集合中则计数加一。
4. 正确性：集合中保存的恰为 A 的全部元素，对 B 中每个元素判断是否在集合中，等价于判断是否同时出现在 A 和 B 中；又因 B 内元素互不相同，每个公共元素只被统计一次，故计数即为交集大小。
5. 实现要点：使用 ios::sync_with_stdio(false) 与 cin.tie(nullptr) 加速输入；s.reserve(n) 预分配桶空间，减少哈希表扩容开销。

## 复杂度分析

- 时间复杂度：O(n + m)（哈希集合插入与查询平均 O(1)）
- 空间复杂度：O(n)（存储数组 A 的哈希集合）

## 代码

```text
#include <iostream>
#include <unordered_set>
#include <vector>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr); // 关闭同步加速输入，解决大数据输入超时

    int n, m;
    cin >> n >> m;

    unordered_set<int> s;
    s.reserve(n); // 预分配空间，减少哈希表扩容开销

    // 读取数组A，存入哈希表
    for (int i = 0; i < n; ++i) {
        int a;
        cin >> a;
        s.insert(a);
    }

    int count = 0;
    // 读取数组B，统计交集
    for (int i = 0; i < m; ++i) {
        int b;
        cin >> b;
        if (s.count(b)) {
            ++count;
        }
    }

    cout << count << endl;
    return 0;
}
```

## 复盘备注

易错点：
- 若用两层循环暴力比较，复杂度 O(nm)，在 n,m 达 1e5 时会超时。
- 若用数组下标标记，因 a_i,b_i 可达 1e9，无法直接开数组，需用哈希表或离散化。
- 题目保证数组内元素互不相同，因此无需去重；若元素可重复，则需改用 set 或额外处理重复计数。
可优化点：也可对 A 排序后二分查找 B 中元素，复杂度 O(n log n + m log n)，但哈希法更优。
