## 题目简述

如题，给定 $N$ 个字符串（第 $i$ 个字符串长度为 $M_i$，字符串内包含数字、大小写字母，大小写敏感），请求出 $N$ 个字符串中共有多少个不同的字符串。

**友情提醒：如果真的想好好练习哈希的话，请自觉。**

输入格式
第一行包含一个整数 $N$，为字符串的个数。

接下来 $N$ 行每行包含一个字符串，为所提供的字符串。

输出格式
输出包含一行，包含一个整数，为不同的字符串个数。

说明/提示
### 数据范围

对于 $30\%$ 的数据：$N\leq 10$，$M_i≈6$，$M_{\max}\leq 15$。

对于 $70\%$ 的数据：$N\leq 1000$，$M_i≈100$，$M_{\max}\leq 150$。

对于 $100\%$ 的数据：$N\leq 10000$，$M_i≈1000$，$M_{\max}\leq 1500$。

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
typedef unsigned long long ull;
const ull base=131;//自然溢出准备
ull get_hash(const string &s){
    ull res=0;
    for(char c:s){
        res=res*base+c;
    }
    return res;
}

int main(){
    int n;
    cin>>n;
    unordered_set<ull> st;
    string s;
    for(int i=1;i<=n;i++){
        cin>>s;
        st.insert(get_hash(s));
    }
    cout<<st.size()<<endl;
    return 0;
}
```
