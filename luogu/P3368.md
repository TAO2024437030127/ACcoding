## 题目简述

如题，已知一个数列，你需要进行下面两种操作：

1. 将某区间每一个数加上 $x$；

2. 求出某一个数的值。

输入格式
第一行包含两个整数 $N$、$M$，分别表示该数列数字的个数和操作的总个数。

第二行包含 $N$ 个用空格分隔的整数，其中第 $i$ 个数字表示数列第 $i $ 项的初始值。

接下来 $M$ 行每行包含 $2$ 或 $4$ 个整数，表示一个操作，具体如下：

操作 $1$： 格式：`1 x y k` 含义：将区间 $[x,y]$ 内每个数加上 $k$；

操作 $2$： 格式：`2 x` 含义：输出第 $x$ 个数的值。

输出格式
输出包含若干行整数，即为所有操作 $2$ 的结果。

## 解题思路

本题是树状数组 2 的模板题，但给出的 AC 代码使用了**线段树 + 懒标记**实现，同样正确。

- **关键观察**：操作是区间加、单点查，属于典型的“区间修改、单点查询”问题。线段树通过懒标记把区间加操作延迟到需要访问子区间时再下传，从而保证效率。
- **建树**：`build` 递归建立线段树，叶子结点存初始值 `a[l]`，内部结点 `sum` 为左右子结点之和，`lazy` 初始化为 0。
- **区间加**：`update` 在完全覆盖当前结点区间时，直接给 `sum[rt]` 加上 `v*(r-l+1)`，并累加 `lazy[rt]`；否则先 `push_down` 下传懒标记，再递归处理与查询区间相交的子结点，最后 `push_up` 更新当前结点和。
- **单点查询**：`query` 从根递归到目标叶子，路径上遇到懒标记就下传，保证叶子结点的 `sum` 已包含所有祖先的区间加贡献，到达叶子时直接返回 `sum[p]`。
- **正确性要点**：懒标记保证每个区间加的增量最终都会作用到其覆盖的所有叶子；查询路径上的 `push_down` 确保目标位置的值被正确累加。
- **注意**：虽然题目是树状数组模板，但线段树解法完全等价且可通过；数据范围要求使用 `long long` 存储和与懒标记。

## 复杂度分析

- 时间复杂度：建树 O(N)，每次区间加 O(log N)，每次单点查询 O(log N)，总 O(N + M log N)
- 空间复杂度：O(N)

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
typedef long long ll;
const int MAXN=5e5+10;
ll a[MAXN];
ll sum[MAXN<<2];
ll lazy[MAXN<<2];
int n,m;
void push_up(int rt){
    sum[rt]=sum[rt<<1]+sum[rt<<1|1];
}

void push_down(int rt,int l,int r){
    if(lazy[rt]){
        int mid=(l+r)>>1;
        sum[rt<<1]+=lazy[rt]*(mid-l+1);
        sum[rt<<1|1]+=lazy[rt]*(r-mid);
        lazy[rt<<1]+=lazy[rt];
        lazy[rt<<1|1]+=lazy[rt];
        lazy[rt]=0;
        
    }
}

void build(int rt,int l,int r){
    lazy[rt]=0;
    if(l==r){
        sum[rt]=a[l];
        return ;
    }
    int mid=(l+r)>>1;
    build(rt<<1,l,mid);
    build(rt<<1|1,mid+1,r);
    push_up(rt);
}

void update(int rt,int l,int r,int ql,int qr,ll v){
    if(ql<=l&&r<=qr){
        sum[rt]+=v*(r-l+1);
        lazy[rt]+=v;
        return ;
    }
    push_down(rt,l,r);
    int mid=(l+r)>>1;
    if(ql<=mid) update(rt<<1,l,mid,ql,qr,v);
    if(qr>mid) update(rt<<1|1,mid+1,r,ql,qr,v);
    push_up(rt);
}

// 单点查询 pos
ll query(int p, int l, int r, int pos){
    if(l == r){
        return sum[p];
    }
    push_down(p,l,r);
    int mid = (l+r)/2;
    if(pos <= mid) return query(p<<1,l,mid,pos);
    else return query(p<<1|1,mid+1,r,pos);
}

int main(){ cin >> n >> m;
    for(int i=1;i<=n;i++) cin >> a[i];
    build(1,1,n);
    while(m--){
        int op; cin >> op;
        if(op == 1){
            int x,y; ll k;
            cin >> x >> y >> k;
            update(1,1,n,x,y,k);
        }else{
            int x; cin >> x;
            cout << query(1,1,n,x) << '\n';
        }
    }
    return 0;}
```

## 复盘备注

易错点：
- `sum` 和 `lazy` 必须用 `long long`，因为元素绝对值可达 2^30，多次累加可能超出 `int`。
- `push_down` 中更新子结点 `sum` 时要乘区间长度，`lazy` 直接累加。
- 查询是单点查询，不需要合并左右子结点，直接沿路径下传即可。

可优化点：本题也可用树状数组维护差分数组实现，代码更短、常数更小：区间加转化为差分数组上的两次单点加，单点查询转化为差分数组前缀和。

同类题提示：P3374（树状数组 1：单点加、区间求和）、P3372（线段树 1：区间加、区间求和）。
