## 题目简述

很久以前，在一个遥远的星系，一个黑暗的帝国靠着它的超级武器统治着整个星系。

某一天，凭着一个偶然的机遇，一支反抗军摧毁了帝国的超级武器，并攻下了星系中几乎所有的星球。这些星球通过特殊的以太隧道互相直接或间接地连接。

但好景不长，很快帝国又重新造出了他的超级武器。凭借这超级武器的力量，帝国开始有计划地摧毁反抗军占领的星球。由于星球的不断被摧毁，两个星球之间的通讯通道也开始不可靠起来。

现在，反抗军首领交给你一个任务：给出原来两个星球之间的以太隧道连通情况以及帝国打击的星球顺序，以尽量快的速度求出每一次打击之后反抗军占据的星球的连通块的个数。（如果两个星球可以通过现存的以太通道直接或间接地连通，则这两个星球在同一个连通块中）。

输入格式
输入文件第一行包含两个整数 $n,m$，分别表示星球的数目和以太隧道的数目。星球用 $0 \sim n-1$ 的整数编号。

接下来的 $m$ 行，每行包括两个整数 $x,y$，表示星球 $x$ 和星球 $y$ 之间有“以太”隧道，可以直接通讯。

接下来的一行为一个整数 $k$，表示将遭受攻击的星球的数目。

接下来的 $k$ 行，每行有一个整数，按照顺序列出了帝国军的攻击目标。这 $k$ 个数互不相同，且都在 $0$ 到 $n-1$ 的范围内。

输出格式
第一行是开始时星球的连通块个数。接下来的 $k$ 行，每行一个整数，表示经过该次打击后现存星球的连通块个数。

说明/提示
**【数据范围】**

对于 $100\%$ 的数据，$1\le m \le 2\times 10^5$，$1\le n \le 2m$，$x \neq y$。

## 解题思路

正向删除点并维护连通块数量需要支持删边，较难处理；采用离线逆序加点的经典技巧。

1. 先读入所有边和所有被摧毁的星球，用 ban 数组标记最终状态中不存在的点。
2. 在最终状态（所有 k 个点都被摧毁后）上，只对未被 ban 的点用并查集合并边，统计连通块数 cnt。
3. 将摧毁序列倒序处理：每次“恢复”一个星球 u，先令 cnt 加一（u 单独成为一个新连通块），然后遍历 u 的所有邻居 v，若 v 当前存在（未被 ban），则合并 u 与 v，每成功合并一次 cnt 减一。
4. 把每次恢复后的 cnt 依次记录，最后连同初始状态的 cnt 一起倒序输出，即得到正向每次打击后的答案。

正确性要点：逆序过程等价于从最终状态逐步加回被删的点，并查集合并保证连通块计数正确；每次加点先加一，再通过合并邻居修正，恰好维护当前图的连通块数。

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
typedef long long ll;
const int N=400000;
vector<int> g[N];
int dest[N];
int fa[N];
bool ban[N];
int n,m,k;
int cnt;
int find(int x){
    if(fa[x]!=x) {
        fa[x]=find(fa[x]);
    }
    return fa[x];
}

void unite(int x,int y){
    x=find(x);
    y=find(y);
    if(x!=y){
        fa[y]=x;
        cnt--;
    }
}

int main(){
    cin>>n>>m;
    for(int i=0;i<=n;i++){
        fa[i]=i;
    }
    for(int i=1;i<=m;i++){
        int x,y;
        cin>>x>>y;
        g[x].push_back(y);
        g[y].push_back(x);
    }
    cin>>k;
    for(int i=1;i<=k;i++){
        cin>>dest[i];
        ban[dest[i]]=true;
    }
    cnt==0;
    for(int i=0;i<n;i++){
        if(!ban[i]){
            cnt++;
        }
    }
    for(int u=0;u<n;u++){
        if(ban[u]) continue;
        for(int v:g[u]){
            if(!ban[v]){
                unite(u,v);
            }
        }
    }
    vector<int> res;
    res.push_back(cnt);
    for(int i=k;i>=1;i--){
        int u=dest[i];
        ban[u]=false;
        cnt++;
        for(int v:g[u]){
            if(!ban[v]){
                unite(u,v);
            }
        }
        res.push_back(cnt);
    }
    
    for(int i=k;i>=0;i--){
        cout<<res[i]<<endl;
    }
    return 0;
    
}
```

## 复盘备注

易错点：
- 初始化 cnt 时只统计未被 ban 的点，不要漏掉孤立点。
- 恢复点 u 时先 cnt++，再合并邻居，顺序不能反。
- 输出时 res 中存储的是逆序过程的答案，需要从 k 到 0 倒序输出。
- 并查集路径压缩要写对，find 中先递归压缩再返回根。

同类题提示：离线逆序处理删除操作是常见套路，如“删边/删点后询问连通性”类问题可考虑反向加边/加点。
