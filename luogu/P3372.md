## 题目简述

如题，已知一个数列 $\{a_i\}$，你需要进行下面两种操作：

1. 将某区间每一个数加上 $k$。
2. 求出某区间每一个数的和。

输入格式
第一行包含两个整数 $n, m$，分别表示该数列数字的个数和操作的总个数。

第二行包含 $n$ 个用空格分隔的整数 $a_i$，其中第 $i$ 个数字表示数列第 $i$ 项的初始值。

接下来 $m$ 行每行包含 $3$ 或 $4$ 个整数，表示一个操作，具体如下：

1. `1 x y k`：将区间 $[x, y]$ 内每个数加上 $k$。
2. `2 x y`：输出区间 $[x, y]$ 内每个数的和。

输出格式
输出包含若干行整数，即为所有操作 2 的结果。

说明/提示
对于 $15\%$ 的数据：$n \le 8$，$m \le 10$。
对于 $35\%$ 的数据：$n \le {10}^3$，$m \le {10}^4$。
对于 $100\%$ 的数据：$1 \le n, m \le {10}^5$，$a_i,k$ 为正数，且任意时刻数列的和不超过 $2\times 10^{18}$。

## 解题思路

本题是线段树区间修改与区间查询的模板题，采用带懒标记的线段树。

- 每个结点维护两个值：`sum[rt]` 表示该结点对应区间的元素和，`lazy[rt]` 表示尚未下传给子结点的区间加法标记。
- `build` 递归建树，叶子结点取原数组值，非叶子结点由左右子结点求和得到。
- `push_down` 在访问子结点前调用：若当前结点有懒标记，则把标记值乘以左右子区间长度分别累加到子结点的 `sum`，同时把标记累加到子结点的 `lazy`，最后清空当前标记。
- `update` 若当前区间完全被修改区间覆盖，直接更新 `sum` 并累加 `lazy`；否则先下传标记，再递归处理与修改区间相交的子结点，最后 `push_up` 更新当前和。
- `query` 若当前区间完全被查询区间覆盖，直接返回 `sum`；否则先下传标记，再递归累加相交子区间的查询结果。
- 正确性要点：懒标记表示“该区间整体加了多少但尚未传给子结点”，下传时按子区间长度分配增量，保证每个结点的 `sum` 始终等于其区间真实和；查询和修改前都先下传，保证子结点信息正确。

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
typedef long long ll;
const int MAXN=5e5+10;
ll a[MAXN];
ll sum[MAXN<<2];
ll lazy[MAXN<<2];
int n,m;
void push_up(int rt){
    sum[rt]=sum[rt<<1]+sum[rt<<1|1];
}

void push_down(int rt,int l,int r){
    if(lazy[rt]){
        int mid=(l+r)>>1;
        sum[rt<<1]+=lazy[rt]*(mid-l+1);
        sum[rt<<1|1]+=lazy[rt]*(r-mid);
        lazy[rt<<1]+=lazy[rt];
        lazy[rt<<1|1]+=lazy[rt];
        lazy[rt]=0;
        
    }
}

void build(int rt,int l,int r){
    lazy[rt]=0;
    if(l==r){
        sum[rt]=a[l];
        return ;
    }
    int mid=(l+r)>>1;
    build(rt<<1,l,mid);
    build(rt<<1|1,mid+1,r);
    push_up(rt);
}

void update(int rt,int l,int r,int ql,int qr,ll v){
    if(ql<=l&&r<=qr){
        sum[rt]+=v*(r-l+1);
        lazy[rt]+=v;
        return ;
    }
    push_down(rt,l,r);
    int mid=(l+r)>>1;
    if(ql<=mid) update(rt<<1,l,mid,ql,qr,v);
    if(qr>mid) update(rt<<1|1,mid+1,r,ql,qr,v);
    push_up(rt);
}

ll query(int rt,int l,int r,int ql,int qr){
    if(ql<=l&&r<=qr){
        return sum[rt];
        
    }
    push_down(rt,l,r);
    int mid=(l+r)>>1;
    ll res=0;
    if(ql<=mid){
        res+=query(rt<<1,l,mid,ql,qr);
        
    }
    if(qr>mid){
        res+=query(rt<<1|1,mid+1,r,ql,qr);
        
    }
    return res;
}


int main(){
    cin>>n>>m;
    for(int i=1;i<=n;i++){
        cin>>a[i];        
    }
    build(1,1,n);
    while(m--){
        int op;
        cin>>op;
        if(op==1){
            int x,y;
            ll k;
            cin>>x>>y>>k;
            update(1,1,n,x,y,k);
        }
        if(op==2){
            int x,y;
            cin>>x>>y;
            ll ans=query(1,1,n,x,y);
            cout<<ans<<endl;
        }
            
    }

    return 0;
}
```

## 复盘备注

易错点：
- 数据范围要求使用 `long long`，`sum`、`lazy`、加法增量及查询结果均需 64 位。
- `push_down` 中标记乘以子区间长度时注意左右长度分别为 `mid-l+1` 和 `r-mid`。
- 修改和查询递归前必须先 `push_down`，否则子结点信息可能未更新。
- 数组大小需开到 4n 以上，代码中 `MAXN=5e5+10` 足够。
可优化点：
- 输入输出量较大时可使用 `scanf/printf` 或关闭同步的 `cin/cout`。
- 本题为线段树基础模板，可进一步练习区间乘、区间赋值等带多种懒标记的题目。
