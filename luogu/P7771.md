## 题目简述

求有向图字典序最小的欧拉路径。

输入格式
第一行两个整数 $n,m$ 表示有向图的点数和边数。

接下来 $m$ 行每行两个整数 $u,v$ 表示存在一条 $u\to v$ 的有向边。

输出格式
如果不存在欧拉路径，输出一行 `No`。

否则输出一行 $m+1$ 个数字，表示字典序最小的欧拉路径。

说明/提示
对于 $50\%$ 的数据，$n,m\leq 10^3$。

对于 $100\%$ 的数据，$1\leq u,v\leq n\leq 10^5$，$m\leq 2\times 10^5$。

保证将有向边视为无向边后图连通。

## 解题思路

1. 欧拉路径存在性判定：统计每个点的入度与出度。
   - 若所有点入度等于出度，则存在欧拉回路，可从任意有出边的点出发；
   - 若恰有一个点出度比入度大 1（起点），一个点入度比出度大 1（终点），其余点入度等于出度，则存在欧拉路径；
   - 其他情况均不存在。
2. 字典序最小：对每个点的邻接表按终点编号升序排序。这样在 DFS 时优先走编号小的边。
3. 使用迭代版 Hierholzer 算法：用栈模拟 DFS，每次取当前点尚未访问的最小邻边前进；当无路可走时，将当前点加入答案序列并退栈。
4. 最终答案序列是逆序的欧拉路径，倒序输出即为字典序最小的欧拉路径。
5. 正确性要点：Hierholzer 算法保证每条边恰好走一次；邻接表升序保证在回溯时优先选择小编号边，从而得到字典序最小的路径；最后检查答案长度是否为 m+1，可排除图不连通等异常情况。

## 代码

```cpp
#include<bits/stdc++.h>
using namespace std;
typedef long long ll;
const int MAXN=1e5+10;
vector<int> g[MAXN];
int indeg[MAXN],outdeg[MAXN],idx[MAXN];
int stk[MAXN*2],ans[MAXN*2];
int n,m;
int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin>>n>>m;
    for(int i=1;i<=m;i++){
        int u,v;
        cin>>u>>v;
        g[u].push_back(v);
        outdeg[u]++;
        indeg[v]++;
    }
    int start=1,cnt1=0,cnt2=0;
    for(int i=1;i<=n;i++){
        if(outdeg[i]-indeg[i]==1)cnt1++,start=i;
        else if(indeg[i]-outdeg[i]==1)cnt2++;
        else if(outdeg[i]!=indeg[i]){
            cout<<"No\n";return 0;
        }
    }
    if(cnt1==0&&cnt2==0){
        for(int i=1;i<=n;i++){
            if(!g[i].empty()){start=i;break;}
        }
    }else if(!(cnt1==1&&cnt2==1)){
        cout<<"No\n";return 0;
    }
    for(int i=1;i<=n;i++)sort(g[i].begin(),g[i].end());
    int top=0,cnt=0;
    stk[++top]=start;
    while(top){
        int u=stk[top];
        if(idx[u]<(int)g[u].size()){
            int v=g[u][idx[u]];
            idx[u]++;
            stk[++top]=v;
        }else{
            ans[++cnt]=u;
            top--;
        }
    }
    if(cnt!=m+1){cout<<"No\n";return 0;}
    for(int i=cnt;i>=1;i--)cout<<ans[i]<<" ";
    cout<<"\n";
    return 0;
}
```

## 复盘备注

易错点：
- 起点选择：当存在欧拉路径时，起点是出度比入度大 1 的点；当存在欧拉回路时，起点应为编号最小的有出边的点。
- 排序邻接表是保证字典序最小的关键。
- 迭代版 DFS 避免递归爆栈。
- 最后需检查答案长度是否为 m+1，防止图不连通时输出错误路径。
- 注意多组数据或自环、重边的情况。
