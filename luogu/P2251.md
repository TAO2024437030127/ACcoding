## 题目简述

为了检测生产流水线上总共 $N$ 件产品的质量，我们首先给每一件产品打一个分数 $A$ 表示其品质，然后统计前 $M$ 件产品中质量最差的产品的分值 $Q_M = \min\{A_1, A_2, \cdots, A_M\}$，以及第 $2$ 至第 $M + 1$ 件的 $Q_{M + 1},Q_{M + 2},\cdots$，最后统计第 $N - M + 1$ 至第 $N$ 件的 $Q_N$，根据 $Q$ 再做进一步评估。

请你尽快求出 $Q$ 序列。

输入格式
输入共两行。

第一行共两个数 $N,M$，由空格隔开。含义如前述。

第二行共 $N$ 个数，表示 $N$ 件产品的质量。

输出格式
输出共 $N - M + 1$ 行。

第 $1$ 至 $N - M + 1$ 行每行一个数，第 $i$ 行的数表示 $Q_{i + M - 1}$。含义如前述。

说明/提示
对于 $30\%$ 的数据，$N \le 1 000$。

对于 $100\%$ 的数据，$1 \le M \le N \le 10^5$，$A_i \le 10^6$。

## 解题思路

本题是经典的滑动窗口最小值问题，使用单调队列（双端队列 deque）维护窗口内元素下标，使队列中对应元素值单调递增。

- 关键观察：对于两个下标 i < j，若 A[i] >= A[j]，则 A[i] 不可能成为后续任何窗口的最小值，可以提前删除。
- 算法步骤：遍历序列，对每个元素 A[i]：
  1. 从队尾不断弹出对应值大于等于 A[i] 的下标，保证队列单调递增；
  2. 将当前下标 i 入队；
  3. 若队首下标 <= i-M，说明已滑出窗口，弹出队首；
  4. 当 i >= M 时，队首即为当前窗口最小值，输出 A[队首]。
- 正确性要点：队列中始终保存当前窗口内可能成为最小值的候选下标，且队首为窗口最小值；每个元素最多入队、出队一次，保证线性时间。

## 复杂度分析

- 时间复杂度：O(N)
- 空间复杂度：O(N)

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
int main(){
    int n,m;
    cin>>n>>m;
    vector<int> num(n+1);
    for(int i=1;i<=n;i++){
        cin>>num[i];
    }
    deque<int> dq;
    for(int i=1;i<=n;i++){
        while(!dq.empty()&&num[i]<num[dq.back()]){
            dq.pop_back();
        }
        dq.push_back(i);
        while(dq.front()<=i-m){
            dq.pop_front();
        }
        if(i>=m){
            cout<<num[dq.front()]<<endl;
        }
    }
    return 0;
}
```

## 复盘备注

易错点：
- 弹出队首的条件应为 `dq.front() <= i - m`，注意等号，确保窗口长度为 M。
- 输出时机为 `i >= m`，即从第 M 个元素开始输出。
- 使用 `endl` 换行在数据量较大时可能较慢，可改用 `'\n'` 优化。

同类题：滑动窗口最大值（洛谷 P1886）、窗口内的最小值等单调队列模板题。
