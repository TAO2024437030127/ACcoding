## 题目简述

小 L 有一根 $n$ 厘米的刻度尺，上面有刻度 $0,1,\ldots, n$。她想知道有哪些刻度和 $a$ 厘米刻度的距离**恰好**是 $b$ 厘米。请你从小到大输出所有满足要求的刻度，以空格隔开。特别地，如果没有满足要求的刻度，输出 `No solution`。

输入格式
输入有一行三个整数 $n,a,b$，分别表示刻度尺长度、给定的刻度和距离。

输出格式
从小到大输出一行若干个整数，用空格隔开，表示所有可能的刻度。

特别的，如果不存在满足要求的刻度，输出 `No solution`。

说明/提示
对于全体数据，保证 $1\le n \le 100$，$0\le a\le n$，$0\le b\le 100$。

## 解题思路

- 关键观察：与刻度 a 距离为 b 的刻度只有两个候选：a-b 和 a+b。
- 合法条件：候选刻度必须在 [0, n] 范围内。
- 算法选择：直接判断两个候选是否合法，按从小到大顺序输出。
- 正确性要点：
  1. 若 a-b 合法（即 a-b >= 0），则它一定小于等于 a+b，先输出；
  2. 若 a+b 合法（即 a+b <= n），则输出；
  3. 注意 b=0 时两个候选相同，只输出一次 a；
  4. 若两个候选都不合法，输出 No solution。
- 代码中通过分支处理了各种边界情况，逻辑等价于上述判断。

## 代码

```text
#include<iostream>
using namespace std;
int main(){
    int n,a,b;
    cin>>n>>a>>b;
    if(a-b<0&&a+b>n){
        cout<<"No solution";
    }else if(a-b<0&&a+b<=n){
        cout<<a+b;
    }else if(b==0){
        cout<<a;
    }
    else if(a-b>=0&&a+b>n){
        cout<<a-b;
    }else{
        cout<<a-b<<" "<<a+b;
    }
    return 0;
}
```

## 复盘备注

- 易错点：b=0 时 a-b 和 a+b 相等，不能重复输出；
- 易错点：候选刻度必须在 0 到 n 之间，包括端点；
- 可优化点：代码分支较多，可统一为判断两个候选是否合法后按序输出，更简洁；
- 同类题提示：注意距离的对称性和边界条件。
