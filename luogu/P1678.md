## 题目简述

计算机竞赛小组的神牛 V 神终于结束了高考，然而作为班长的他还不能闲下来，班主任老 t 给了他一个艰巨的任务：帮同学找出最合理的大学填报方案。可是 V 神太忙了，身后还有一群小姑娘等着和他约会，于是他想到了同为计算机竞赛小组的你，请你帮他完成这个艰巨的任务。

现有 $m$ 所学校，其中第 $i$ 所学校的预计分数线为 $a_i$。有 $n$ 位学生，其中第 $i$ 位学生的估分为 $b_i$。

根据 $n$ 位学生的估分情况，分别给每位学生推荐一所学校，要求学校的预计分数线和学生的估分相差最小（可高可低，毕竟是估分嘛），这个最小值为这位学生的不满意度。求所有学生的不满意度的和。

输入格式
第一行包含两个正整数 $m,n$，分别表示学校数和学生数。

第二行包含 $m$ 个非负整数 $a_1,a_2,\dots,a_m$，分别表示 $m$ 所学校的预计分数线。

第三行包含 $n$ 个非负整数 $b_1,b_2,\dots,b_n$，分别表示 $n$ 位学生的估分。

输出格式
输出一行一个非负整数，表示所有学生的不满意度的和。

说明/提示
数据范围：

对于 $30\%$ 的数据，$1\le n,m\le{10}^3$，$0\le a_i,b_i\le{10}^4$；

对于 $100\%$ 的数据，$1\le n,m\le{10}^5$，$0\le a_i,b_i\le{10}^6$。

## 解题思路

1. 将学校分数线数组 a 升序排序，便于对每个估分快速找到最接近的分数线。
2. 对每个学生估分 b，在有序数组 a 中二分查找第一个大于等于 b 的位置 pos（即 lower_bound）。
3. 最接近 b 的分数线只可能是 a[pos]（若 pos < m）或 a[pos-1]（若 pos > 0），分别计算绝对差并取较小值，累加到总和 sum。
4. 正确性要点：排序后数组单调，二分找到的 pos 是第一个不小于 b 的元素，因此 b 左侧最近的元素是 a[pos-1]，右侧最近的是 a[pos]，全局最近元素必在这两者之中。
5. 使用 long long 存储总和，防止 n 较大时累加溢出。

## 复杂度分析

- 时间复杂度：O(m log m + n log m)
- 空间复杂度：O(m)

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
typedef long long ll;

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int m,n;
    cin>>m>>n;
    vector<int> a(m);
    for(int i=0;i<m;i++) cin>>a[i];
    sort(a.begin(),a.end());
    ll sum=0;
    for(int i=0;i<n;i++){
        int b;
        cin>>b;
        int l=0,r=m-1;
        int pos=m;
        while(l<=r){
            int mid=(l+r)/2;
            if(a[mid]>=b){
                pos=mid;
                r=mid-1;
            }else{
                l=mid+1;
            }
        }
        int mi=INT_MAX;
        if(pos<m) mi=min(mi,abs(a[pos]-b));
        if(pos>0) mi=min(mi,abs(a[pos-1]-b));
        sum+=mi;
    }
    cout<<sum<<endl;
    return 0;

}
```

## 复盘备注

易错点：
- 二分查找的边界处理：pos 初始化为 m，当所有分数线都小于 b 时，只能取 a[m-1]；当所有分数线都大于 b 时，只能取 a[0]。
- 总和需用 long long，避免 int 溢出。
- 输入输出量较大，建议关闭同步流加速。

可优化点：
- 也可使用 std::lower_bound 简化代码。
- 若估分范围较小，可考虑计数排序或前缀最值，但本题二分已足够。

同类题提示：
- 有序数组上查找最接近给定值的元素，常使用二分查找定位插入点后比较相邻元素。
