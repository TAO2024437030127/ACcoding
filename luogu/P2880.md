## 题目简述

每天，农夫 John 的 $n\ (1\le n\le 5\times 10^4)$ 头牛总是按同一序列排队。

有一天，John 决定让一些牛们玩一场飞盘比赛。他准备找一群在队列中位置连续的牛来进行比赛。但是为了避免水平悬殊，牛的身高不应该相差太大。John 准备了 $q\ (1\le q\le 1.8\times10^5)$ 个可能的牛的选择和所有牛的身高 $h_i\ (1\le h_i\le 10^6,1\le i\le n)$。他想知道每一组里面最高和最低的牛的身高差。

输入格式
第一行两个数 $n,q$。

接下来 $n$ 行，每行一个数 $h_i$。

再接下来 $q$ 行，每行两个整数 $a$ 和 $b$，表示询问第 $a$ 头牛到第 $b$ 头牛里的最高和最低的牛的身高差。

输出格式
输出共 $q$ 行，对于每一组询问，输出每一组中最高和最低的牛的身高差。

## 解题思路

本题是经典的静态区间最值查询（RMQ）问题，使用 ST 表（Sparse Table）解决。

1. **关键观察**：区间最大值和最小值可以分别用两个 ST 表维护，查询时取两个表的结果相减即可。
2. **预处理**：
   - 用 `Log[i]` 预处理每个长度的二进制对数，`Log[i] = Log[i/2] + 1`。
   - `max_st[k][i]` 表示从位置 i 开始、长度为 2^k 的区间最大值；`min_st[k][i]` 同理维护最小值。
   - 递推式：`max_st[k][i] = max(max_st[k-1][i], max_st[k-1][i + 2^(k-1)])`，最小值类似。
3. **查询**：对于区间 [l, r]，长度 len = r-l+1，取 k = Log[len]，则区间最值可由两个长度为 2^k 的重叠区间覆盖：`max(max_st[k][l], max_st[k][r-2^k+1])`，最小值同理。
4. **正确性**：两个长度为 2^k 的区间覆盖了整个查询区间（允许重叠），因此最大值和最小值不会遗漏。
5. **实现细节**：代码中 `LOG=20`，因为 n ≤ 5×10^4，2^16 > 5×10^4，20 足够。数组下标从 1 开始，预处理时注意边界 `i + (1<<k) - 1 <= n`。

## 复杂度分析

- 时间复杂度：预处理 O(n log n)，每次查询 O(1)，总 O(n log n + q)
- 空间复杂度：O(n log n)

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
const int LOG=20;

int getmax(int l,int r,vector<vector<int>> &st,vector<int> &Log){
    int len=r-l+1;
    int k=Log[len];
    return max(st[k][l], st[k][r-(1<<k)+1]);
}
int getmin(int l,int r,vector<vector<int>> &st,vector<int> &Log){
    int len=r-l+1;
    int k=Log[len];
    return min(st[k][l], st[k][r-(1<<k)+1]);
}

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n,q;
    cin>>n>>q;

    vector<vector<int>> max_st(LOG,vector<int>(n+1));
    vector<vector<int>> min_st(LOG,vector<int>(n+1));
    vector<int> Log(n+1);
    
    Log[1]=0;
    for(int i=2;i<=n;i++) Log[i]=Log[i/2]+1;
    
    for(int i=1;i<=n;i++){
        cin>>max_st[0][i];
        min_st[0][i]=max_st[0][i];
    }

    //预处理最大表
    for(int k=1;k<LOG;k++){
        for(int i=1;i+(1<<k)-1<=n;i++){
            max_st[k][i]=max(max_st[k-1][i],max_st[k-1][i+(1<<(k-1))]);
        }
    }
    //预处理最小表
    for(int k=1;k<LOG;k++){
        for(int i=1;i+(1<<k)-1<=n;i++){
            min_st[k][i]=min(min_st[k-1][i],min_st[k-1][i+(1<<(k-1))]);
        }
    }

    int l,r;
    while(q--){
        cin>>l>>r;
        int mx=getmax(l,r,max_st,Log);
        int mi=getmin(l,r,min_st,Log);
        cout<<mx-mi<<'\n';
    }
    return 0;
}
```

## 复盘备注

易错点：
- ST 表第二维大小应为 n+1，且预处理循环边界要写对，避免越界。
- 查询时 `r - (1<<k) + 1` 不要写成 `r - (1<<k)`。
- 当 l == r 时，k=0，两个区间相同，结果正确。

可优化点：
- 可以将两个 ST 表合并为一个结构体或使用 `array` 减少重复代码。
- 若内存紧张，可用 `short` 存储身高（身高 ≤ 10^6，int 足够），但本题空间充足。
