## 题目简述

两个整数 $a$ 和 $b$ 分别作为分子和分母，即分数 $\dfrac{a}{b}$，求它的浮点数值（双精度浮点数，保留小数点后 $9$ 位）。

输入格式
输入仅一行，包括两个整数 $a$ 和 $b$。

输出格式
输出也仅一行，分数 $\dfrac{a}{b}$ 的浮点数值（双精度浮点数，保留小数点后 $9$ 位）。

说明/提示
对于 $100 \%$ 的数据，$1 \le a, b \le {10}^9$。

## 样例

### 样例 1

输入：
```text
5 7
```

输出：
```text
0.714285714
```

## 解题思路

1. 数据范围到 10^9，乘积可能超出 int 范围，因此用 long long 读入 a 和 b。
2. 直接计算 a/b 会进行整数除法导致小数部分丢失，需要先转换为浮点数：用 1.0*a 使表达式变为 double 类型，再除以 b。
3. 使用 printf 的格式控制符 %.9lf 输出 double 类型结果，自动四舍五入保留 9 位小数。
4. 正确性要点：转换顺序保证先做浮点乘法再做除法，避免整数截断；long long 保证输入不溢出；输出格式与题目要求一致。

## 复杂度分析

- 时间复杂度：O(1)
- 空间复杂度：O(1)

## 代码

```cpp
#include<iostream>
#include<cstdio>
using namespace std;
int main(){
    long long a,b;
    scanf("%lld %lld", &a, &b);
    double res=1.0*a/b;
    printf("%.9lf",res);
    return 0;
}
```

## 复盘备注

易错点：直接写 a/b 会得到整数结果；应写成 1.0*a/b 或 (double)a/b。输入范围较大，建议用 long long 而非 int。输出保留 9 位小数可用 printf("%.9lf") 或 cout << fixed << setprecision(9)。
