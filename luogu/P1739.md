## 题目简述

假设一个表达式由数字、英文字母（小写）、运算符（`+`、`-`、`*`、`/`）和左右小（圆）括号构成，以 `@` 作为表达式的结束符。请编写一个程序检查表达式中的左右圆括号是否匹配，若匹配，则输出 `YES`；否则输出 `NO`。表达式长度小于 $255$，左圆括号少于 $20$ 个。

输入格式
一行：表达式。

输出格式
一行：`YES` 或 `NO`。

说明/提示
表达式长度小于 $255$，左圆括号少于 $20$ 个。

## 样例

### 样例 1

输入：
```text
2*(x+y)/(1-x)@
```

输出：
```text
YES
```

### 样例 2

输入：
```text
(25+x)*(a*(a+b+b)@
```

输出：
```text

```

## 解题思路

本题只需关注括号，其他字符（数字、字母、运算符、@）全部忽略。

- 关键观察：括号匹配具有“后进先出”的性质，遇到左括号就期待之后出现右括号，遇到右括号就应消耗最近一个未匹配的左括号，因此用栈维护未匹配的左括号。
- 算法选择：顺序扫描字符串，遇到 '(' 入栈；遇到 ')' 时，若栈空说明当前右括号没有对应左括号，直接标记非法并结束；否则弹出栈顶左括号。
- 正确性要点：扫描结束后，若中途没有出现“右括号多于左括号”的情况，且栈为空，说明左右括号数量相等且任意前缀中左括号不少于右括号，即完全匹配；否则不匹配。
- 实现细节：代码中 valid 标记中途是否出现非法右括号，最后同时检查 valid 与 st.empty()。

## 复杂度分析

- 时间复杂度：O(n)，其中 n 为表达式长度，每个字符至多处理一次。
- 空间复杂度：O(n)，栈中最多存储所有左括号，题目中左括号少于 20 个，实际很小。

## 代码

```text
#include<iostream>
#include<stack>
#include<string>
using namespace std; 
int main(){
    string s;
    cin>>s;
    stack<char> st;
    bool valid = true;
    int n = s.size();
    for(int i = 0; i < n; i++){
        if(s[i] == '('){
            st.push(s[i]);
        }
        else if(s[i] == ')'){
            if(st.empty()){
                // 没有左括号匹配当前右括号
                valid = false;
                break;
            }
            st.pop();
        }
    }
    // 合法条件：中途无异常 + 栈内无剩余左括号
    if(valid && st.empty()){
        cout<<"YES";
    }else{
        cout<<"NO";
    }
    return 0;
}
```

## 复盘备注

易错点：遇到右括号时若栈空必须立即判定为 NO；扫描结束后还要检查栈是否为空，否则会漏掉多余左括号的情况。
可优化点：由于只关心左括号数量，可以用一个计数器代替栈，空间降为 O(1)。
同类题提示：若括号种类不止一种（如同时有圆括号、方括号、花括号），则需要用栈保存括号类型并检查配对。
