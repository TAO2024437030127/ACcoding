## 题目简述

小 T 是一名质量监督员，最近负责检验一批矿产的质量。这批矿产共有 $n$ 个矿石，从 $1$ 到 $n$ 逐一编号，每个矿石都有自己的重量 $w_i$ 以及价值 $v_i$。检验矿产的流程是：

1. 给定 $m$ 个区间 $[l_i,r_i]$；
2. 选出一个参数 $W$；
3. 对于一个区间 $[l_i,r_i]$，计算矿石在这个区间上的检验值 $y_i$：

$$y_i=\sum\limits_{j=l_i}^{r_i}[w_j \ge W] \times \sum\limits_{j=l_i}^{r_i}[w_j \ge W]v_j$$

其中 $j$ 为矿石编号，$[p]$ 是指示函数，若条件 $p$ 为真返回 $1$，否则返回 $0$。

这批矿产的检验结果 $y$ 为各个区间的检验值之和。即：$\sum\limits_{i=1}^m y_i$。

若这批矿产的检验结果与所给标准值 $s$ 相差太多，就需要再去检验另一批矿产。小 T 不想费时间去检验另一批矿产，所以他想通过调整参数 $W$ 的值，让检验结果尽可能的靠近标准值 $s$，即使得 $|s-y|$ 最小。请你帮忙求出这个最小值。

输入格式
第一行包含三个整数 $n,m,s$，分别表示矿石的个数、区间的个数和标准值。

接下来的 $n$ 行，每行两个整数，中间用空格隔开，第 $i+1$ 行表示 $i$ 号矿石的重量 $w_i$ 和价值 $v_i$。

接下来的 $m$ 行，表示区间，每行两个整数，中间用空格隔开，第 $i+n+1$ 行表示区间 $[l_i,r_i]$ 的两个端点 $l_i$ 和 $r_i$。注意：不同区间可能重合或相互重叠。

输出格式
一个整数，表示所求的最小值。

说明/提示
【输入输出样例说明】

当 $W$ 选 $4$ 的时候，三个区间上检验值分别为 $20,5,0$，这批矿产的检验结果为 $25$，此时与标准值 $s$ 相差最小为 $10$。

【数据范围】

对于 $10\%$ 的数据，有 $1 ≤n,m≤10$；

对于 $30\%$ 的数据，有 $1 ≤n,m≤500$；

对于 $50\%$ 的数据，有 $1 ≤n,m≤5,000$；

对于 $70\%$ 的数据，有 $1 ≤n,m≤10,000$；

对于 $100\%$ 的数据，有 $1 ≤n,m≤2\times 10^5$，$0 < w_i,v_i≤10^6$，$0 < s≤10^{12}$，$1 ≤l_i ≤r_i ≤n$。

## 解题思路

关键观察：当 W 增大时，满足 w_j ≥ W 的矿石变少，每个区间的个数与价值和均单调不增，因此总检验值 y 关于 W 单调不增。

算法选择：二分答案 W。在 [1, max_w] 上二分，对每个 mid 用前缀和 O(n+m) 计算 y(mid)，并更新 |y-s| 的最小值。

正确性要点：
1. 单调性保证二分可以找到使 y 跨越 s 的临界 W，而最优 W 一定在临界点附近；
2. 每次计算 y 时，先预处理前缀个数 cnt 和前缀价值和 sumv，再对每个区间用 O(1) 得到区间内满足条件的个数 c 与价值和 val，累加 c*val；
3. 二分过程中同时记录所有访问过的 W 对应的 |y-s|，最终答案即为最小值。

注意：y 可能很大，需用 long long；ans 初始化为足够大的值。

## 复杂度分析

- 时间复杂度：O((n+m) log max_w)
- 空间复杂度：O(n+m)

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
typedef long long ll;

int n, m;
ll s;
vector<ll> w, v;
vector<int> L, R;

// 计算参数W对应的总y值
ll get_y(int W) {
    vector<ll> cnt(n + 1, 0), sumv(n + 1, 0);
    for (int i = 1; i <= n; i++) {
        cnt[i] = cnt[i - 1];
        sumv[i] = sumv[i - 1];
        if (w[i] >= W) {
            cnt[i]++;
            sumv[i] += v[i];
        }
    }
    ll total = 0;
    for (int i = 1; i <= m; i++) {
        int l = L[i], r = R[i];
        ll c = cnt[r] - cnt[l - 1];
        ll val = sumv[r] - sumv[l - 1];
        total += c * val;
    }
    return total;
}

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    cin >> n >> m >> s;
    w.resize(n + 1);
    v.resize(n + 1);
    L.resize(m + 1);
    R.resize(m + 1);
    
    int max_w = 0;
    for(int i = 1; i <= n; i++){
        cin >> w[i] >> v[i];
        max_w = max(max_w, (int)w[i]);
    }
    for(int i = 1; i <= m; i++){
        cin >> L[i] >> R[i];
    }
    
    ll ans = 1e18;
    int l = 1, r = max_w;
    while(l <= r) {
        int mid = (l + r) / 2;
        ll y = get_y(mid);
        ans = min(ans, abs(y - s));
        if(y > s) {
            l = mid + 1;
        } else {
            r = mid - 1;
        }
    }
    cout << ans << endl;
    return 0;
}
```

## 复盘备注

易错点：
- y 可能超过 int 范围，必须用 long long；
- 二分边界可取 [1, max_w+1]，其中 W=max_w+1 时 y=0，可覆盖 s 很小的情况；
- 计算区间贡献时注意 cnt 和 sumv 的差分下标为 l-1。

可优化点：
- 可将 get_y 中的临时数组改为全局数组复用，减少反复分配；
- 二分时若 y==s 可直接输出 0 提前结束。

同类题提示：涉及“参数单调影响结果”并求最接近目标值的题目，常可用二分答案 + 前缀和/差分优化判定。
