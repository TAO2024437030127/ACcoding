## 题目简述

已知一个数列 $a$，它满足：

$$
a_x=
\begin{cases}
1 & x \in\{1,2,3\}\\
a_{x-1}+a_{x-3} & x \geq 4
\end{cases}
$$

求 $a$ 数列的第 $n$ 项对 $10^9+7$ 取余的值。

输入格式
第一行一个整数 $T$，表示询问个数。

以下 $T$ 行，每行一个正整数 $n$。

输出格式
每行输出一个非负整数表示答案。

说明/提示
- 对于 $30\%$ 的数据 $n \leq 100$；
- 对于 $60\%$ 的数据 $n \leq2 \times 10^7$；
- 对于 $100\%$ 的数据 $1 \leq T \leq 100$，$1 \leq n \leq 2 \times 10^9$。

## 解题思路

关键观察：递推式 a_x = a_{x-1} + a_{x-3} 是常系数线性递推，可以用 3×3 矩阵表示状态转移。

1. 构造状态向量 S_k = [a_k, a_{k-1}, a_{k-2}]^T，则 S_{k+1} = M · S_k，其中 M = [[1,0,1],[1,0,0],[0,1,0]]。
2. 初始状态 S_3 = [a_3, a_2, a_1]^T = [1,1,1]^T。
3. 因此 S_n = M^{n-3} · S_3，a_n 就是结果向量的第一个分量。
4. 对于 n≤3 直接输出 1；否则用快速幂计算 M^{n-3}，再与初始向量相乘（代码中直接取矩阵第一行与 [1,1,1] 点积）。
5. 正确性：矩阵乘法与递推式完全对应，快速幂保证指数运算正确；所有乘法用 __int128 防止溢出，结果对 mod 取模。

## 复杂度分析

- 时间复杂度：O(T log n)，每次询问做 O(log n) 次 3×3 矩阵乘法，常数很小。
- 空间复杂度：O(1)，只存储固定大小的 3×3 矩阵。

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
typedef long long ll;
using mat=vector<vector<ll>>;
const ll mod=1e9+7;
mat mul(const mat &a,const mat &b){
    int n=a.size();
    mat c(n,vector<ll>(n,0));
    for(int i=0;i<n;i++){
        for(int k=0;k<n;k++){
            if(a[i][k]){
                for(int j=0;j<n;j++){
                    c[i][j]=(c[i][j]+(__int128)a[i][k]*b[k][j])%mod;
                }
            }
        }
    }
    return c;
    
}

mat qpow(mat a,ll p){
    int n=a.size();
    mat res(n,vector<ll>(n,0));
    for(int i=0;i<n;i++){
        res[i][i]=1;
    }
    while(p){
        if(p&1) res=mul(res,a);
        a=mul(a,a);
        p>>=1;
    }
    return res;
}
int main(){
    int t;
    cin>>t;
    int n;
    mat m={{1,0,1},{1,0,0},{0,1,0}};
    while(t--){
        cin>>n;
        if(n<=3){cout<<"1\n";continue;}
        mat powM=qpow(m,n-3);
        ll ans = (powM[0][0]*1 + powM[0][1]*1 + powM[0][2]*1) % mod;
        cout<<ans<<"\n";
    }
    return 0;
}
```

## 复盘备注

易错点：
- n≤3 时需特判，否则 n-3 为负数会导致快速幂死循环或错误。
- 矩阵乘法中累加可能超过 long long，代码用 __int128 强制转换避免溢出。
- 取模要每一步都做，防止中间值过大。

可优化点：
- 矩阵大小固定为 3，可以展开循环或使用一维数组存储，减少 vector 开销。
- 多个询问可以预处理矩阵的 2 的幂次，但本题 T 很小，直接快速幂已足够。

同类题提示：常系数线性递推求第 n 项（如斐波那契、Tribonacci 等）均可构造转移矩阵后用快速幂求解。
