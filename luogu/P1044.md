## 题目简述

栈是计算机中经典的数据结构，简单的说，栈就是限制在一端进行插入删除操作的线性表。

栈有两种最重要的操作，即 pop（从栈顶弹出一个元素）和 push（将一个元素进栈）。

栈的重要性不言自明，任何一门数据结构的课程都会介绍栈。宁宁同学在复习栈的基本概念时，想到了一个书上没有讲过的问题，而他自己无法给出答案，所以需要你的帮忙。

![](https://cdn.luogu.com.cn/upload/image_hosting/5qxy9fz2.png)

宁宁考虑的是这样一个问题：一个操作数序列，$1,2,\ldots ,n$（图示为 1 到 3 的情况），栈 A 的深度大于 $n$。

现在可以进行两种操作，

1. 将一个数，从操作数序列的头端移到栈的头端（对应数据结构栈的 push 操作）
2. 将一个数，从栈的头端移到输出序列的尾端（对应数据结构栈的 pop 操作）

使用这两种操作，由一个操作数序列就可以得到一系列的输出序列，下图所示为由 `1 2 3` 生成序列 `2 3 1` 的过程。

![](https://cdn.luogu.com.cn/upload/image_hosting/8uwv2pa2.png)

（原始状态如上图所示）

你的程序将对给定的 $n$，计算并输出由操作数序列 $1,2,\ldots,n$ 经过操作可能得到的输出序列的总数。

输入格式
输入文件只含一个整数 $n$（$1 \leq n \leq 18$）。

## 解题思路

本题本质是求第 n 个卡特兰数。

关键观察：设 f[i] 表示 i 个元素依次入栈出栈能得到的不同输出序列数。考虑最后一个出栈的元素是第 j+1 个入栈元素（j 从 0 到 i-1）：在它入栈前，前 j 个元素已经完成入栈和出栈，方案数为 f[j]；在它入栈后、出栈前，后 i-1-j 个元素完成入栈和出栈，方案数为 f[i-1-j]。两者相互独立，因此 f[i] = Σ_{j=0}^{i-1} f[j] * f[i-1-j]。

算法选择：直接按上述递推式做区间 DP（即卡特兰数递推），初始化 f[0]=1，从 i=1 到 n 依次计算。

正确性要点：每个输出序列唯一对应最后一个出栈元素的位置划分，且前后两段互不影响，因此乘法原理成立；枚举所有可能的 j 不重不漏。n≤18 时结果在 long long 范围内。

## 复杂度分析

- 时间复杂度：O(n^2)
- 空间复杂度：O(n)

## 代码

```text
#include <iostream>
#include <vector>
using namespace std;
typedef long long ll;

int main()
{
    int n;
    cin >> n;
    vector<ll> dp(n+1,0);
    dp[0] = 1;
    for(int i = 1; i <= n; ++i)
    {
        for(int j = 0; j < i; ++j)
        {
            dp[i] += dp[j] * dp[i-1-j];
        }
    }
    cout << dp[n] << endl;
    return 0;
}
```

## 复盘备注

易错点：dp 数组需用 long long，n=18 时卡特兰数约为 4.77e9，超过 int 范围；递推时注意 dp[0]=1 的初始化。
可优化点：也可直接用卡特兰数公式 C(2n,n)/(n+1) 计算，但需注意乘法溢出，本题 O(n^2) 已足够。
