## 题目简述

今天是小 Z 的生日，同学们为他带来了一块蛋糕。这块蛋糕是一个长方体，被用不同色彩分成了 $n$ 个相同的小块，每小块都有对应的幸运值。

小 Z 作为寿星，自然希望吃到的蛋糕的幸运值总和最大，但小 Z 最多又只能吃 $m(m\le n)$ 小块的蛋糕。

请你帮他从这 $n$ 小块中找出**连续**的 $k(1 \le k\le m)$ 块蛋糕，使得其上的总幸运值最大。

**形式化地**，在数列 $\{p_n\}$ 中，找出一个子段 $[l,r](r-l+1\le m)$，最大化 $\sum\limits_{i=l}^rp_i$。

输入格式
第一行两个整数 $n,m$。分别代表共有 $n$ 小块蛋糕，小 Z 最多只能吃 $m$ 小块。

第二行 $n$ 个整数，第 $i$ 个整数 $p_i$ 代表第 $i$ 小块蛋糕的幸运值。

输出格式
仅一行一个整数，即小 Z 能够得到的最大幸运值。

说明/提示
#### 数据规模与约定

- 对于 $20\%$ 的数据，有 $1\le n\le100$。
- 对于 $100\%$ 的数据，有 $1\le n\le5\times 10^5$，$|p_i|≤500$。

保证答案的绝对值在 $[0,2^{31}-1]$ 之内。

## 解题思路

本题是经典的最大子段和模型加上长度限制，用前缀和与单调队列解决。

1. 设前缀和 s[i]=p[1]+...+p[i]，则子段 [l,r] 的和为 s[r]-s[l-1]。
2. 枚举右端点 i，需要找左端点 j=l-1 满足 i-j≤m，即 j≥i-m，并让 s[j] 尽量小。
3. 用单调队列维护下标 j 的候选集合，队列中 s[j] 单调递增，队首即当前窗口内最小的 s[j]。
4. 初始把下标 0 入队（对应空前缀，s[0]=0），保证可以取从第一个元素开始的子段。
5. 对每个 i：先弹出队首中 j<i-m 的过期下标；此时队首 j 满足长度限制，用 s[i]-s[j] 更新答案；再把 i 入队，入队前从队尾弹出所有 s 值不小于 s[i] 的下标，保持队列单调。
6. 正确性：队列中始终保存窗口 [i-m, i-1] 内可能成为最小前缀和的下标，队首就是该窗口最小值，因此每个右端点都取到了最优左端点。

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
typedef long long ll;
const int MAX=500010;
int main(){
    ios::sync_with_stdio(false);
    cin.tie(0); // 加读入加速，大数据不超时
    int n,m;
    cin>>n>>m;
    vector<ll> p(n+1);
    vector<ll> s(n+1,0);
    deque<ll> q;
    // 关键：预先存入l=0，s[0]=0
    q.push_back(0);
    for(int i=1;i<=n;i++){
        cin>>p[i];
        s[i]=s[i-1]+p[i];
    }
    ll ans=-1e18;
    
    for(int i=1;i<=n;i++){
        // 1. 移除超出窗口左边界的下标
        while(!q.empty()&&q.front()<i-m){
            q.pop_front();
        }
        // 此时队列一定非空，安全取队首最小值
        ans=max(ans,s[i]-s[q.front()]);
        // 2. 单调队列：队尾比当前s[i]大则弹出，维护递增
        while(!q.empty()&&s[q.back()]>=s[i]){
            q.pop_back();
        }
        q.push_back(i);
    }
    cout<<ans;
    return 0;
}
```

## 复盘备注

易错点：
- 初始必须把下标 0 入队，否则无法处理从第一个元素开始的子段。
- 弹出过期下标的条件是 q.front() < i-m，不是 ≤。
- 维护单调队列时用 >= 弹出队尾，可避免重复值堆积，不影响答案。
- 答案初始化为足够小的负数，因为元素可能全为负。

同类题：P1440 求 m 区间内的最小值、P1886 滑动窗口、P2032 扫描，都是单调队列模板。
