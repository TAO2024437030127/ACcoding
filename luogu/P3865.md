## 题目简述

这是一道 ST 表经典题——静态区间最大值

**请注意最大数据时限只有 0.8s，数据强度不低，请务必保证你的每次查询复杂度为 $O(1)$。若使用更高时间复杂度算法不保证能通过。**

给定一个长度为 $N$ 的数列，和 $ M $ 次询问，求出每一次询问的区间内数字的最大值。

输入格式
第一行包含两个整数 $N,M$，分别表示数列的长度和询问的个数。

第二行包含 $N$ 个整数（记为 $a_i$），依次表示数列的第 $i$ 项。

接下来 $M$ 行，每行包含两个整数 $l_i,r_i$，表示查询的区间为 $[l_i,r_i]$。

输出格式
输出包含 $M$ 行，每行一个整数，依次表示每一次询问的结果。

说明/提示
对于 $30\%$ 的数据，满足 $1\le N,M\le 10$。

对于 $70\%$ 的数据，满足 $1\le N,M\le {10}^5$。

对于 $100\%$ 的数据，满足 $1\le N\le {10}^5$，$1\le M\le 2\times{10}^6$，$a_i\in[0,{10}^9]$，$1\le l_i\le r_i\le N$。

## 解题思路

1. 关键观察：区间最大值满足可重复贡献性质，即 max(a, a) = a，因此可以用两个长度为 2^k 的区间覆盖整个查询区间而不影响答案。
2. 预处理 ST 表：st[k][i] 表示从 i 开始长度为 2^k 的区间最大值。递推式 st[k][i] = max(st[k-1][i], st[k-1][i + 2^(k-1)])，边界为 st[0][i] = a[i]。
3. 预处理对数表 Log[i] = floor(log2(i))，递推 Log[i] = Log[i/2] + 1，用于 O(1) 求区间长度对应的 k。
4. 查询时令 len = r - l + 1，k = Log[len]，答案 = max(st[k][l], st[k][r - 2^k + 1])，两个区间长度均为 2^k 且覆盖 [l, r]。
5. 正确性：两个区间都完全落在 [l, r] 内，且并集覆盖整个区间，因此最大值即为区间最大值。
6. 由于 M 很大，使用快速读入和 printf 输出以保证效率。

## 复杂度分析

- 时间复杂度：预处理 O(N log N)，每次查询 O(1)，总 O(N log N + M)
- 空间复杂度：O(N log N)

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
typedef long long ll;

inline int read()
{
	int x=0,f=1;char ch=getchar();
	while (ch<'0'||ch>'9'){if (ch=='-') f=-1;ch=getchar();}
	while (ch>='0'&&ch<='9'){x=x*10+ch-48;ch=getchar();}
	return x*f;
}

int main(){
    int n=read(),m=read();
    const int LOG=20;
    vector<vector<int>> st(LOG,vector<int>(n+1));
    vector<int> Log(n+1);

    for(int i=1;i<=n;i++){
        st[0][i]=read();
    }

    Log[1]=0;
    for(int i=2;i<=n;i++){
        Log[i]=Log[i/2]+1;
    }

    for(int k=1;k<LOG;k++){
        for(int i=1;i+(1<<k)-1<=n;++i){
            st[k][i]=max(st[k-1][i],st[k-1][i+(1<<(k-1))]);
        }
    }

    while(m--)
    {
        int l = read(), r = read();
        int len = r - l + 1;
        int k = Log[len];
        int ans = max(st[k][l], st[k][r - (1 << k) + 1]);
        printf("%d\n", ans);
    }
    return 0;
}
```

## 复盘备注

易错点：
- 查询时右端点偏移为 r - (1 << k) + 1，注意 +1 不能漏。
- Log 数组需处理 Log[1] = 0，且循环从 2 开始。
- ST 表第二维大小需为 n+1，第一维 LOG 取 20 对 N ≤ 1e5 足够（2^17 > 1e5）。
- 输入输出量大，务必使用快速读入与 printf，避免 cin/cout 超时。
可优化点：
- 可将 st 表按行连续存储以提升缓存命中率，但当前写法已能 AC。
同类题提示：ST 表适用于静态区间可重复贡献问题（最大值、最小值、gcd 等），不支持修改；若需修改可考虑线段树或树状数组。
