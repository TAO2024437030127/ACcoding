## 题目简述

有两堆石子，数量任意，可以不同。游戏开始由两个人轮流取石子。游戏规定，每次有两种不同的取法：一是可以在任意的一堆中取走任意多的石子；二是可以在两堆中同时取走相同数量的石子。最后把石子全部取完者为胜者。现在给出初始的两堆石子的数目，你先取，假设双方都采取最好的策略，问最后你是胜者还是败者。

输入格式
输入共一行。

第一行共两个数 $a, b$，表示石子的初始情况。

输出格式
输出共一行。

第一行为一个数字 $1,0$ 或 $-1$，如果最后你是胜利者则为 $1$；若失败则为 $0$；若结果无法确定则为 $-1$。

说明/提示
**数据范围**

$50\%$ 的数据满足 $a, b \le 1000$；

$100\%$ 的数据满足 $a, b \le 10^9$。

## 解题思路

1. 这是经典威佐夫博弈，必败态（奇异局势）为 (⌊kφ⌋, ⌊kφ²⌋)，其中 φ=(1+√5)/2，k=0,1,2,…，且两数之差 d=⌊kφ²⌋-⌊kφ⌋=k。
2. 因此判断方法：令 mi=min(a,b)、ma=max(a,b)、d=ma-mi，计算 k=⌊d·φ⌋，若 k==mi 则当前为必败态，先手输，输出 0；否则先手胜，输出 1。
3. 正确性依据：威佐夫博弈的奇异局势恰好由 Beatty 序列给出，任意非奇异局势均可一步走到某个奇异局势，而奇异局势之间无法一步互达，故上述判定等价于胜负判定。
4. 实现上用 long double 计算 φ 与 d·φ，并加微小扰动 1e-10 防止浮点下取整误差；d 最大约 10^9，long double 精度足够区分整数边界。

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
typedef long long ll;

int main()
{
    ll a,b;
    cin>>a>>b;
    ll mi = min(a,b);
    ll ma = max(a,b);
    ll d = ma - mi;
    long double phi = (sqrtl(5.0L)+1.0L)/2.0L;
    ll k = (ll)floorl((long double)d * phi + 1e-10L);
    cout << (k == mi ? 0 : 1) << '\n';
    return 0;
}
```

## 复盘备注

易错点：直接 floor(d*φ) 可能因浮点误差把整数边界算小 1，需加 eps 或改用整数/高精度判定；另外输入两数顺序任意，必须先取 min/max。题目输出说明中的 -1 在本题数据下不会出现。
