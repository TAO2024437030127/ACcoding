## 题目简述

约翰有一架用来称牛的体重的天平。与之配套的是 $ N \ ( 1 \leq N \leq 1000 ) $ 个已知质量的砝码（所有砝码质量的数值都在 $32$ 位带符号整数范围内）。

每次称牛时，他都把某头奶牛安置在天平的某一边，然后往天平另一边加砝码，直到天平平衡，于是此时砝码的总质量就是牛的质量（约翰不能把砝码放到奶牛的那边，因为奶牛不喜欢称体重，每当约翰把砝码放到她的蹄子底下，她就会尝试把砝码踢到约翰脸上）。

天平能承受的物体的质量不是无限的，当天平某一边物体的质量大于 $ C \ ( 1 \leq C \leq 2^{30} ) $ 时，天平就会被损坏。砝码按照它们质量的大小被排成一行。并且，这一行中从第 $3$ 个砝码开始，每个砝码的质量至少等于前面两个砝码（也就是质量比它小的砝码中质量最大的两个）的质量的和。

约翰想知道，用他所拥有的这些砝码以及这架天平，能称出的质量最大是多少。由于天平的最大承重能力为 $C$，他不能把所有砝码都放到天平上。

现在约翰告诉你每个砝码的质量，以及天平能承受的最大质量，你的任务是选出一些砝码，使它们的质量和在不压坏天平的前提下是所有组合中最大的。

输入格式
第 $1$ 行输入两个用空格隔开的正整数 $ N $ 和 $ C $。

第 $2$ 到 $ N+1 $ 行：每一行仅包含一个正整数，即某个砝码的质量。保证这些砝码的质量是一个不下降序列。

输出格式
输出一个正整数，表示用所给的砝码能称出的不压坏天平的最大质量。

## 解题思路

1. 由于砝码质量满足类似斐波那契的增长关系，实际能参与选择的砝码数量很少（不超过约 45 个），但题目 N 可达 1000，直接枚举所有子集仍不可行。
2. 采用折半搜索（Meet-in-the-Middle）：将砝码序列分成左右两半，分别 DFS 枚举所有子集和，得到两个数组 l 和 r。
3. 对左半部分的和数组 l 排序，然后遍历右半部分的每个和 sum_r：若 sum_r > C 则跳过；否则在 l 中二分查找不超过 C - sum_r 的最大值，用 sum_r 加上该值更新答案。
4. 正确性：任意一个合法方案可拆分为左半部分选出的子集与右半部分选出的子集，枚举右半部分所有子集并二分左半部分最优搭配，必然覆盖最优解。

## 复杂度分析

- 时间复杂度：O(2^(N/2) log 2^(N/2))，实际因 N 有效规模很小而很快
- 空间复杂度：O(2^(N/2))

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
typedef long long ll;

void dfs(int pos, ll cur, const vector<ll>& w, vector<ll>& res){
    if(pos == w.size()){
        res.push_back(cur);
        return;
    }
    dfs(pos+1, cur, w, res);
    dfs(pos+1, cur + w[pos], w, res);
}

int main(){
    int n;
    ll c;
    cin >> n >> c;
    vector<ll> w(n);
    for(int i = 0; i < n; i++){
        cin >> w[i];
    }

    vector<ll> w_left, w_right;
    int mid = n / 2;
    for(int i = 0; i < mid; i++){
        w_left.push_back(w[i]);
    }
    for(int i = mid; i < n; i++){
        w_right.push_back(w[i]);
    }

    vector<ll> l, r;
    dfs(0, 0, w_left, l);
    dfs(0, 0, w_right, r);

    sort(l.begin(), l.end());
    ll ans = 0;
    for(ll sum_r : r){
        if(sum_r > c) continue;
        ll target = c - sum_r;
        auto it = upper_bound(l.begin(), l.end(), target);
        if(it != l.begin()){
            --it;
            ans = max(ans, sum_r + *it);
        }else{
            ans = max(ans, sum_r);
        }
    }
    cout << ans << endl;
    return 0;
}
```

## 复盘备注

易错点：右半部分和超过 C 时应直接跳过，不能与左半部分组合；二分查找需用 upper_bound 后回退，注意处理左半部分无合法值的情况。可优化点：DFS 时可提前剪枝掉超过 C 的分支，或利用砝码增长性质进一步缩小搜索范围。同类题提示：折半搜索常用于 N 在 40 左右、需要枚举子集和的组合优化问题。
