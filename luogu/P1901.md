## 题目简述

某地有 $N$ 个能量发射站排成一行，每个发射站 $i$ 都有不相同的高度 $H_i$，并能向两边（两端的发射站只能向一边）同时发射能量值为 $V_i$ 的能量，发出的能量只被两边**最近的**比它高的发射站接收。显然，每个发射站发来的能量有可能被 $0$ 或 $1$ 或 $2$ 个其他发射站所接受。

请计算出接收最多能量的发射站接收的能量是多少。

输入格式
第 $1$ 行一个整数 $N$。

第 $2$ 到 $N+1$ 行，第 $i+1$ 行有两个整数 $H_i$ 和 $V_i$，表示第 $i$ 个发射站的高度和发射的能量值。

输出格式
输出仅一行，表示接收最多能量的发射站接收到的能量值。答案不超过 32 位带符号整数的表示范围。

说明/提示
对于 $40\%$ 的数据，$1\le N\le 5000,1\le H_i\le 10^5,1\le V_i\le 10^4$。

对于 $70\%$ 的数据，$1\le N\le 10^5,1\le H_i\le 2\times 10^9,1\le V_i\le 10^4$。

对于 $100\%$ 的数据，$1\le N\le 10^6,1\le H_i\le 2\times 10^9,1\le V_i\le 10^4$。

## 解题思路

关键观察：对每个站 i，它向左发射的能量被左边第一个高度大于 H_i 的站接收，向右发射的能量被右边第一个高度大于 H_i 的站接收。因此问题转化为对每个位置求左右两侧第一个更大元素，并把 V_i 累加到对应站上。

算法选择：单调栈。
1. 从左到右扫描，维护一个高度严格递减的栈（栈中存下标）。当 H[st.top()] <= H[i] 时不断弹出，因为 i 比栈顶高且更靠右，会挡住栈顶向左的视线；弹出后若栈非空，栈顶就是 i 左边第一个比 H_i 高的站，把 V_i 累加到 sum[st.top()]。
2. 清空栈后从右到左同理，处理每个站向右发射的能量，累加到右边第一个更高站。
3. 最后遍历 sum 数组取最大值。

正确性要点：由于高度互不相同，单调栈弹出条件用 <= 或 < 均可；栈中保留的是尚未找到更高站的候选，栈顶恰好是当前元素最近的更高站，因此每次累加都准确对应题目要求的接收关系。

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
typedef long long ll;
const int MAX=1000010;
int H[MAX];
int V[MAX];
ll sum[MAX];
int main(){
    int n;
    cin>>n;
    for(int i=1;i<=n;i++){
        cin>>H[i]>>V[i];
    }
    stack<int> st;
    
    for(int i=1;i<=n;i++){
        while(!st.empty()&&H[st.top()]<=H[i]){
            st.pop();
        }
        if(!st.empty()){
            sum[st.top()]+=V[i];
        }
        st.push(i);
    }
    while(!st.empty()) st.pop();
    for(int i=n;i>=1;i--){
        while(!st.empty()&&H[st.top()]<=H[i]){
            st.pop();
        }
        if(!st.empty()){
            sum[st.top()]+=V[i];
        }
        st.push(i);
    }
    ll max_e=0;
    for(int i=1;i<=n;i++){
        max_e=max(max_e,sum[i]);
    }
    cout<<max_e;
    return 0;
}
```

## 复盘备注

易错点：
- 累加值可能超过 int，sum 数组和答案需用 long long。
- 两次扫描之间必须清空栈，否则会混入上一轮的下标。
- 高度互不相同，但若题目改为可相同，需明确“比它高”是严格大于，弹出条件应相应调整。

同类题提示：单调栈求左右第一个更大/更小元素，如“接雨水”“柱状图中最大矩形”等。
