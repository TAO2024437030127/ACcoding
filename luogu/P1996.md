## 题目简述

$n$ 个人围成一圈，从第一个人开始报数，数到 $m$ 的人出列，再由下一个人重新从 $1$ 开始报数，数到 $m$ 的人再出圈，依次类推，直到所有的人都出圈，请输出依次出圈人的编号。

**注意：本题和《深入浅出-基础篇》上例题的表述稍有不同。书上表述是给出淘汰 $n-1$ 名小朋友，而该题是全部出圈。**

输入格式
输入两个整数 $n,m$。

输出格式
输出一行 $n$ 个整数，按顺序输出每个出圈人的编号。

说明/提示
$1 \le m, n \le 100$

## 样例

### 样例 1

输入：
```text
10 3
```

输出：
```text
3 6 9 2 7 1 8 5 10 4
```

## 解题思路

本题是经典的约瑟夫环问题，数据范围很小（n,m ≤ 100），可以直接模拟。

- 使用 C++ 标准库中的 `std::list` 存储当前仍在圈中的人的编号，初始按 1 到 n 顺序插入。
- 用迭代器 `it` 指向当前报数起点。每次需要数到第 m 个人：从当前位置开始，循环 m-1 次执行 `it++`，若 `it` 到达 `end()` 则回绕到 `begin()`。
- 此时 `it` 指向要出圈的人，输出其编号。
- 删除该元素前，先记录下一个有效位置：令 `it2 = ++it`（此时 `it` 指向被删元素的后一个位置），若 `it2` 为 `end()` 则改为 `begin()`。然后 `num.erase(--it)` 删除当前元素，并将 `it` 更新为 `it2`。
- 重复上述过程直到链表为空。

正确性要点：每次移动时正确处理环形回绕；删除元素后迭代器失效，因此先保存下一个位置再删除；当链表只剩一个元素时，`++it` 会得到 `end()`，回绕逻辑保证 `it2` 指向 `begin()`，删除后链表为空，循环结束。

## 复杂度分析

- 时间复杂度：O(n·m)
- 空间复杂度：O(n)

## 代码

```text
#include<iostream>
#include<list>
using namespace std;
int m,n;
int main(){
    cin>>m>>n;
    list<int> num;
    for(int i=1;i<=m;i++){
        num.push_back(i);
    }
    auto it=num.begin();
    while(!num.empty()){
        for(int i=1;i<n;i++){
            it++;
            if(it==num.end()){
                it=num.begin();
            }
        }
        cout<<*it<<" ";
        auto it2=++it;
        if(it2==num.end()){
            it2=num.begin();
        }
        num.erase(--it);
        it=it2;
    }
}
```

## 复盘备注

易错点：
- 删除元素后原迭代器失效，必须先用 `it2` 保存下一个位置再删除。
- 当 `it` 已经指向最后一个元素时，`++it` 会得到 `end()`，需要回绕到 `begin()`。
- 循环条件用 `while(!num.empty())` 确保所有人出圈，而不是只淘汰 n-1 人。

可优化点：数据范围小，模拟即可；若 n 很大可用递推或树状数组优化，但本题无需。

同类题提示：约瑟夫环的变体（如报数到 m 出圈、求最后幸存者）可用递推公式 f(1)=0, f(i)=(f(i-1)+m)%i 求解最后一人，但本题要求输出完整出圈序列，模拟更直接。
