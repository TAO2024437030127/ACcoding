## 题目简述

自从曹冲搞定了大象以后，曹操就开始琢磨让儿子干些事业，于是派他到中原养猪场养猪，可是曹冲满不高兴，于是在工作中马马虎虎，有一次曹操想知道母猪的数量，于是曹冲想狠狠耍曹操一把。举个例子，假如有 $16$ 头母猪，如果建了 $3$ 个猪圈，剩下 $1$ 头猪就没有地方安家了。如果建造了 $5$ 个猪圈，但是仍然有 $1$ 头猪没有地方去，然后如果建造了 $7$ 个猪圈，还有 $2$ 头没有地方去。你作为曹总的私人秘书理所当然要将准确的猪数报给曹总，你该怎么办？

输入格式
第一行包含一个整数 $n$ —— 建立猪圈的次数，接下来 $n$ 行，每行两个整数 $a_i, b_i$，表示建立了 $a_i$ 个猪圈，有 $b_i$ 头猪没有去处。你可以假定 $a_1 \sim a_n$ 互质。

输出格式
输出包含一个自然数，即为曹冲至少养母猪的数目。

说明/提示
$1 \leq n\le10$，$0 \leq b_i\lt a_i\le100000$，$1 \leq \prod a_i \leq 10^{18}$

## 解题思路

本题是中国剩余定理（CRT）模板题，但代码实际使用了扩展中国剩余定理（EXCRT）的合并思路，兼容模数互质的情形。

1. 维护当前已合并的同余方程：x ≡ ans (mod M)，初始取第一个方程 ans = b_1, M = a_1。
2. 每次加入新方程 x ≡ b_i (mod a_i)，需要解 ans + t·M ≡ b_i (mod a_i)，即 t·M ≡ b_i - ans (mod a_i)。
3. 用扩展欧几里得 exgcd(M, a_i) 求出 g = gcd(M, a_i) 及 M 的逆元系数 x，若 (b_i - ans) 不能被 g 整除则无解（本题保证互质，g=1，必有解）。
4. 用快速乘 qmul 计算 t = x · ((b_i - ans)/g) mod (a_i/g)，避免中间乘积溢出 long long。
5. 更新 ans = ans + t·M，M = M/g·a_i，并对 ans 取模 M 保证非负最小。
6. 全部合并后输出 ans 即为最小自然数解。

正确性要点：每次合并保持 x ≡ ans (mod M) 与已处理方程等价，且新方程被满足；最终 M 为所有模数之积，ans 为模 M 下的唯一解，取最小非负即答案。

## 代码

```cpp
#include<bits/stdc++.h>
using namespace std;
typedef long long ll;

ll exgcd(ll a,ll b,ll &x,ll &y){
    if(b==0){
        x=1;
        y=0;
        return a;
    }
    ll g=exgcd(b,a%b,y,x);
    y-=a/b*x;
    return g;
}

ll qmul(ll a,ll b,ll mod){
    ll res=0;
    while(b){
        if(b&1)res=(res+a)%mod;
        a=(a+a)%mod;
        b>>=1;
    }
    return res;
}

ll inv_exgcd(ll a,ll mod){
    ll x,y;
    exgcd(a,mod,x,y);
    return (x%mod+mod)%mod;
}

ll crt(int n,ll *a,ll *m){
    ll M=1;
    ll ans=0;
    for(int i=1;i<=n;i++){
        M*=m[i];
    }

    for(int i=1;i<=n;i++){
        ll Mi=M/m[i];
        ll ti=inv_exgcd(Mi%m[i],m[i]);
        ans=(ans+qmul(qmul(a[i],Mi,M),ti,M))%M;
    }

    return (ans%M+M)%M;
}

ll excrt(int n,ll *a,ll *m){
    ll M=m[1];
    ll ans=(a[1]%M+M)%M;
    for(int i=2;i<=n;i++){
        ll x,y;
        ll g=exgcd(M,m[i],x,y);
        ll c=((a[i]-ans)%m[i]+m[i])%m[i];
        if(c%g) return -1;
        ll t=qmul(x,c/g,m[i]/g);
        ans+=qmul(t,M,M/g*m[i]);
        M=M/g*m[i];
        ans=(ans%M+M)%M;
    }
    return (ans%M+M)%M;
}


int main(){
    int n;
    cin>>n;
    ll a[15],b[15];
    for(int i=1;i<=n;i++){
        cin>>a[i]>>b[i];
    }
    ll ans=excrt(n,b,a);
    cout<<ans;
    return 0;
}
```

## 复盘备注

易错点：
- 中间乘法可能超过 long long，需用快速乘或 __int128。
- 合并时 c = (b_i - ans) mod a_i 要处理负数。
- 本题模数互质，可直接用标准 CRT，但 EXCRT 写法更通用。
- 输出要求最小自然数，最后需 (ans % M + M) % M。

可优化点：模数互质时可直接用 CRT 公式，省去合并步骤；快速乘可用 __int128 替代。
