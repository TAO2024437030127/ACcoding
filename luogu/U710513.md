## 题目简述

A队和B队是dgut的两支参赛小队，他们外出打比赛时经常一起行动。

但受到各种神秘诅咒的影响，在前往某处地点时，先出发的队伍反而会晚到。

给定两个日期字符串，分别代表两个小队的出发时间，已知**先出发的队伍反而会后到达目的地**。请你判断那支小队先到达目的地

另外，如果某个时间戳不合法，请直接输出 `-1`

输入格式
输入共两行，每行一个日期字符串，格式为"YYYY-MM-DD"

- 第一行：A队的出发时间
- 第二行：B队的出发时间

保证日期字符串格式正确，且不存在两队同时出发的情况

输出格式
- 如果 A 队先到达，输出 `A`
- 如果 B 队先到达，输出 `B`
- 如果某个日期**不合法**，输出 `-1`

说明/提示
在本题中，日期不合法**仅限日期不存在**，例如：

- `2026-02-29`（2026年不是闰年，2月没有29日）
- `2026-99-12`（没有99月）

#### 闰年判断规则

**闰年**：年份能被 4 整除且不能被 100 整除，或者能被 400 整除。

- 闰年的 2 月有 **29** 天
- 平年的 2 月有 **28** 天

## 解题思路

1. 从字符串中按固定位置截取年、月、日，分别用 stoi 转成整数。
2. 合法性检查：月份必须在 1~12；根据闰年规则确定 2 月天数；日必须在 1 到该月天数之间。任一日期不合法直接输出 -1。
3. 比较两个日期：先比年，年不同则年份大者更晚；年相同比月；月相同比日。
4. 关键观察：先出发反而后到达，因此出发日期更晚的队伍先到达。若 A 的日期严格大于 B，则 A 先到达，输出 A；否则输出 B（题目保证不会同时出发）。
5. 正确性要点：日期比较按年→月→日字典序进行，与时间先后一致；合法性检查覆盖了月份越界和日越界两种情况。

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
bool is_run(int y){
    if(y%400==0) return true;
    if(y%100==0) return false;
    if(y%4==0) return true;
    return false;
}
int get_day(string s){
    int d=stoi(s.substr(8,2));
    return d;
}
int get_m(string s){
    int m=stoi(s.substr(5,2));
    return m;
}
int get_year(string s){
    int y=stoi(s.substr(0,4));
    return y;
}
bool vali(int y,int m,int d){
    if(m<1||m>12) return false;
    int m_d[]={0,31,28,31,30,31,30,31,31,30,31,30,31};
    if(is_run(y)) m_d[2]=29;
    if(m_d[m]<d||d<1) return false;
    return true;
}

bool date_c(int ya,int ma,int da,int yb,int mb,int db){
    if(ya!=yb) return ya>yb;
    if(ma!=mb) return ma>mb;
    return da>db;
}
int main(){
    string sa;
    string sb;
    getline(cin,sa);
    getline(cin,sb);
    int ya=get_year(sa);
    int ma=get_m(sa);
    int da=get_day(sa);
    int yb=get_year(sb);
    int mb=get_m(sb);
    int db=get_day(sb);
    if(!vali(ya,ma,da)||!vali(yb,mb,db)){
        cout<<-1<<endl;
        return 0;
    }
    if(date_c(ya,ma,da,yb,mb,db)){
        cout<<"A"<<endl;
    }else{
        cout<<"B"<<endl;
    }
    
    return 0;
}
```
