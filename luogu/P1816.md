## 题目简述

老管家是一个聪明能干的人。他为财主工作了整整 $10$ 年。财主为了让自己账目更加清楚，要求管家每天记 $k$ 次账。由于管家聪明能干，因而管家总是让财主十分满意。

但是由于一些人的挑拨，财主还是对管家产生了怀疑。于是他决定用一种特别的方法来判断管家的忠诚。他把每次的账目按 $1, 2, 3, \ldots$ 编号，然后不定时地问管家这样的问题：在 $a$ 到 $b$ 号账中最少的一笔是多少？

为了让管家没时间作假，他总是一次问多个问题。

输入格式
第一行输入两个数 $m, n$，表示有 $m$ 笔账和 $n$ 个问题。
第二行输入 $m$ 个数，分别表示账目的钱数 $x_i$。
接下来 $n$ 行分别输入 $n$ 个问题，每行 $2$ 个数字，分别表示开始的账目编号 $a$ 和结束的账目编号 $b$。

输出格式
第一行输出每个问题的答案，每个答案中间以一个空格分隔。

说明/提示
对于 $100\%$ 的数据，$1 \leq m \leq 10^5$，$1 \leq n \leq 10^5$，$0 \le x_i \le 10^5$。

## 解题思路

- 关键观察：题目是静态数组的区间最小值查询（RMQ），没有修改操作，适合用 ST 表（Sparse Table）预处理。
- 预处理：st[k][i] 表示从位置 i 开始长度为 2^k 的区间最小值。递推式 st[k][i] = min(st[k-1][i], st[k-1][i+2^(k-1)])，边界为 i+2^k-1 <= n。
- 查询：对于区间 [a,b]，长度 len=b-a+1，取 k=floor(log2(len))，答案 = min(st[k][a], st[k][b-2^k+1])，两个长度为 2^k 的区间覆盖整个查询区间且可能有重叠，最小值不受影响。
- 正确性要点：预处理覆盖所有长度为 2 的幂的区间；查询时两个区间并集覆盖 [a,b]，因此取 min 即为区间最小值。
- 注意代码中变量名与题面相反：代码读入 n 为账目数、m 为询问数，但逻辑正确。

## 复杂度分析

- 时间复杂度：O(m log m + n)（预处理 O(m log m)，每个询问 O(1)）
- 空间复杂度：O(m log m)

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
const int LOG=20;
int main(){
    int m,n;
    cin>>n>>m;
    vector<vector<int>> st(LOG,vector<int>(n+1));
    vector<int> Log(n+1);
    Log[1]=0;
    for(int i=2;i<=n;i++){
        Log[i]=Log[i/2]+1;
    }
    for(int i=1;i<=n;i++){
        cin>>st[0][i];
    }
    for(int k=1;k<LOG;k++){
        for(int i=1;i+(1<<k)-1<=n;i++){
            st[k][i]=min(st[k-1][i],st[k-1][i+(1<<(k-1))]);
        }
    }
    int a,b;
    while(m--){
        cin>>a>>b;
        int len=b-a+1;
        int k=Log[len];
        cout<< min(st[k][a], st[k][b - (1 << k) + 1])<<" ";
    }
    return 0;
}
```

## 复盘备注

易错点：
- 输入顺序：题面第一行是 m,n（账目数、询问数），代码中读入为 n,m，需注意变量含义。
- 预处理循环边界 i+(1<<k)-1<=n，避免越界。
- 查询时 b-(1<<k)+1 可能等于 a，需保证下标有效。
- 输出格式：每个答案后跟空格，行末空格通常可接受。
可优化点：
- 可用快速读入/输出提升 I/O 效率。
- 若内存紧张，可只存 log 表与 ST 表，已足够。
