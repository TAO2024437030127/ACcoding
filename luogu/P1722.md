## 题目简述

usqwedf 改编系列题。

如果你在百忙之中抽空看题，请自动跳到第六行。

众所周知，在中国古代算筹中，红为正，黑为负……

给定一个 $1\times 2n$ 的矩阵（usqwedf：这不是一个 $2n$ 的队列么），现让你自由地放入红色算筹和黑色算筹，使矩阵平衡（即 $\forall i \in[1, 2n]$，$1\sim i$ 格中红色算筹个数大于等于黑色算筹）。

问有多少种方案满足矩阵平衡（注意红色算筹和黑色算筹的数量必须相等）。

输入格式
正整数 $n$。

输出格式
方案数 $t$ 对 $100$ 取模后的结果。

说明/提示
样例解释：

- 方案一：红，黑，红，黑

- 方案二：红，红，黑，黑

数据范围：

$1\le n\le 100$

## 解题思路

将问题转化为括号序列计数：红筹视为左括号，黑筹视为右括号，要求任意前缀左括号数 ≥ 右括号数，最终左右各 n 个。

- 设 dp[i][j] 表示前 i 个位置中放了 j 个红筹的方案数（则黑筹数为 i-j）。
- 初始 dp[0][0]=1。
- 转移：在第 i+1 位放红筹，则 dp[i+1][j+1] += dp[i][j]；放黑筹需满足当前红筹数 j 不少于黑筹数 i-j，即 j ≥ i-j，此时 dp[i+1][j] += dp[i][j]。
- 所有加法对 100 取模。
- 最终答案为 dp[2n][n]，即前 2n 位恰有 n 个红筹且全程合法的方案数。

正确性要点：状态完整记录了已处理位置数与红筹数，转移枚举下一位的两种选择并强制前缀约束，因此不重不漏地统计了所有合法序列。

## 复杂度分析

- 时间复杂度：O(n^2)
- 空间复杂度：O(n^2)

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
typedef long long ll;
const int mod=100;
int main(){
    int n;
    cin>>n;
    vector<vector<int>> dp(2*n+1,vector<int>(2*n+1,0));
    dp[0][0]=1;
    for(int i=0;i<2*n;i++){
        for(int j=0;j<=i;j++){
            if(dp[i][j]==0)continue;
            dp[i+1][j+1]=(dp[i+1][j+1]+dp[i][j])%mod;
            if(j>=(i+1-j)){
                dp[i+1][j]=(dp[i+1][j]+dp[i][j])%mod;
            }
        }
    }
    cout<<dp[2*n][n]<<endl;
    return 0;
}
```

## 复盘备注

易错点：放黑筹的合法性判断是 j ≥ i-j（当前红筹数不少于黑筹数），而不是放完后判断；取模 100 要在每次累加时进行。
可优化点：dp 只依赖上一行，可用滚动数组将空间降至 O(n)。
同类题：卡特兰数计数（如合法括号序列、出栈序列），本题答案即第 n 个卡特兰数模 100。
