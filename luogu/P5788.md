## 题目简述

模板题，无背景。

2019.12.12 更新数据，放宽时限，现在不再卡常了。

给出项数为 $n$ 的整数数列 $a_{1 \dots n}$。

定义函数 $f(i)$ 代表数列中第 $i$ 个元素之后第一个大于 $a_i$ 的元素的**下标**，即 $f(i)=\min_{i<j\leq n, a_j > a_i} \{j\}$。若不存在，则 $f(i)=0$。

试求出 $f(1\dots n)$。

输入格式
第一行一个正整数 $n$。

第二行 $n$ 个正整数 $a_{1\dots n}$。

输出格式
一行 $n$ 个整数表示 $f(1), f(2), \dots, f(n)$ 的值。

说明/提示
【数据规模与约定】

对于 $30\%$ 的数据，$n\leq 100$；

对于 $60\%$ 的数据，$n\leq 5 \times 10^3$ ；

对于 $100\%$ 的数据，$1 \le n\leq 3\times 10^6$，$1\leq a_i\leq 10^9$。

## 解题思路

1. 关键观察：要求的是“右侧第一个更大元素”，具有单调性——若某个位置 j 在 i 的右侧且 a[j] ≤ a[i]，那么 j 不可能成为 i 的答案，也不可能成为 i 左侧更小元素的答案（因为 i 更靠左且更大）。
2. 因此维护一个下标栈，栈中下标对应的元素值从栈底到栈顶单调不增（实际实现为严格递减或非递增均可，因为遇到相等时不弹出）。
3. 从左到右扫描 i：当栈非空且 a[i] > a[栈顶] 时，说明 i 就是栈顶位置右侧第一个更大元素，弹出栈顶并记录 res[栈顶] = i；重复直到不满足条件。
4. 将当前下标 i 压栈。扫描结束后仍在栈中的位置右侧没有更大元素，res 保持初始值 0。
5. 正确性：每个位置只入栈一次、出栈一次；出栈时赋值的是第一个满足条件的 i，因为更早的更大元素若存在会先使该位置出栈。

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 代码

```text
#include<iostream>
#include<stack>
#include<vector>
using namespace std;
int main(){
    int n;
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin>>n;
    vector<int> num(n+1);
    vector<int> res(n+1,0);
    for(int i=1;i<=n;i++){
        cin>>num[i];
    }
    stack<int> st;
    for(int i=1;i<=n;i++){
        while(!st.empty()&&num[i]>num[st.top()]){
            res[st.top()]=i;
            st.pop();
        }
        st.push(i);
    }
    for(int i=1;i<=n;i++){
        cout<<res[i]<<" ";
    }
    return 0;
}
```

## 复盘备注

易错点：比较应为严格大于（a[i] > a[栈顶]），相等时不能弹出；答案存的是下标而非值；n 可达 3×10^6，需用快速输入输出并避免递归。可优化点：可用数组模拟栈减少 STL 开销，但本题已放宽时限。同类题：下一个更大元素、柱状图中最大矩形、接雨水等单调栈应用。
