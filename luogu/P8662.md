## 题目简述

你有一张某海域 $N \times N$ 像素的照片，`.` 表示海洋、 `#` 表示陆地，如下所示：

```
.......
.##....
.##....
....##.
..####.
...###.
.......
```

其中 "上下左右" 四个方向上连在一起的一片陆地组成一座岛屿。例如上图就有 $2$ 座岛屿。

由于全球变暖导致了海面上升，科学家预测未来几十年，岛屿边缘一个像素的范围会被海水淹没。具体来说如果一块陆地像素与海洋相邻（上下左右四个相邻像素中有海洋），它就会被淹没。

例如上图中的海域未来会变成如下样子：

```
.......
.......
.......
.......
....#..
.......
.......
```

请你计算：依照科学家的预测，照片中有多少岛屿会被完全淹没。

输入格式
第一行包含一个整数 $N$。$(1 \le N \le 1000)$。

以下 $N$ 行 $N$ 列代表一张海域照片。

照片保证第 $1$ 行、第 $1$ 列、第 $N$ 行、第 $N$ 列的像素都是海洋。

输出格式
一个整数表示答案。

说明/提示
时限 1 秒, 256M。蓝桥杯 2018 年第九届省赛

```text
1
```

## 解题思路

1. 遍历所有格子，对每个未访问的 '#' 启动 DFS，标记同一岛屿的所有陆地。
2. 在 DFS 过程中，对每个陆地格子检查其上下左右四个邻居：若存在 '.'，说明该格子会被淹没；若某个格子四个邻居全是 '#'，说明该格子不会被淹没，即该岛屿至少有一个像素存活。
3. 用全局布尔变量 has_survive 记录当前岛屿是否存在不会被淹没的像素：初始为 false，DFS 中一旦发现四邻全为 '#' 的格子就置为 true。
4. 每次 DFS 结束后，若 has_survive 仍为 false，说明该岛屿所有像素都临海，会被完全淹没，答案加一。
5. 正确性要点：岛屿由四连通陆地构成，DFS 恰好遍历一个连通块；判断完全淹没等价于该连通块中不存在四邻全为陆地的像素，因为只要有一个内部像素不临海，它就会保留下来。

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
const int MAX=1005;
int dx[]={1,-1,0,0};
int dy[]={0,0,1,-1};

char mp[MAX][MAX];
bool vis[MAX][MAX];
int n;
bool has_survive; 

void dfs(int x,int y){
    vis[x][y]=true;
    bool ok=true;
    for(int i=0;i<4;i++){
        int nx=x+dx[i];
        int ny=y+dy[i];
        if(mp[nx][ny]=='.'){
            ok=false;
        }
    }
    if(ok) has_survive=true;

    for(int i=0;i<4;i++){
        int nx=x+dx[i];
        int ny=y+dy[i];
        if(!vis[nx][ny]&&mp[nx][ny]=='#'){
            dfs(nx,ny);
        }
    }
}

int main(){
    cin>>n;
    for(int i=1;i<=n;i++){
        for(int j=1;j<=n;j++){
            cin>>mp[i][j];
        }
    }
    int ans=0;
    for(int i=1;i<=n;i++){
        for(int j=1;j<=n;j++){
            if(mp[i][j]=='#'&&!vis[i][j]){
                has_survive=false;
                dfs(i,j);
                if(!has_survive){
                    ans++;
                }
            }
        }
    }
    cout<<ans<<endl;
    return 0;
}
```

## 复盘备注

易错点：
- 判断像素是否被淹没时，应检查其四邻是否有海洋，而不是只检查当前像素本身。
- 全局变量 has_survive 必须在每个新岛屿开始 DFS 前重置为 false。
- 照片边界保证是海洋，因此 DFS 中访问邻居时不会越界，无需额外边界判断。
- 输入按字符读取时注意不要读入换行符，使用 cin >> mp[i][j] 可自动跳过空白字符。
同类题提示：网格连通块 + 状态统计类问题，常用 DFS/BFS 遍历连通块并在过程中维护额外信息。
