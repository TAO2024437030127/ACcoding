## 题目简述

输入 $n$ 个数字 $a_i$，输出这些数字中第 $k$ 小的数。最小的数是第 $0$ 小。

请尽量不要使用 `nth_element` 来写本题，因为本题的重点在于练习分治算法。

输入格式
第一行有两个整数，分别表示 $n$ 和 $k$。

第二行有 $n$ 个整数，第 $i$ 个数表示 $a_i$。

输出格式
一个整数，表示第 $k$ 小的数。

说明/提示
对于 $100\%$ 的数据，$1\le a_i<{10}^9$，$1 \le n < 5\times 10^6$，$0 \le k < n$，且 $n$ 为奇数。

## 解题思路

采用快速选择（Quick Select）算法，本质是分治思想：
1. 在区间 [l, r] 中随机选取一个基准值 pivot，并将其交换到区间左端，避免有序数据导致退化。
2. 使用双指针挖坑法进行划分：j 从右向左找小于 pivot 的元素填入左坑，i 从左向右找大于 pivot 的元素填入右坑，最终 i==j 的位置放入 pivot。
3. 划分后 pivot 的最终位置 pos 满足：pos 左侧元素均 ≤ pivot，右侧元素均 ≥ pivot。
4. 若 pos == k，则 a[pos] 即为第 k 小；若 pos > k，说明目标在左半区间，令 r = pos - 1；否则令 l = pos + 1。
5. 使用 while 循环迭代缩小区间，而非递归，避免栈溢出风险。
正确性要点：每次划分后，pivot 的位置是确定的，且左侧元素都不大于它、右侧元素都不小于它，因此可以根据 k 与 pos 的关系安全地丢弃一半区间，逐步逼近目标。

## 复杂度分析

- 时间复杂度：期望 O(n)，最坏 O(n^2)（随机化后概率极低）
- 空间复杂度：O(n)（存储数组），额外空间 O(1)

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
const int MAXN = 5e6 + 10;
int a[MAXN];

int quick_select(int l, int r, int k)
{
    while(l <= r)
    {
        // 随机基准
        int rd = rand() % (r - l + 1) + l;
        swap(a[l], a[rd]);
        int pivot = a[l];
        int i = l, j = r;
        while(i < j)
        {
            while(i < j && a[j] >= pivot) j--;
            a[i] = a[j];
            while(i < j && a[i] <= pivot) i++;
            a[j] = a[i];
        }
        a[i] = pivot;
        int pos = i;
        if(pos == k) return a[pos];
        else if(pos > k)
            r = pos - 1;
        else
            l = pos + 1;
    }
    return -1;
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    srand((unsigned)time(NULL));
    int n, k;
    cin >> n >> k;
    for(int i = 0; i < n; i++)
        cin >> a[i];
    cout << quick_select(0, n - 1, k);
    return 0;
}
```

## 复盘备注

易错点：
- 划分时内层 while 条件必须带 i < j，防止越界。
- 挖坑法中 a[i] = a[j] 和 a[j] = a[i] 的顺序不能颠倒，最后要 a[i] = pivot。
- k 是从 0 开始计数的，直接与 pos 比较即可，无需减 1。
- 随机化种子只需设置一次，放在 main 中即可。
可优化点：
- 输入量很大，已使用 ios::sync_with_stdio(false) 和 cin.tie(nullptr) 加速。
- 若担心 rand() 质量，可使用 mt19937 或手动实现随机数。
同类题提示：快速选择也常用于求第 k 大、中位数等问题，核心都是划分后根据位置缩小区间。
