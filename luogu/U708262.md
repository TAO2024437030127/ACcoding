## 题目简述

MBTI 知识在解密动物园里属于最深奥的知识，可是猫猫却以全对的成绩出色的完成了考核。于是，超级超级超级超聪明的章鱼把猫猫拉进神秘的地下组织。

他们到达地下组织门口的时候，超级超级超级超聪明的章鱼不小心睡着了，所以猫猫需要自己打开地下组织的大门。

给定一个锁和 $k$ 把钥匙。锁和每一把钥匙都表示为一个包含 $n$ 行、$m$ 列的 01 网格。

在锁的网格中：

- 0 表示该位置是空的；
- 1 表示该位置不是空的。

在钥匙的网格中：

- 1 表示该位置存在钥匙的一部分；
- 0 表示该位置是空的。

使用一把钥匙时，钥匙与锁的左上角对齐，并直接比较两个网格中位置相同的格子。钥匙不能平移、旋转或翻转。

如果一把钥匙中所有值为 1 的位置，恰好与锁中所有值为 0 的位置完全相同，那么这把钥匙可以打开锁。

换句话说，对于每一个位置 $(i,j)$，锁和钥匙在该位置的数字必须不同。

给出的 $k$ 把钥匙两两不同，其中恰好有一把能够打开锁。请输出这把钥匙的编号。

输入格式
第一行输入三个整数 $n,m,k$（$1\le n,m\le 100$，$1\le k\le\min(100,2^{n\times m})$），分别表示网格的行数、列数和钥匙的数量。

接下来 $n$ 行，每行输入一个长度为 $m$ 且仅由 `0` 和 `1` 组成的字符串，表示锁的网格。

随后依次输入 $k$ 把钥匙。每把钥匙包含 $n$ 行，每行输入一个长度为 $m$ 且仅由 `0` 和 `1` 组成的字符串。

输入中相邻两把钥匙之间没有额外的分隔符。

保证给出的 $k$ 把钥匙两两不同，且其中恰好有一把能够打开锁。

输出格式
输出一个整数，表示能够打开锁的钥匙编号。

钥匙按照输入顺序从 $1$ 开始编号。

## 解题思路

1. 读入锁网格，用二维数组或字符串保存每个格子的 0/1 值。
2. 依次读入 k 把钥匙，每把钥匙读入后立即与锁逐格比较。
3. 对每个位置 (i,j)，若 key[i][j] == lock[i][j]，说明该钥匙不满足“每个位置数字都不同”的条件，标记失败并停止比较该钥匙。
4. 若某把钥匙所有位置都满足 key[i][j] != lock[i][j]，则它就是答案，直接输出当前编号并结束程序。
5. 由于题目保证恰好有一把钥匙能开锁，循环中一定能提前返回，无需处理无解情况。
正确性要点：条件“所有值为 1 的位置恰好与锁中所有值为 0 的位置完全相同”等价于每个格子锁与钥匙的值不同，因此逐格比较 key[i][j] == lock[i][j] 即可判定失败。

## 代码

```text
#include<bits/stdc++.h>
using namespace std;

int main(){
    int n,m,k;
    cin>>n>>m>>k;
    vector<vector<int>> lock(n,vector<int>(m));
    string s;
    for(int i=0;i<n;i++){
        cin>>s;
        for(int j=0;j<m;j++){
            lock[i][j]=s[j]-'0';
        }
    }

    for(int id=1;id<=k;id++){
        vector<vector<int>> key(n,vector<int>(m));
        for(int i=0;i<n;i++){
            cin >> s;
            for(int j=0;j<m;j++){
                key[i][j]=s[j]-'0';
            }
        }
        bool ok = true;
        for(int i=0;i<n && ok;i++){
            for(int j=0;j<m;j++){
                if(key[i][j]==lock[i][j]){
                    ok=false;
                    break;
                }
            }
        }
        if(ok){
            cout<<id;
            return 0;
        }
    }
    return 0;
}
```

## 复盘备注

易错点：比较条件应为“不同”才合法，不要写成相同；找到答案后可直接 return 0，避免继续读入。可优化点：锁可以按行存成字符串，比较时直接逐字符判断，减少二维数组开销；也可把每把钥匙读成字符串后与锁字符串逐位异或判断。同类题提示：网格逐格匹配类问题，注意对齐方式、是否允许变换以及“恰好互补”与“完全相同”的区别。
