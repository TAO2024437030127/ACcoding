## 题目简述

给定一个 $1 \sim n$ 的排列 $p$，构建其笛卡尔树。

即构建一棵二叉树，满足：

1. 每个节点的编号满足二叉搜索树的性质。
2. 节点 $i$ 的权值为 $p_i$，每个节点的权值满足小根堆的性质。

输入格式
第一行一个整数 $n$。

第二行一个排列 $p_{1 \dots n}$。

输出格式
设 $l_i,r_i$ 分别表示节点 $i$ 的左右儿子的编号（若不存在则为 $0$）。

一行两个整数，分别表示 $\operatorname{xor}_{i = 1}^n i \times (l_i + 1)$ 和 $\operatorname{xor}_{i = 1}^n i \times (r_i + 1)$。

说明/提示
【样例解释】

| $i$ | $l_i$ | $r_i$ |
| :-: | :-: | :-: |
| $1$ | $0$ | $0$ |
| $2$ | $1$ | $4$ |
| $3$ | $0$ | $0$ |
| $4$ | $3$ | $5$ |
| $5$ | $0$ | $0$ |

【数据范围】

对于 $30\%$ 的数据，$n \le 10^3$。

对于 $60\%$ 的数据，$n \le 10^5$。

对于 $80\%$ 的数据，$n \le 10^6$。

对于 $90\%$ 的数据，$n \le 5 \times 10^6$。

对于 $100\%$ 的数据，$1 \le n \le 10^7$。

## 解题思路

1. 关键观察：笛卡尔树中，节点编号天然满足 BST 性质（左子树编号小于根，右子树编号大于根），因此只需按编号顺序插入节点，并维护小根堆性质。
2. 使用单调栈维护当前“最右链”：栈中节点编号递增，且对应权值也递增（小根堆性质）。
3. 依次处理 i=1..n：弹出栈顶所有权值大于 a[i] 的节点，最后一个被弹出的节点成为 i 的左儿子（因为它在 i 左侧且权值更大，应挂在 i 的左子树）；若栈非空，则栈顶节点成为 i 的右儿子（i 是其右子树中编号最小的节点）；否则 i 成为新的根。
4. 将 i 入栈。由于每个节点最多入栈、出栈一次，总复杂度 O(n)。
5. 正确性要点：栈中始终维护从根到当前最右节点的路径，弹出操作保证小根堆性质，左右儿子赋值保证 BST 性质。

- 时间复杂度：O(n)

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
typedef long long ll;
const int MAXN=1e7+10;
int a[MAXN],ls[MAXN],rs[MAXN],stk[MAXN];
int n;
int build_cartesian(int n){
    int top=0;
    int root=0;
    for(int i=1;i<=n;i++){
        ls[i]=rs[i]=0;
        int last=0;
        while(top&&a[stk[top]]>a[i]){
            last=stk[top--];
        }
        ls[i]=last;
        if(top)rs[stk[top]]=i;
        else root=i;
        stk[++top]=i;
        
    }
    return root;
}


int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin>>n;
    for(int i=1;i<=n;i++){
        cin>>a[i];
    }
    int root=build_cartesian(n);
    ll ans1=0,ans2=0;
    for(int i=1;i<=n;i++){
        ans1^=1LL*i*(ls[i]+1);
        ans2^=1LL*i*(rs[i]+1);
    }
    cout<<ans1<<" "<<ans2;
    return 0;
}
```

## 复盘备注

易错点：
- 弹出循环条件为 a[stk[top]] > a[i]（严格大于），因为排列中权值互异，等于不会出现。
- 当栈为空时，i 成为根，需更新 root。
- 答案使用 long long 防止 i*(l_i+1) 溢出（n 可达 10^7，乘积约 10^14）。
- 输入输出量大，需关闭同步或使用快读。
可优化点：
- 数组大小 MAXN 需略大于 10^7，避免越界。
- 可边建树边计算异或和，但需注意左右儿子可能后续被修改，因此建完再统一计算更安全。
同类题提示：笛卡尔树常用于 RMQ 问题、直方图最大矩形等，单调栈建树是标准 O(n) 方法。
