## 题目简述

服务器好好玩。

lcy0x1 去服务器的系统商店买东西。

一个人的背包有 $21$ 格。

一开始他的背包里有 $m$ 件不同的物品（**不能卖**）。

他要买 $n$ 种物品，第 $i$ 件物品的名字为 $st_i$，有 $a_i$ 件，单件价值为 $b_i$，一格可以放 $c_i$ 件。

相同的物品可以放同一格（只要没放满）。

问：他一次最多能买多少钱的物品。

输入格式
第一行两个整数 $m,n$。

下面 $n$ 行，第 $i+1$ 行三个整数 $a_i,b_i,c_i$ 与一个字符串 $st_i$。

输出格式
买入物品的最高价值总和 $s$。

说明/提示
数据保证：

- $0\leq m\leq 21$；
- $0\leq n\leq 100$；
- $0\leq a_i\leq 1344$；
- $0\leq b_i\leq 10^4$；
- $0<c_i\leq 64$；
- $0<|st_i|<100$；
- $0\leq s\leq 10^6$。

**注：数据强大，搜索 $0$ 分，请使用多重背包。**

## 解题思路

1. 先读入 m、n，可用格子数为 cap = max(0, 21-m)。
2. 用哈希表按物品名合并同名记录：数量累加，单价和每格容量沿用第一次出现的值。
3. 对每种物品，最多能放入的件数为 min(a_i, cap*c_i)，因为总格数只有 cap。
4. 把“买 k 件该物品”看成一个决策：占用格子数为 ceil(k/c_i)，获得价值为 k*b_i。由于同种物品可以分散到多格，且每格容量为 c_i，所以对 k 从 1 到上限枚举即可。
5. 做分组背包：dp[j] 表示恰好/至多使用 j 格时的最大价值。外层枚举物品，内层倒序枚举格子数 j，再枚举购买件数 k，用 dp[j-cost] + k*b 更新 dp[j]。倒序保证每种物品只选一次。
6. 最终答案是 dp[0..cap] 中的最大值。

## 复杂度分析

- 时间复杂度：O(n * cap * max_k)，其中 max_k ≤ cap*c_i，最坏约为 O(n * cap^2 * c)，cap ≤ 21，实际很小
- 空间复杂度：O(cap + n)，cap ≤ 21

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
typedef long long ll;
struct Item{
    int a,b,c;
};
int main(){
    int n,m;
    cin>>m>>n;
    int cap=max(0,21-m);
    unordered_map<string,Item> mp;
    for(int i=1;i<=n;i++){
        int aa,bb,cc;
        string s;
        cin>>aa>>bb>>cc>>s;
        if(mp.count(s)){
            mp[s].a+=aa;
        }else{
            mp[s]={aa,bb,cc};
        }
        
    }
    vector<Item> items;
    for(auto &p:mp){
        items.push_back(p.second);
    }
    vector<int> dp(cap+1,0);
    for(auto &it:items){
        int a=it.a;
        int b=it.b;
        int c=it.c;
        int lim=min(a,cap*c);
        for(int j=cap;j>=0;j--){
            for(int k=1;k<=lim;k++){
                int cost=(k+c-1)/c;
                if(j>=cost){
                    dp[j]=max(dp[j],dp[j-cost]+k*b);
                }
            }
        }
    }
    int ans=0;
    for(auto &x:dp){
        ans=max(ans,x);
    }
    cout<<ans;
    return 0;
}
```

## 复盘备注

易错点：
- 初始 m 件物品不能卖，只影响可用格子数，不要计入价值。
- 同名物品必须合并数量，但单价和每格容量取第一次出现的值。
- 枚举 k 时上限要同时受 a_i 和 cap*c_i 限制。
- 内层 j 必须倒序，否则同种物品会被重复选择。
- 计算占用格子数用 (k+c-1)/c 向上取整。
可优化点：
- 可以把每种物品按“每格最多 c_i 件”拆成若干组，但当前 cap 很小，直接枚举 k 已足够。
- 也可用多重背包二进制拆分，但本题数据规模下没有必要。
