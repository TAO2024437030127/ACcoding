## 题目简述

一个含有 $n$ 项的数列，求出每一项前的 $m$ 个数到它这个区间内的最小值。若前面的数不足 $m$ 项则从第 $1$ 个数开始，若前面没有数则输出 $0$。

输入格式
第一行两个整数，分别表示 $n$，$m$。

第二行，$n$ 个正整数，为所给定的数列 $a_i$。

输出格式
$n$ 行，每行一个整数，第 $i$ 个数为序列中 $a_i$ 之前 $m$ 个数的最小值。

说明/提示
对于 $100\%$ 的数据，保证 $1\le m\le n\le2\times10^6$，$1\le a_i\le3\times10^7$。

## 解题思路

本题是滑动窗口最小值的经典问题，使用单调队列（双端队列 deque）维护候选最小值的下标。

- 队列中存储的是数组下标，并保证这些下标对应的数值从队头到队尾单调递增。
- 对于每个位置 i（从 0 开始），先输出答案：若队列为空说明前面没有数，输出 0；否则队头下标对应的 num 值就是当前窗口的最小值。
- 然后将 num[i] 加入队列：不断从队尾弹出比 num[i] 大的元素，保证单调性，再把 i 压入队尾。
- 最后维护窗口左边界：若队头下标 ≤ i-m，说明它已经不在下一个位置 i+1 的窗口 [i-m+1, i] 内，弹出队头。
- 由于每个下标最多入队、出队一次，总操作次数为 O(n)。

正确性要点：单调队列的队头始终是当前窗口内最小元素的下标；在输出第 i 个答案时，队列中保存的是下标 ≤ i-1 且尚未过期的元素，且已按值单调递增，因此队头即为所求。

## 代码

```text
#include<iostream>
#include<vector>
#include<deque>
using namespace std;
int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n,m;
    cin>>n>>m;
    vector<int> num(n);
    for(int i=0;i<n;i++){
        cin>>num[i];
    }
    deque<int> q;
    for(int i=0;i<n;i++){
        if(q.empty()){
            cout<<0<<endl;
        }else{
            cout<<num[q.front()]<<endl;
        }
        while(!q.empty()&&num[i]<num[q.back()]){
            q.pop_back();
        }
        q.push_back(i);
        while(!q.empty()&&q.front()<=i-m){
            q.pop_front();
        }
    }
    return 0;
}
```

## 复盘备注

易错点：
- 输出答案与更新队列的顺序：必须先输出当前答案，再把 a_i 入队，因为题目要求的是 a_i 之前的数。
- 窗口过期条件为 q.front() <= i - m，注意下标从 0 开始时的边界。
- 使用 endl 会频繁刷新缓冲区，在 n 很大时可能较慢，建议改用 '\n'。
- 输入量较大，需关闭同步并解绑 cin/cout。

可优化点：
- 用数组模拟双端队列（手写队列）可进一步减少常数。
- 输出用 '\n' 替代 endl。
