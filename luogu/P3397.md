## 题目简述

[加强版](/problem/P13787)

在 $n\times n$ 的格子上有 $m$ 个地毯。

给出这些地毯的信息，问每个点被多少个地毯覆盖。

输入格式
第一行，两个正整数 $n,m$。意义如题所述。

接下来 $m$ 行，每行两个坐标 $(x_1,y_1)$ 和 $(x_2,y_2)$，代表一块地毯，左上角是 $(x_1,y_1)$，右下角是 $(x_2,y_2)$。

输出格式
输出 $n$ 行，每行 $n$ 个正整数。

第 $i$ 行第 $j$ 列的正整数表示 $(i,j)$ 这个格子被多少个地毯覆盖。

## 解题思路

本题是二维差分模板题，直接对每个矩形逐格加一会达到 O(n²m)，在 n,m≤1000 时不可行。

关键观察：矩形区域加一、最后统一查询每个点的值，适合用二维差分。

做法：
1. 开差分数组 diff（大小 (n+2)×(n+2)）。对每个矩形 (x1,y1)-(x2,y2)，执行四个角修改：diff[x1][y1]++，diff[x1][y2+1]--，diff[x2+1][y1]--，diff[x2+1][y2+1]++。
2. 对 diff 做二维前缀和还原：cnt[i][j] = diff[i][j] + cnt[i-1][j] + cnt[i][j-1] - cnt[i-1][i-1]，得到每个格子的实际覆盖数。
3. 按行输出 cnt。

正确性要点：二维差分中四个角修改使得矩形内部每个格子的前缀和恰好增加 1，矩形外抵消为 0；前缀和递推利用容斥原理，逐格累加左上区域，保证每个位置等于所有覆盖它的矩形数量。

## 复杂度分析

- 时间复杂度：O(n² + m)
- 空间复杂度：O(n²)

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
int main(){
    int n,m,x1,y1,x2,y2;
    cin>>n>>m;
    vector<vector<int>> cnt(n+1,vector<int>(n+1,0));
    vector<vector<int>> diff(n+2,vector<int>(n+2,0));
    for(int i=1;i<=m;i++){
        cin>>x1>>y1>>x2>>y2;
        diff[x1][y1]++;
        diff[x1][y2+1]--;
        diff[x2+1][y1]--;
        diff[x2+1][y2+1]++;
    }
    for(int i=1;i<=n;i++){
        for(int j=1;j<=n;j++){
            cnt[i][j]=diff[i][j]+cnt[i-1][j]+cnt[i][j-1]-cnt[i-1][j-1];
        }
    }
    for(int i=1;i<=n;i++){
        for(int j=1;j<=n;j++){
            cout<<cnt[i][j]<<" ";
        }
        cout<<endl;
    }
    return 0;
}
```

## 复盘备注

易错点：
- 差分数组需要开到 (n+2)×(n+2)，因为 x2+1、y2+1 可能等于 n+1。
- 四个角修改的符号不要写反：左上 +1，右上、左下 -1，右下 +1。
- 前缀和递推时注意容斥减去的项是 cnt[i-1][j-1]。

可优化点：
- 输出量较大，可用 printf 或关闭同步的 cin/cout；本题数据量下通常足够。
