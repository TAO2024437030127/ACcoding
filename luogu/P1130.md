## 题目简述

某地临时居民想获得长期居住权就必须申请拿到红牌。获得红牌的过程是相当复杂 ，一共包括 $N$ 个步骤。每一步骤都由居委会的某个工作人员负责检查你所提交的材料是否符合条件。为了加快进程，每一步居委会都派了 $M$ 个工作人员来检查材料。不幸的是，并不是每一个工作人员效率都很高。尽管如此，为了体现“公开”的政策，居委会部门把每一个工作人员的处理一个申请所花天数都对外界公开。

为了防止所有申请人都到效率高的工作人员去申请。这 $M \times N$ 个工作人员被分成 $M$ 个小组。每一组在每一步都有一个工作人员。申请人可以选择任意一个小组也可以更换小组。但是更换小组是很严格的，一定要相邻两个步骤之间来更换，而不能在某一步骤已经开始但还没结束的时候提出更换，并且也只能从原来的小组 $I$ 更换到小组 $I+1$，当然从小组 $M$ 可以更换到小组 $1$。对更换小组的次数没有限制。

例如：下面是 $3$ 个小组，每个小组 $4$ 个步骤工作天数：

- 小组 $1$： $2, 6 ,1 ,8$；
- 小组 $2$：$3,6, 2, 6$；
- 小组 $3$：$ 4, 2 ,3 ,6$。

例子中，可以选择小组 $1$ 来完成整个过程一共花了$2+6+1+8=17$ 天，也可以从小组 $2$ 开始第一步，然后第二步更换到小组 $3$，第三步到小组 $1$，第四步再到小组 $2$，这样一共花了 $3+2+1+6=12$ 天。你可以发现没有比这样效率更高的选择。

你的任务是求出完成申请所花最少天数。

输入格式
第一行是两个正整数 $N$ 和 $M$，表示步数和小组数。

接下来有 $M$ 行，每行有 $N$ 个非负整数，第 $i+1(1 \le i \le M)$ 行的第 $j$ 个数表示小组 $i$ 完成第 $j$ 步所花的天数，天数都不超过 $100000$。

输出格式
一个正整数，为完成所有步所需最少天数。

说明/提示
对于 $100\%$ 的数据，$1\le N,M \le 2000$，矩阵的每个数字不超过 $100000$。

## 解题思路

设 dp[j][i] 表示完成前 j 步且第 j 步由小组 i 完成时的最小总天数。

- 初始：第 1 步没有前置步骤，dp[1][i] = num[i][1]。
- 转移：第 j 步选小组 i 时，上一步只能是同一小组 i，或从 i-1 换过来（i=1 时从 M 换过来）。因此 dp[j][i] = min(dp[j-1][i], dp[j-1][prei]) + num[i][j]，其中 prei = i-1（i>1）或 M（i=1）。
- 最终答案：完成第 N 步后可能停在任意小组，取 min(dp[N][i])。

正确性要点：每一步的小组选择只影响下一步可选的来源，状态完整刻画了“当前步骤 + 当前小组”，转移枚举了所有合法前驱，因此覆盖全部合法方案。

## 复杂度分析

- 时间复杂度：O(NM)
- 空间复杂度：O(NM)

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
typedef long long ll;
const ll MAX=1e18;
int main(){
    int n,m;
    cin>>n>>m;
    vector<vector<ll>> num(m+1,vector<ll>(n+1,0));
    for(int i=1;i<=m;i++){
        for(int j=1;j<=n;j++){
            cin>>num[i][j];
        }
    }
    vector<vector<ll>> dp(n+1,vector<ll>(m+1,MAX));
    for(int i=1;i<=m;i++){
        dp[1][i]=num[i][1];
    }
    for(int j=2;j<=n;j++){
        for(int i=1;i<=m;i++){
            int prei;
            if(i==1){
                prei=m;
            }else{
                prei=i-1;
            }
            dp[j][i]=min(dp[j-1][i],dp[j-1][prei])+num[i][j];
        }
    }
    ll ans = MAX;
    for (int i = 1; i <= m; ++i)
    {
        ans = min(ans, dp[n][i]);
    }
    cout << ans << endl;
    return 0;
}
```

## 复盘备注

易错点：换组方向是 i 到 i+1，且 M 可到 1，因此第 i 组的前驱是 i-1（i=1 时为 M），不要写反。
可优化点：dp 只依赖上一列，可用两个一维数组滚动，空间降到 O(M)。
同类题提示：环形相邻转移的 DP，注意首尾相接的下标处理。
