## 题目简述

Consider the number triangle shown below. Write a program that calculates the highest sum of numbers that can be passed on a route that starts at the top and ends somewhere on the base. Each step can go either diagonally down to the left or diagonally down to the right.

![](https://cdn.luogu.com.cn/upload/image_hosting/95pzs0ne.png)

In the sample above, the route from $7$ to $3$ to $8$ to $7$ to $5$ produces the highest sum: $30$.

输入格式
The first line contains $R$ ($1 \le R \le 1000$), the number of rows. Each subsequent line contains the integers for that particular row of the triangle. All the supplied integers are non-negative and no larger than $100$.

输出格式
A single line containing the largest sum using the traversal specified.

## 解题思路

本题是经典的数字三角形动态规划问题。

- **状态定义**：用一维数组 `dp[j]` 表示从顶部走到当前行第 j 个位置时能获得的最大路径和。
- **初始化**：`dp[1] = a[1][1]`，即顶部元素。
- **状态转移**：对于第 i 行（i≥2），从右向左更新 `dp[j]`（避免覆盖上一行数据）：
  - 当 j=1 时，只能从上一行第 1 个位置下来：`dp[1] = dp[1] + a[i][1]`；
  - 当 j=i 时，只能从上一行第 i-1 个位置下来：`dp[i] = dp[i-1] + a[i][i]`；
  - 其他情况：`dp[j] = max(dp[j-1], dp[j]) + a[i][j]`。
- **答案**：遍历最后一行所有 `dp[j]` 取最大值。

正确性要点：由于每个位置只能由上一行相邻的两个位置转移而来，且从右向左更新保证 `dp[j-1]` 仍是上一行的值，因此状态转移正确。

## 复杂度分析

- 时间复杂度：O(R^2)
- 空间复杂度：O(R)

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
int main(){
    int n;
    cin>>n;
    vector<vector<int>> a(n+1,vector<int>(n+1));
    for(int i=1;i<=n;i++){
        for(int j=1;j<=i;j++){
            cin>>a[i][j];
        }
    }
    vector<int> dp(n+1,0);
    dp[1]=a[1][1];
    for(int i=2;i<=n;i++){
        for(int j=i;j>=1;j--){
            if(j==1){
                dp[j]=dp[j]+a[i][j];
            }else if(j==i){
                dp[j]=dp[j-1]+a[i][j];
            }else{
                dp[j]=max(dp[j-1],dp[j])+a[i][j];
            }
        }
    }
    int ans=0;
    for(int i=1;i<=n;i++){
        ans=max(ans,dp[i]);
    }
    cout<<ans<<endl;
    return 0;
}
```

## 复盘备注

易错点：
- 内层循环必须从右向左更新，否则 `dp[j-1]` 会被当前行覆盖，导致错误。
- 边界 j=1 和 j=i 需要单独处理，不能直接用 max 转移。
- 答案初始化为 0 即可，因为所有数字非负。

可优化点：
- 输入时可直接边读边处理，减少存储空间，但当前代码已足够。

同类题提示：与“最长上升子序列”“背包问题”等一维 DP 优化类似，注意滚动数组的更新方向。
