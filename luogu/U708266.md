## 题目简述

超级超级超级超聪明的章鱼和猫猫成功进入了小蝴蝶秘密基地。

可是刚进大门，大门就被自动关了。

黑幕中，缓缓走出来一只小蝴蝶。

猫猫说：“糟糕，中计了！必须和小蝴蝶大战！”

猫猫的初始血量为 $h_1$，小蝴蝶的初始血量为 $h_2$、攻击力为 $a_2$。战斗开始前，猫猫可以决定自己的攻击力 $a_1$，且 $a_1$ 可以是任意非负整数。

战斗按回合进行，每个回合中：

1. 猫猫先攻击小蝴蝶，使小蝴蝶的血量减少 $a_1$；
2. 如果小蝴蝶的血量小于等于 $0$，猫猫立即获胜；
3. 否则小蝴蝶攻击猫猫。如果猫猫的血量小于等于 $0$，猫猫立即失败。

小蝴蝶会在第 $k$、第 $2k$、第 $3k$、……回合结束后进入虚弱状态，并在接下来的 $x$ 个回合中保持虚弱。也就是说，第 $k+1$ 至第 $k+x$ 回合、第 $2k+1$ 至第 $2k+x$ 回合、第 $3k+1$ 至第 $3k+x$ 回合……都是虚弱回合。

小蝴蝶在虚弱回合造成 $\left\lceil\dfrac{a_2}{2}\right\rceil$ 点伤害，其他回合造成 $a_2$ 点伤害。

当 $a_1=0$ 时，猫猫无法获胜。

请计算使猫猫无法打败小蝴蝶的最大攻击力 $a_1$。

输入格式
一行输入五个整数 $h_1,h_2,a_2,k,x$（$1 \le h_1,h_2,a_2 \le 10^9$，$2 \le k \le 10^9$，$1 \le x<k$），分别表示猫猫的初始血量、小蝴蝶的初始血量、小蝴蝶的攻击力、虚弱状态出现的间隔和虚弱状态持续的回合数。

输出格式
输出一个非负整数，表示使猫猫无法打败小蝴蝶的最大攻击力 $a_1$。答案可以为 $0$。

说明/提示
小蝴蝶在第 $4,7,10,\ldots$ 个回合处于虚弱状态。

当 $a_1=5$ 时，猫猫需要攻击 $6$ 次才能获胜，但会在第 $5$ 个回合受到总计 $27$ 点伤害并失败。

当 $a_1=6$ 时，猫猫只需攻击 $5$ 次。在最后一次攻击前，猫猫受到的总伤害为 $6+6+6+3=21<22$，因此能够获胜。更大的攻击力也能获胜，所以答案为 $5$。

## 解题思路

关键观察：给定 a1 后，猫猫需要攻击 t=ceil(h2/a1) 次才能击杀小蝴蝶，因此猫猫只会承受前 t-1 个回合的反击伤害。若这 t-1 回合的总伤害 ≥ h1，则猫猫失败；否则猫猫获胜。

由于 a1 越大，t 越小，承受的回合数越少，总伤害单调不增，因此“猫猫失败”这一性质关于 a1 具有单调性：a1 较小时失败，a1 较大时获胜。可以二分答案。

计算前 s 回合总伤害：小蝴蝶的伤害周期为 k+x 回合，其中前 k 回合为普通伤害 a2，后 x 回合为虚弱伤害 ceil(a2/2)。用 s 除以周期得到完整周期数，再处理余数部分（余数 ≤ k 时全为普通伤害，否则前 k 回合普通、剩余为虚弱）。

二分范围 [0, h2]：a1=0 时猫猫永远无法获胜，check(0) 返回 true；a1>h2 时一击必杀，猫猫获胜。二分找最后一个使 check 为 true 的 a1 即为答案。

     if(s==0) return 0;

    ll one_cycle=k*normal_dmg+x*weak_dmg;
    ll res=full*one_cycle;

    if(rem<=k){
        
        res+=rem*normal_dmg;
    }else{

        res+=k*normal_dmg+(rem-k)*weak_dmg;
    }
    return res;
}

bool check(ll a1){
    if(a1==0) return true;
    ll t=(h2+a1-1)/a1;
    ll fight_round=t-1;
    ll total=calc(fight_round);
    return total>=h1;
}

int main(){
    scanf("%lld%lld%lld%lld%lld",&h1,&h2,&a2,&k,&x);
    normal_dmg=a2;
    weak_dmg=(a2+1)/2;

    ll l=0,r=h2;
    ll ans=0;
    while(l<=r){
        ll mid=(l+r)/2;
        if(check(mid)){
            ans=mid;
            l=mid+1;
        }else{
            r=mid-1;
        }
    }
    printf("%lld\n",ans);
    return 0;
}

## 复盘备注

易错点：
- 猫猫只承受 t-1 回合伤害，最后一回合击杀小蝴蝶后不再受击。
- 虚弱伤害为 ceil(a2/2)，即 (a2+1)/2。
- 周期为 k+x，前 k 回合普通、后 x 回合虚弱，注意余数判断边界 rem<=k。
- a1=0 时直接判定猫猫无法获胜，避免除零。
- 二分上界取 h2 即可，因为 a1>h2 时一击必杀必然获胜。
