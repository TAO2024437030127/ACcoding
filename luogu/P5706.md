## 题目简述

现在有 $t$ 毫升肥宅快乐水，要均分给 $n$ 名同学。每名同学需要 $2$ 个杯子。现在想知道每名同学可以获得多少毫升饮料（严格精确到小数点后 $3$ 位），以及一共需要多少个杯子。

输入格式
输入一个实数 $t$ 和一个正整数 $n$，使用空格隔开。

输出格式
输出两行。

第一行输出一个三位小数，表示可以获得多少毫升饮料。第二行输出一个正整数，表示一共需要多少个杯子。

说明/提示
对于所有数据，$0\leq t\leq 10000$ 且小数点后不超过 $3$ 位，$1\leq n\leq 1000$。

## 样例

### 样例 1

输入：
```text
500.0 3
```

输出：
```text
166.667
6
```

## 解题思路

1. 读入实数 t 和整数 n，注意 t 用浮点类型存储。
2. 每人分得饮料量为 t / n，用 printf 的 "%.3f" 格式输出，自动四舍五入到小数点后三位。
3. 杯子总数为 n * 2，直接整数乘法输出。
4. 正确性要点：除法使用浮点数进行，避免整数除法截断；输出格式严格匹配题目要求（第一行三位小数，第二行整数）。

## 复杂度分析

- 时间复杂度：O(1)
- 空间复杂度：O(1)

## 代码

```text
#include<cstdio>
#include<iostream>
using namespace std;
int main(){
    int n;
    float L;
    scanf("%f %d",&L,&n);
    printf("%.3f\n",L/n);
    printf("%d",n*2);
    return 0;
}
```

## 复盘备注

易错点：若用整数读入 t 会导致小数丢失；输出时注意换行和格式。可优化点：使用 double 代替 float 可提高精度，但本题 float 已足够。同类题提示：注意浮点数输出格式与整数运算的区分。
