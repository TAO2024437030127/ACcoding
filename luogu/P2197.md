## 题目简述

甲，乙两个人玩 Nim 取石子游戏。

Nim 游戏的规则是这样的：地上有 $n$ 堆石子，每人每次可从任意一堆石子里取出任意多枚石子扔掉，可以取完，不能不取。每次只能从一堆里取。最后没石子可取的人就输了。假如甲是先手，且告诉你这 $n$ 堆石子的数量，他想知道是否存在先手必胜的策略。

输入格式
**本题有多组测试数据。**

第一行一个整数 $T$，表示有 $T$ 组数据。

接下来每两行是一组数据：
- 第一行一个整数 $n$，表示有 $n$ 堆石子；
- 第二行有 $n$ 个非负整数，表示每一堆石子的数量。

输出格式
共 $T$ 行，每行表示如果对于这组数据存在先手必胜策略则输出 `Yes`，否则输出 `No`。

说明/提示
对于所有数据，$1\le T\le 10$，$1\le n\le 10^4$，每堆石子的数量不超过 $2^{31}-1$。

## 解题思路

- 关键观察：Nim 游戏是经典的公平组合游戏，其胜负完全由各堆石子数的异或和决定。
- 结论：设所有堆石子数的异或和为 S，则 S ≠ 0 时先手必胜，S = 0 时先手必败。
- 正确性要点：
  1. 若 S = 0，先手无论从哪一堆取走若干石子，都会使该堆数值改变，从而异或和变为非 0，把局面交给对手；
  2. 若 S ≠ 0，先手总可以找到某一堆，将其取到使整体异或和变为 0 的值（取该堆为原值异或 S，且该值小于原值），从而把必败局面留给对手；
  3. 终局所有堆为 0 时异或和为 0，是必败局面，归纳可得结论。
- 算法选择：对每组数据读入 n 个数，边读边做异或累加，最后判断异或和是否为 0 即可。
- 实现细节：使用 int 存储异或和即可，因为每堆不超过 2^31-1，异或结果仍在 int 范围内；多组数据注意每组重置异或和。

## 复杂度分析

- 时间复杂度：O(∑n)，每组数据只需线性扫描所有石子堆
- 空间复杂度：O(1)，仅使用常数个变量

## 代码

```text
#include<bits/stdc++.h>
using namespace std;

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    cin>>t;
    while(t--){
        int n;
        cin>>n;
        int ans = 0;
        int x;
        for(int i=0;i<n;i++){
            cin >> x;
            ans ^= x;
        }
        if(ans == 0){
            cout << "No\n";
        }else{
            cout << "Yes\n";
        }
    }
    return 0;
}
```
