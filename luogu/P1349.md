## 题目简述

广义的斐波那契数列是指形如 $a_n=p\times a_{n-1}+q\times a_{n-2}$ 的数列。

今给定数列的两系数 $p$ 和 $q$，以及数列的最前两项 $a_1$ 和 $ a_2$，另给出两个整数 $n$ 和 $m$，试求数列的第 $n$ 项 $a_n$ 对 $m$ 取模后的结果。

输入格式
输入包含一行六个整数，$p,q,a_1,a_2,n,m$。

输出格式
输出包含一行一个整数表示答案。

说明/提示
数列第 $10 $ 项是 $55$，$55 \bmod 7 = 6$。

**【数据范围】**
对于 $100\%$ 的数据，$p,q,a_1,a_2 \in [0,2^{31}-1]$，$1\le n,m \le 2^{31}-1$。

## 解题思路

1. 将递推写成矩阵形式：\[\begin{pmatrix}a_n\\a_{n-1}\end{pmatrix}=\begin{pmatrix}p&q\\1&0\end{pmatrix}\begin{pmatrix}a_{n-1}\\a_{n-2}\end{pmatrix}\]，因此 \[\begin{pmatrix}a_n\\a_{n-1}\end{pmatrix}=\begin{pmatrix}p&q\\1&0\end{pmatrix}^{n-2}\begin{pmatrix}a_2\\a_1\end{pmatrix}\]。
2. 用快速幂计算转移矩阵的 n-2 次方，矩阵乘法中每一步都对 m 取模，避免溢出。
3. 特判 n=1 和 n=2，直接输出 a_1%m 和 a_2%m。
4. 正确性：矩阵乘法满足结合律，快速幂结果与逐次递推等价；所有运算在模 m 下进行，最终取模结果正确。
5. 注意输入参数可能为 0，矩阵元素先取模；乘法使用 long long 并在累加时取模。

## 复杂度分析

- 时间复杂度：O(log n)
- 空间复杂度：O(1)

## 代码

```text
#include <iostream>
#include <vector>
using namespace std;
typedef long long ll;

ll p,q,a1,a2,n,mod;
using Matrix = vector<vector<ll>>;

Matrix mul(const Matrix &A,const Matrix &B){
    Matrix res(2,vector<ll>(2,0));
    for(int i=0;i<2;i++){
        for(int k=0;k<2;k++){
            if(A[i][k]==0) continue;
            for(int j=0;j<2;j++){
                res[i][j]=(res[i][j]+A[i][k]*B[k][j])%mod;
            }
        }
    }
    return res;
}

Matrix pow_mat(Matrix A,ll b){
    Matrix res={{1,0},{0,1}};
    while(b>0){
        if(b&1) res=mul(res,A);
        A=mul(A,A);
        b>>=1;
    }
    return res;
}

int main(){
    cin>>p>>q>>a1>>a2>>n>>mod;
    if(n==1){
        cout<<a1%mod<<endl;
        return 0;
    }
    if(n==2){
        cout<<a2%mod<<endl;
        return 0;
    }
    Matrix base={{p%mod,q%mod},{1,0}};
    Matrix M=pow_mat(base,n-2);
    ll ans=(M[0][0]*(a2%mod)+M[0][1]*(a1%mod))%mod;
    cout<<ans<<endl;
    return 0;
}
```

## 复盘备注

易错点：n=1 或 n=2 需特判；p、q、a1、a2 可能大于等于 m，构造矩阵和计算答案时先取模；矩阵乘法中乘法可能溢出 int，需用 long long。可优化点：固定 2×2 矩阵可用数组代替 vector 减少开销。同类题：P1962 斐波那契数列、P1939 矩阵加速（数列）。
