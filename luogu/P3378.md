## 题目简述

给定一个数列，初始为空，请支持下面三种操作：

1. 给定一个整数 $x$，请将 $x$ 加入到数列中。
2. 输出数列中最小的数。
3. 删除数列中最小的数（如果有多个数最小，只删除 $1$ 个）。

输入格式
第一行是一个整数，表示操作的次数 $n$。
接下来 $n$ 行，每行表示一次操作。每行首先有一个整数 $op$ 表示操作类型。
- 若 $op = 1$，则后面有一个整数 $x$，表示要将 $x$ 加入数列。
- 若 $op = 2$，则表示要求输出数列中的最小数。
- 若 $op = 3$，则表示删除数列中的最小数。如果有多个数最小，只删除 $1$ 个。

输出格式
对于每个操作 $2$，输出一行一个整数表示答案。

说明/提示
**【数据规模与约定】**
- 对于 $30\%$ 的数据，保证 $n \leq 15$。
- 对于 $70\%$ 的数据，保证 $n \leq 10^4$。
- 对于 $100\%$ 的数据，保证 $1 \leq n \leq 10^6$，$1 \leq x \lt 2^{31}$，$op \in \{1, 2, 3\}$。

## 解题思路

本题是堆（优先队列）模板题。

- 关键观察：只需要动态维护最小值，且删除时只删一个最小值，正好对应小根堆的 top 与 pop。
- 算法选择：C++ STL 的 priority_queue，通过 greater<ll> 指定小根堆，底层默认用 vector 存储。
- 操作对应：op=1 时 push(x)；op=2 时输出 top()；op=3 时 pop()。
- 正确性要点：小根堆保证堆顶始终是当前所有元素中的最小值；push 后堆性质由 STL 维护，pop 删除堆顶即删除一个最小值，多个相同最小值时也只删一个，符合题意。
- 代码中判断 !pq.empty() 是防御性写法，按题意操作 2、3 时数列非空，不影响正确性。

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
typedef long long ll;

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    priority_queue<ll,vector<ll>,greater<ll>> pq;
    int n;
    cin>>n;
    int op;
    ll x;
    while(n--){
        cin>>op;
        if(op == 1){
            cin>>x;
            pq.push(x);
        }else if(op == 2){
            if(!pq.empty()) cout<<pq.top()<<'\n';
        }else if(op == 3){
            if(!pq.empty()) pq.pop();
        }
    }
    return 0;
}
```

## 复盘备注

易错点：
- priority_queue 默认是大根堆，求最小值必须写 greater<ll>，并包含 <functional>（bits/stdc++.h 已包含）。
- 数据范围 n 可达 10^6，需使用 ios::sync_with_stdio(false) 与 cin.tie(nullptr) 加速输入，输出用 '\n' 而非 endl。
- x < 2^31，用 int 也可存，但用 long long 更稳妥。

可优化点：
- 本题也可手写二叉堆，但 STL 已足够且更简洁。
- 若查询/删除前不确定是否为空，保留 empty 判断可避免未定义行为。
