## 题目简述

给定一个长度为 $N$ 的非负整数序列 $A$，对于前奇数项求中位数。

输入格式
第一行一个正整数 $N$。

第二行 $N$ 个正整数 $A_{1\dots N}$。

输出格式
共 $\lfloor \frac{N + 1}2\rfloor$ 行，第 $i$ 行为 $A_{1\dots 2i - 1}$ 的中位数。

说明/提示
对于 $20\%$ 的数据，$N \le 100$；

对于 $40\%$ 的数据，$N \le 3000$；

对于 $100\%$ 的数据，$1 \le N ≤ 10^5$，$0 \le A_i \le 10^9$。

## 解题思路

采用对顶堆（双堆）在线维护中位数：
- 用一个大根堆 `max_heap` 保存当前前缀中较小的一半，用一个小根堆 `min_heap` 保存较大的一半。
- 每读入一个数 x：若 `max_heap` 为空或 x ≤ `max_heap.top()`，压入大根堆；否则压入小根堆。
- 随后调整两堆大小，保证 `max_heap.size()` 等于 `min_heap.size()` 或比它多 1。调整规则：当大根堆比小根堆多超过 1 个时，把大根堆堆顶移到小根堆；当小根堆比大根堆多时，把小根堆堆顶移到大根堆。
- 由于前缀长度为奇数时，调整后大根堆恰好比小根堆多 1 个元素，因此大根堆堆顶就是当前前缀的中位数，直接输出。
正确性要点：大根堆中所有元素 ≤ 小根堆中所有元素，且大小关系满足左半部分元素个数为 ceil(k/2)，故大根堆堆顶为第 (k+1)/2 小元素，即中位数。

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
typedef long long ll;

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    priority_queue<ll> max_heap;  // 大根堆 左半边
    priority_queue<ll, vector<ll>, greater<ll>> min_heap; // 小根堆 右半边

    for(int i = 1; i <= n; ++i)
    {
        ll x;
        cin >> x;
        if(max_heap.empty() || x <= max_heap.top())
        {
            max_heap.push(x);
        }
        else
        {
            min_heap.push(x);
        }

        // 平衡两个堆
        // 左边最多比右边多1个
        while(max_heap.size() > min_heap.size() + 1)
        {
            ll val = max_heap.top();
            max_heap.pop();
            min_heap.push(val);
        }
        while(min_heap.size() > max_heap.size())
        {
            ll val = min_heap.top();
            min_heap.pop();
            max_heap.push(val);
        }

        // 当前是奇数项，输出中位数
        if(i % 2 == 1)
        {
            cout << max_heap.top() << '\n';
        }
    }
    return 0;
}
```

## 复盘备注

易错点：
- 插入时比较的是 `max_heap.top()`，不要误写成 `min_heap.top()`。
- 调整顺序应先处理大根堆过多，再处理小根堆过多，否则可能反复移动。
- 只在 i 为奇数时输出，输出的是 `max_heap.top()`。
可优化点：本题数据范围下双堆已足够；若需离线可考虑树状数组/平衡树，但实现更复杂。
同类题：动态中位数、滑动窗口中位数（需支持删除，可用对顶堆 + 延迟删除）。
