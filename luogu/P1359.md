## 题目简述

长江游艇俱乐部在长江上设置了 $n$ 个游艇出租站 $1,2,\dots,n$。游客可在这些游艇出租站租用游艇，并在下游的任何一个游艇出租站归还游艇。游艇出租站 $i$ 到游艇出租站 $j$ 之间的租金为 $r_{i,j}$（$1\le i\lt j\le n$）。试设计一个算法，计算出从游艇出租站 $1$ 到游艇出租站 $n$ 所需的最少租金。

输入格式
第一行中有一个正整数 $n$，表示有 $n$ 个游艇出租站。接下来的 $n-1$ 行是一个半矩阵 $r_{i,j}$（$1\le i<j\le n$）。

输出格式
输出计算出的从游艇出租站 $1$ 到游艇出租站 $n$ 所需的最少租金。

说明/提示
$1\le n\le 200$，保证计算过程中任何时刻数值都不超过 $10^6$。

## 解题思路

**关键观察**：所有航线只能从编号小的站到编号大的站，因此整个图是一个有向无环图（DAG），且边权非负。

**算法选择**：按站点编号从小到大进行动态规划。设 dp[i] 表示从站 1 到达站 i 的最小租金。

**转移**：对于每个 i（2 ≤ i ≤ n），枚举所有可能的上一个停靠站 k（1 ≤ k < i），则 dp[i] = min_{k<i} (dp[k] + r_{k,i})。初始 dp[1] = 0，其余为无穷大。

**正确性要点**：由于只能从小编号到大编号移动，任何到达 i 的路径最后一步必然是从某个 k < i 直达 i，且到达 k 的最优方案已由 dp[k] 给出，满足最优子结构，因此按编号顺序递推即可得到全局最优解。

**实现细节**：读入半矩阵时只读 i<j 的部分存入 a[i][j]；dp 初始值取 1e6 足够大（题目保证结果不超过 10^6）。

## 复杂度分析

- 时间复杂度：O(n^2)
- 空间复杂度：O(n^2)

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
int main(){
    int n;
    cin>>n;
    vector<vector<int>> a(n+1,vector<int>(n+1,0));
    for(int i=1;i<=n;i++){
        for(int j=i+1;j<=n;j++){
            cin>>a[i][j];
        }
    }
    vector<int> dp(n+1,1e6);
    dp[1]=0;
    for(int i=2;i<=n;i++){
        for(int k=1;k<i;k++){
            dp[i]=min(dp[i],dp[k]+a[k][i]);
        }
    }
    cout<<dp[n]<<endl;
    return 0;
    
}
```

## 复盘备注

**易错点**：
- 输入是半矩阵，只读上三角部分，不要误读下三角或对角线。
- dp 初始值要足够大，但不要溢出；1e6 在本题约束下安全。
- 站点编号从 1 开始，数组大小需 n+1。

**可优化点**：
- 空间上 a 矩阵可只存上三角，但 n ≤ 200 时 O(n^2) 完全够用。
- 本题也可用最短路算法（Dijkstra/Floyd），但 DAG 上 DP 更简洁高效。

**同类题提示**：DAG 上按拓扑序 DP 求最短路是经典套路，注意区分“边权”与“点权”以及是否允许重复经过节点。
