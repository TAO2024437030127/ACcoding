## 解题思路

1. 由于 x + y = N 且 x < y，等价于 x < N - x，即 2x < N，也就是 x < N/2。
2. x 为非负整数，因此 x 的取值范围是 0 ≤ x ≤ floor((N-1)/2)。
3. 对于每个满足条件的 x，y = N - x 唯一确定，因此整数对数量等于满足条件的 x 的个数。
4. 计算 N/2 的整数部分：N = 2026202520242023，N/2 = 1013101260121011.5，所以 floor((N-1)/2) = 1013101260121011。
5. 因此 x 可取 0, 1, 2, ..., 1013101260121011，共 1013101260121012 个。
6. 代码直接输出该计算结果。
