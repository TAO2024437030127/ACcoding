## 题目简述

NASA（美国航空航天局）因为航天飞机的隔热瓦等其他安全技术问题一直大伤脑筋，因此在各方压力下终止了航天飞机的历史，但是此类事情会不会在以后发生，谁也无法保证。所以，在遇到这类航天问题时，也许只能让航天员出仓维修。但是过多的维修会消耗航天员大量的能量，因此 NASA 便想设计一种食品方案，使体积和承重有限的条件下多装载一些高卡路里的食物。

航天飞机的体积有限，当然如果载过重的物品，燃料会浪费很多钱，每件食品都有各自的体积、质量以及所含卡路里。在告诉你体积和质量的最大值的情况下，请输出能达到的食品方案所含卡路里的最大值，当然每个食品只能使用一次。

输入格式
第一行 $2$ 个整数，分别代表体积最大值 $H$ 和质量最大值 $T$。

第二行 $1$ 个整数代表食品总数 $n$。

接下来 $n$ 行每行 $3$ 个数 体积 $h_i$，质量 $t_i$，所含卡路里 $k_i$。

输出格式
一个数，表示所能达到的最大卡路里（`int` 范围内）

说明/提示
对于 $100\%$ 的数据，$H,T,h_i,t_i \le 400$，$n \le 50$，$k_i \le 500$。

## 解题思路

- 这是经典的 0/1 背包在**两个容量维度**上的推广：体积与质量同时受限，物品只能取一次。
- 设 dp[j][l] 表示体积不超过 j、质量不超过 l 时能获得的最大卡路里，初值全 0。
- 逐件处理食品 (h,t,k)。对每件物品，体积维 j 从 H 递减到 h、质量维 l 从 T 递减到 t，做转移：dp[j][l] = max(dp[j][l], dp[j-h][l-t] + k)。
- 两维都**倒序**枚举是关键：倒序保证 dp[j-h][l-t] 仍是“未考虑当前物品”的旧状态，从而每件食品最多被选一次；若任一维正序，就会退化成完全背包，导致同一物品被重复选取。
- 正确性：dp 按物品逐个更新，每次转移相当于在“不选当前物品”和“选当前物品”之间取较优，且状态覆盖所有体积、质量组合，故 dp[H][T] 即为全局最优解。
- 边界：h>H 或 t>T 时内层循环不执行，该物品自动被跳过，无需特判。

## 复杂度分析

- 时间复杂度：O(n·H·T)
- 空间复杂度：O(H·T)

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
int main(){
    int H,T;
    cin>>H>>T;
    int n;
    cin>>n;
    vector<vector<int>> dp(H+1,vector<int>(T+1,0));
    for(int i=1;i<=n;i++){
        int h,t,k;
        cin>>h>>t>>k;
        for(int j=H;j>=h;j--){
            for(int l=T;l>=t;l--){
                dp[j][l]=max(dp[j][l],dp[j-h][l-t]+k);
            }
        }
    }
    cout<<dp[H][T]<<endl;
    return 0;
}
```

## 复盘备注

- 易错点：两维循环都必须倒序，只倒序一维会出错；dp 数组大小应为 (H+1)×(T+1)。
- 答案在 dp[H][T]，因为状态定义为“不超过”容量，无需再遍历取最大值。
- 同类题：二维费用背包（如 P1855 榨取kkksc03）、多维背包问题，思路都是把费用维度扩展、各维倒序枚举。
