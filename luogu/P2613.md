## 题目简述

给出一个有理数 $c=\frac{a}{b}$，求 $c \bmod 19260817$ 的值。

这个值被定义为 $bx\equiv a\pmod{19260817}$ 的解。

输入格式
一共两行。

第一行，一个整数 $a$。
第二行，一个整数 $b$。

输出格式
一个整数，代表求余后的结果。如果无解，输出 `Angry!`。

说明/提示
对于所有数据，保证 $0\leq a \leq 10^{10001}$，$1 \leq b \leq 10^{10001}$，且 $a, b$ 不同时是 $19260817$ 的倍数。

## 样例

### 样例 1

输入：
```text
233
666
```

输出：
```text
18595654
```

## 解题思路

1. 模数 p = 19260817 是质数，因此当 b 不被 p 整除时，b 在模 p 下存在乘法逆元，方程有唯一解 x ≡ a * b^{-1} (mod p)。
2. 输入整数极大，无法用内置类型直接存储，采用逐字符读入并边读边取模：res = (res * 10 + digit) % p，得到 a 和 b 模 p 的余数。
3. 若 b % p == 0，则方程 bx ≡ a (mod p) 无解（题目保证 a、b 不同时为 p 的倍数，故此时 a 不为 0），输出 Angry!。
4. 否则用费马小定理求逆元：b^{-1} ≡ b^{p-2} (mod p)，用快速幂计算。
5. 最终答案 ans = a * inv(b) % p，输出即可。

## 复杂度分析

- 时间复杂度：O(|a| + |b| + log p)，其中 |a|、|b| 为输入数字的位数，log p 为快速幂的指数规模。
- 空间复杂度：O(|a| + |b|)（存储输入字符串），若流式读入可降至 O(1)。

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
typedef long long ll;
const ll MOD=19260817;
ll readbig(){
    string s;
    cin >> s;
    ll res = 0;
    for(char ch : s){
        res = (res * 10 + ch - '0') % MOD;
    }
    return res;
}

ll qpow(ll a,ll b,ll mod){
    ll res=1;
    while(b){
        if(b&1){
            res=res*a%mod;
           
        }
         a=a*a%mod;
         b>>=1;
    }
    return res;
}


int main(){
    ll a=readbig();
    ll b=readbig();
    if(b == 0){
        cout << "Angry!\n";
    }else{
        ll invb = qpow(b, MOD - 2, MOD);
        ll ans = a * invb % MOD;
        cout << ans << '\n';
    }
    return 0;
}
```

## 复盘备注

易错点：
- 读入时需用字符串处理超大整数，不能直接读入 long long。
- 判断无解的条件是 b % MOD == 0，而不是 b == 0（b 本身可能很大但模 MOD 为 0）。
- 快速幂中乘法可能溢出 int，需使用 long long。
- 模数 19260817 是质数，才可用费马小定理求逆元；若模数非质数需用扩展欧几里得。
