## 题目简述

有一些电脑，一部分电脑有双向数据线连接。

如果一个电脑得到数据，它可以传送到的电脑都可以得到数据。

现在，你有这个数据，问你至少将其输入几台电脑，才能使所有电脑得到数据。

输入格式
第一行两个整数 $n,m$。$n$ 是点数，$m$ 是边数。

接下来 $m$ 行，每行 $2$ 个整数 $p,q$，表示 $p$ 到 $q$ 有一条双向数据线。

输出格式
一个整数，表示至少输入的电脑数量。

说明/提示
对于 $30\%$ 的数据，$n \le 100$，$m \le 1000$。

对于 $60\%$ 的数据，$n \le 2000$。

对于 $100\%$ 的数据，$0 \le n \le 10^5$，$0 \le m \le 2 \times 10^5$，$1 \le p,q \le n$。

数据可能存在重边自环。

## 解题思路

**关键观察**：数据沿双向边传播，因此同一连通块内只要有一台电脑获得数据，整个连通块都会获得数据；不同连通块之间互不影响。所以最少输入次数等于连通块个数。

**算法选择**：使用并查集维护连通性。
- 初始化每个点自成一个集合；
- 对每条边 (p,q) 执行合并操作；
- 最后统计满足 find(i)==i 的结点个数，即连通块个数。

**正确性要点**：
- 并查集合并保证每条边两端点最终属于同一集合，且只有真正连通的点才会被合并；
- 每个连通块恰好有一个根结点满足 find(i)==i，统计根结点数即连通块数；
- 每个连通块至少需要一次输入，且一次输入足够覆盖整个连通块，故答案等于连通块数。

**边界处理**：n=0 时直接输出 0；重边和自环不影响并查集结果。

## 复杂度分析

- 时间复杂度：O((n+m)α(n))，其中 α 为反阿克曼函数，近似常数
- 空间复杂度：O(n)

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
const int MAX=100005;
int fa[MAX];

//找根
int find(int x){
    if(fa[x]!=x){
        fa[x]=find(fa[x]);
    }
    return fa[x];
}
//合并
void unite(int x,int y){
    x=find(x);
    y=find(y);
    if(x!=y)fa[y]=x;
}
int main(){
    int n,m;
    cin>>n>>m;
    if(n==0){
        cout<<0<<endl;
        return 0;
    }
    for(int i=1;i<=n;i++){
        fa[i]=i;
    }
    for(int i=1;i<=m;i++){
        int p,q;
        cin>>p>>q;
        unite(p,q);
    }
    int ans=0;
    for(int i=1;i<=n;i++){
        if(find(i)==i){
            ans++;
        }
    }
    cout<<ans<<endl;
    return 0;
}
```

## 复盘备注

**易错点**：
- n=0 时需特判输出 0，否则初始化循环不执行但统计逻辑仍可输出 0，不过显式特判更清晰；
- 统计连通块时应对每个点调用 find(i) 后再判断是否为根，避免路径未压缩导致误判；
- 重边和自环无需特殊处理，并查集自动忽略。

**可优化点**：
- 可增加按秩合并或启发式合并，但本题规模下路径压缩已足够；
- 输入量较大时可使用 scanf 或关闭同步流加速。

**同类题提示**：求无向图连通块个数、需要添加多少条边使图连通等题目均可使用并查集解决。
