## 题目简述

因为可恶人类的选择，猫猫并没有如愿进入合理动物园，而是进入了解密动物园。

不过解密动物园并没有猫猫想的那样有大量的谜题，而是和往常的动物园一样。

这天，他遇到了超级超级超级超聪明的章鱼，超级超级超级超聪明的章鱼邀请猫猫进入严谨逻辑社团，但是要对猫猫进行一些考核。

本次考核的内容为 MBTI 测试。

一个 MBTI 类型是一个长度为 $4$ 的字符串，并且满足以下规则：

- 第一个字母为 `I` 或 `E`；
- 第二个字母为 `N` 或 `S`；
- 第三个字母为 `F` 或 `T`；
- 第四个字母为 `J` 或 `P`。

现在给定一个符合上述规则的 MBTI 类型，以及 $q$ 次询问。每次询问给出一个字母，请判断该字母是否出现在给定的 MBTI 类型中。

输入格式
第一行输入一个长度为 $4$ 的字符串 $s$，表示给定的 MBTI 类型。

保证 $s$ 满足以下条件：

- $s_1$ 为 `I` 或 `E`；
- $s_2$ 为 `N` 或 `S`；
- $s_3$ 为 `F` 或 `T`；
- $s_4$ 为 `J` 或 `P`。

第二行输入一个整数 $q$（$1\le q\le10^5$），表示询问次数。

接下来 $q$ 行，每行输入一个大写字母 $c$。保证 $c$ 是 `I`、`E`、`N`、`S`、`F`、`T`、`J`、`P` 中的一个。

输出格式
对于每次询问：

- 如果字母 $c$ 出现在字符串 $s$ 中，输出 `YES`；
- 否则输出 `NO`。

每次询问的答案占一行。

说明/提示
字母 `I` 出现在 `INFJ` 中，因此第一次询问输出 `YES`。

字母 `E` 没有出现在 `INFJ` 中，因此第二次询问输出 `NO`。

## 解题思路

- 关键观察：s 长度固定为 4，且询问字母范围固定为 8 个大写字母之一，只需判断字符是否在 s 中出现。
- 算法选择：将 s 的字符放入哈希集合 `unordered_set<char>`，每次询问用 `count` 查询，平均 O(1)。
- 正确性要点：集合包含且仅包含 s 中出现的字符，`count` 返回 1 当且仅当该字符在 s 中，与题目要求完全一致。
- 实现细节：读入 s 后直接构造集合，读入 q 后循环处理每个询问字符，输出 YES 或 NO。

## 复杂度分析

- 时间复杂度：O(|s| + q)，其中 |s| = 4，每次询问平均 O(1)
- 空间复杂度：O(|s|) = O(1)

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
int main(){
    string s;
    cin>>s;
    unordered_set<char> st(s.begin(),s.end());
    int n;
    cin>>n;
    char a;
    while(n--){
        cin>>a;
        if(st.count(a)){
            cout<<"YES"<<endl;
        }else{
            cout<<"NO"<<endl;
        }
    }
    return 0;
}
```

## 复盘备注

易错点：输出需换行且大小写严格为 YES/NO；使用 `endl` 在 q 较大时可能略慢，可改用 `\n` 优化。同类题：字符存在性判断可直接用集合或布尔数组。
