## 题目简述

在某个神秘的算法实验室里，成员们发现了一种神秘性质：对于某些正整数对 $(x, y)$，它们按位与的结果恰好等于它们的最大公约数。

现在，实验室的成员们想要研究这种性质。给定一个正整数 $x$，请你帮忙找出**最小的正整数** $y$，使得 $x$ 和 $y$ 满足上述神奇性质。

形式化地，你需要求解：

$$y_{min} = \min\{y \in \mathbb{N}^+ : (x \text{ and } y) = \gcd(x, y)\}$$

#### 什么是按位与（and）？

按位与(and)是一种二进制运算。对于两个非负整数 $a$ 和 $b$，将它们写成二进制形式，然后逐位比较：
- 如果某一位上两个数都是 $1$，则结果的这一位为 $1$
- 否则结果的这一位为 $0$

例如，计算 $9 \text{ and } 5$：
- $9$ 的二进制为 $1001$
- $5$ 的二进制为 $0101$
- 逐位比较：$1001 \text{ and } 0101 = 0001 = 1$

在 C/C++ 中，按位与运算符为 `&`。

#### 什么是最大公约数（gcd）？

最大公约数是指能同时整除两个数的最大正整数。

例如，$\gcd(12, 18) = 6$，因为 $6$ 能同时整除 $12$ 和 $18$，且不存在比 $6$ 更大的正整数满足这个条件。

在 C/C++ 中，可以使用 `std::gcd` 函数（需要头文件 `<numeric>`）。

## 解题思路

关键观察：
1. 设 g = gcd(x, y)，则 g 同时整除 x 和 y，且 x & y = g。由于按位与的结果 g 的二进制位是 x 和 y 对应位的子集，所以 g 的每个二进制 1 位在 x 中也为 1，即 g 是 x 的按位子集（g & x = g）。
2. 又 g | x，所以 g 必须是 x 的约数且是 x 的按位子集。最小的候选是 g = 2^k，其中 k 是 x 二进制末尾连续 0 的个数（即 lowbit(x)）。因为 x 的任意按位子集约数至少包含 x 的最低位 1，而 lowbit(x) 本身是 x 的约数且是 x 的按位子集。
3. 取 y = g = lowbit(x) 时，x & y = y（因为 y 是 x 的按位子集），且 gcd(x, y) = y（因为 y | x），满足条件。
4. 证明最小性：任何满足条件的 y 对应的 g = gcd(x, y) 必须是 x 的约数且是 x 的按位子集，因此 g ≥ lowbit(x)。而 y ≥ g，所以 y ≥ lowbit(x)。
5. 因此答案就是 x 的 lowbit，即 x 的二进制最低位 1 所对应的值。代码通过不断右移 x 直到最低位为 1，统计右移次数 k，答案即 1ULL << k。

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
using ull=unsigned long long ;
int main(){
    int t;
    cin>>t;
    while(t--){
        ull x;
        cin>>x;
        int k=0;
        while((x&1)==0){
            k++;
            x>>=1;
        }
        ull ans=1ULL<<k;
        cout<<ans<<endl;
        
    }
    return 0;
}
```

## 复盘备注

易错点：
- x 可达 2^60，需使用 unsigned long long 或 long long 存储，移位时用 1ULL 避免溢出。
- 当 x 为奇数时 k=0，答案为 1，符合样例。
- 注意输入输出量较大（T ≤ 1e5），建议使用快速 I/O。
