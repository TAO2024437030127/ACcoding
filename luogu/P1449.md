## 题目简述

所谓后缀表达式是指这样的一个表达式：式中不再引用括号，运算符号放在两个运算对象之后，所有计算按运算符号出现的顺序，严格地由左而右进行（不用考虑运算符的优先级）。

本题中运算符仅包含 $\texttt{+-*/}$。保证对于 $\texttt{/}$ 运算除数不为 0。特别地，其中 $\texttt{/}$ 运算的结果需要**向 0 取整**（即与 C++ `/` 运算的规则一致）。

如：$\texttt{3*(5-2)+7}$ 对应的后缀表达式为：$\texttt{3.5.2.-*7.+@}$。在该式中，`@` 为表达式的结束符号。`.` 为操作数的结束符号。

输入格式
输入一行一个字符串 $s$，表示后缀表达式。

输出格式
输出一个整数，表示表达式的值。

说明/提示
数据保证，$1 \leq |s| \leq 50$，答案和计算过程中的每一个值的绝对值不超过 $10^9$。

## 解题思路

1. 后缀表达式求值的标准做法是使用一个操作数栈，从左到右扫描字符串。
2. 扫描到数字字符时，先暂存到字符缓冲区；遇到 '.' 表示一个操作数结束，把缓冲区拼成整数并压栈，然后清空缓冲区。
3. 扫描到运算符时，从栈顶连续弹出两个数：先弹出的是右操作数 a，后弹出的是左操作数 b，按 b op a 计算，再把结果压回栈中。
4. 除法直接使用 C++ 的整数除法，天然满足向 0 取整；题目保证除数不为 0。
5. 扫描到 '@' 时表达式结束，栈中唯一剩余元素就是答案。
6. 正确性要点：后缀表达式每个运算符恰好对应此前最近的两个未参与运算的操作数，栈的后进先出顺序正好保证这一点；操作数分隔符 '.' 保证多位数能被完整识别。

## 代码

```text
#include<iostream>
#include<stack>
#include<vector>
#include<string>
using namespace std;

// 字符串转int
int makenum(const string& s){
    return stoi(s);
}

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string s;
    cin >> s;
    int n = s.size();
    
    stack<int> cal;
    vector<char> num;  // 补充分号
    
    for(int i = 0; i < n; i++){
        char ch = s[i];
        if(ch == '.'){
            // 遇到分隔符，把vector<char>转字符串，数字入栈
            string tmp(num.begin(), num.end());
            cal.push(makenum(tmp));
            num.clear();
        }
        else if(ch >= '0' && ch <= '9'){
            // 数字正常插尾部，不颠倒顺序
            num.push_back(ch);
        }
        // 运算符：先取出栈中两个数计算
        else if(ch == '+' || ch == '-' || ch == '*' || ch == '/'){
            int a = cal.top(); cal.pop();
            int b = cal.top(); cal.pop();
            int res;
            if(ch == '+') res = b + a;
            else if(ch == '-') res = b - a;
            else if(ch == '*') res = b * a;
            else if(ch == '/') res = b / a;
            cal.push(res);
        }
    }
    cout << cal.top() << '\n';
    return 0;
}
```

## 复盘备注

易错点：减法与除法必须用“先弹出的数作为右操作数、后弹出的数作为左操作数”，即 b-a、b/a，顺序写反会得到错误结果。
可优化点：本题长度很小，当前写法已足够；若数据规模增大，可边扫描边解析数字，避免额外 vector 与 stoi 的字符串构造。
同类题提示：中缀转后缀、后缀表达式求值、表达式树求值等题目都可用栈统一处理。
