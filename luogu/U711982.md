## 题目简述

给定一个长度为 $n$ 的数组，请你将它按照**从小到大**的顺序排序后输出。

输入格式
第一行包含一个正整数 $T$（$1 \le T \le 10^5$），表示测试用例的数量。

每组测试数据：

- 第一行输入一个整数 $n$（$1 \le n \le 10^5$）
- 第二行输入 $n$ 个整数 $a_i$（$1 \le a_i \le 10^9$）

保证单个测试文件的 $n$ 之和不超过 $2 \times 10^5$。

输出格式
对于每个测试用例，输出一行 $n$ 个整数，表示排序后的结果，中间用空格隔开。

## 样例

### 样例 1

输入：
```text
3
5
3 1 4 1 5
4
10 20 30 40
3
5 5 5
```

输出：
```text
1 1 3 4 5
10 20 30 40
5 5 5
```

## 解题思路

1. 读入测试用例数 T，循环处理每组数据。
2. 对每组数据读入 n 和 n 个整数，存入 vector 容器。
3. 直接调用 C++ 标准库的 sort 函数对 vector 进行升序排序，sort 默认使用小于比较，时间复杂度 O(n log n)。
4. 按顺序输出排序后的元素，每个元素后跟一个空格，每组输出结束后换行。
5. 正确性要点：sort 保证结果非递减；每组使用独立的 vector 并在输出后 clear，避免数据串组；总规模 2×10^5，O(总 n log n) 在时限内可行。

## 复杂度分析

- 时间复杂度：O(Σ n log n)，其中 Σ n 为所有测试用例 n 之和，不超过 2×10^5
- 空间复杂度：O(max n)，用于存储当前测试用例的数组

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
int main(){
    int t;
    cin>>t;
    while(t--){
        int n;
        cin>>n;
        vector<int> num;
        for(int i=1;i<=n;i++){
            int a;cin>>a;
            num.push_back(a);
        }
        sort(num.begin(),num.end());
        for(int i=0;i<num.size();i++){
            cout<<num[i]<<" ";
        }
        cout<<endl;
        num.clear();
    }
    return 0;
}
```

## 复盘备注

易错点：每组输出后需要换行；多组数据之间不要输出多余空行；使用 vector 时注意每组清空或重新声明。可优化点：输出量较大时可使用 ios::sync_with_stdio(false) 加速，或改用 printf/puts 风格输出。同类题提示：多组数据排序注意总规模限制，避免每组都重新分配过大空间。
