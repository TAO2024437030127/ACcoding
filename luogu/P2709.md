## 题目简述

小 B 有一个长为 $n$ 的整数序列 $a$，值域为 $[1,k]$。
他一共有 $m$ 个询问，每个询问给定一个区间 $[l,r]$，求：
$$\sum\limits_{i=1}^k c_i^2$$

其中 $c_i$ 表示数字 $i$ 在 $[l,r]$ 中的出现次数。

小 B 请你帮助他回答询问。

输入格式
第一行三个整数 $n,m,k$。

第二行 $n$ 个整数，表示小 B 的序列。

接下来的 $m$ 行，每行两个整数 $l,r$。

输出格式
输出 $m$ 行，每行一个整数，对应一个询问的答案。

说明/提示
【数据范围】
对于 $100\%$ 的数据，$1\le n,m,k \le 10^5$。

## 解题思路

本题是莫队算法模板题。关键观察：维护当前区间 [L,R] 内每个数的出现次数 cnt[x] 以及答案 cur_ans = Σ cnt[x]^2。当加入一个数 x 时，cnt[x] 变为 cnt[x]+1，平方和增加 (cnt[x]+1)^2 - cnt[x]^2 = 2*cnt[x]+1；删除时先减 cnt[x]，平方和减少 2*cnt[x]+1（此时 cnt[x] 为减一后的值）。因此 add/del 均 O(1)。

算法选择：将询问按左端点所在块排序，块内按右端点排序（奇偶优化可选）。块大小取 sqrt(n)。用双指针 L,R 从空区间开始，依次移动四个边界到当前询问区间，移动过程中调用 add/del 更新答案。

正确性要点：每次移动只改变一个元素，add/del 的增量公式保证 cur_ans 始终等于当前区间内 Σ cnt[x]^2；排序后指针总移动次数为 O((n+m)√n)，在 1e5 规模下可接受。

## 复杂度分析

- 时间复杂度：O((n+m)√n)
- 空间复杂度：O(n+m+k)

## 代码

```cpp
#include<bits/stdc++.h>
using namespace std;
typedef long long ll;
const int MAXN = 1e5 + 10;

int a[MAXN];
int cnt[MAXN];
ll ans[MAXN];
int ql[MAXN], qr[MAXN], qid[MAXN], blk[MAXN];//ql,qr.存询问
int ord[MAXN];
int n, m, k;
ll cur_ans;

bool cmp(int x, int y) {
    if (blk[ql[x]] != blk[ql[y]])
        return blk[ql[x]] < blk[ql[y]];
    return qr[x] < qr[y];
}

void add(int p) {
    int x = a[p];
    cur_ans += 2 * cnt[x] + 1;
    cnt[x]++;
}

void del(int p) {
    int x = a[p];
    cnt[x]--;
    cur_ans -= 2 * cnt[x] + 1;
}

void solve() {
    int size = sqrt(n);
    for (int i = 1; i <= n; i++) {
        blk[i] = (i - 1) / size + 1;
    }
    for (int i = 1; i <= m; i++) ord[i] = i;
    sort(ord + 1, ord + m + 1, cmp);

    int L = 1, R = 0;
    cur_ans = 0;
    for (int i = 1; i <= m; i++) {
        int idx = ord[i];
        while (L > ql[idx]) add(--L);
        while (R < qr[idx]) add(++R);
        while (L < ql[idx]) del(L++);
        while (R > qr[idx]) del(R--);
        ans[qid[idx]] = cur_ans;
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin >> n >> m >> k;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
    }
    // 读入所有询问
    for (int i = 1; i <= m; i++) {
        cin >> ql[i] >> qr[i];
        qid[i] = i;
    }
    solve();
    // 按原顺序输出答案
    for (int i = 1; i <= m; i++) {
        cout << ans[i] << '\n';
    }
    return 0;
}
```

## 复盘备注

易错点：
- add 中先加 2*cnt[x]+1 再 cnt[x]++；del 中先 cnt[x]-- 再减 2*cnt[x]+1，顺序不能反。
- 答案可能达到 n^2 级别（1e10），cur_ans 和 ans 数组需用 long long。
- 块大小取 sqrt(n) 即可；若 m 远大于 n 可调整块大小优化。
- 排序时用询问编号 ord 间接排序，避免复制结构体。
可优化点：块内右端点按奇偶交替排序（奇偶优化）可进一步减少指针移动。
同类题：莫队算法适用于离线区间统计问题，如区间不同数个数、区间众数等。
