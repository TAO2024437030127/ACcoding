## 题目简述

超级超级超级超聪明的章鱼和猫猫进入了地下组织，并拜见了恐龙大王。

恐龙大王说：”我们解密动物园一直掌控在两个动物手里，一个是我，一个是小蝴蝶。可是最近我发现小蝴蝶藏着一个巨大的阴谋，他居然想要把解密动物园的名字改成不解密动物园！猫猫 MBTI 知识如此广博，拯救我们解密动物园的任务就交给你了。“

于是猫猫决定寻找线索。

给定一个包含 $n$ 行、$m$ 列的整数矩阵 $a$，矩阵的行和列均从 $1$ 开始编号。

你可以选择不超过 $k$ 个不同的格子，也可以一个格子都不选择。对于每个被选择的格子 $(i,j)$，将其中的数值 $a_{i,j}$ 变为 $-a_{i,j}$。每个格子最多只能被选择一次。

完成所有操作后，设第 $i$ 行、第 $j$ 列的数值为 $b_{i,j}$，该格子对最终结果的贡献为：

$b_{i,j}\times i-b_{i,j}\times j$

最终矩阵值等于所有格子贡献的总和，即：

$\displaystyle\sum_{i=1}^{n}\sum_{j=1}^{m}(b_{i,j}\times i-b_{i,j}\times j)$

请计算在选择不超过 $k$ 个格子进行反转后，最终矩阵值的最大值。

输入格式
第一行输入三个整数 $n,m,k$（$1\le n,m\le 1000$，$0\le k\le n\times m$），分别表示矩阵的行数、列数以及最多可以反转的格子数量。

接下来 $n$ 行，每行输入 $m$ 个整数。其中第 $i$ 行第 $j$ 个整数为 $a_{i,j}$（$-10^9\le a_{i,j}\le 10^9$）。

输出格式
输出一个整数，表示反转不超过 $k$ 个格子后能够得到的最大矩阵值。

答案可能为负数。

说明/提示
反转之前，每个格子产生的贡献如下：

```
0 -2 -6
4 0 -6
```

猫猫可以反转第 $1$ 行第 $3$ 列和第 $2$ 行第 $3$ 列的数值。

反转之后，每个格子产生的贡献如下：

```
0 -2 6
4 0 6
```

所有格子的贡献之和为 $0-2+6+4+0+6=14$。

可以证明，无法通过其他反转方案得到更大的矩阵值，因此答案为 $14$。

## 解题思路

1. 将每个格子的贡献记为 c[i][j] = a[i][j]*(i-j)，总贡献为所有 c 之和。
2. 翻转格子 (i,j) 会使该格贡献从 c 变为 -c，总和变化量为 -2c。
3. 因此问题转化为：从所有 c 中最多选 k 个，使总和增加量最大；每个 c 的收益为 -2c，且每个格子只能选一次。
4. 由于选择之间互不影响，贪心选择收益为正且最大的那些即可：将所有 c 升序排序，从最小的 c 开始（此时 -2c 最大），若 -2c > 0 则累加并计数，直到选满 k 个或收益非正为止。
5. 正确性：每个格子的翻转决策独立，收益固定；选择任意 k 个格子时，总增加量等于所选格子收益之和，因此选收益最大的至多 k 个正收益格子最优。

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
typedef long long ll;
ll cal(int b,int i,int j){
    return 1LL*b*(i-j);
}
int main(){
    int n,m,k;
    cin>>n>>m>>k;
    vector<vector<int>> num(n+1,vector<int>(m+1));
    for(int i=1;i<=n;i++){
        for(int j=1;j<=m;j++){
            cin>>num[i][j];
        }
    }
    vector<ll> all;
    for(int i=1;i<=n;i++){
        for(int j=1;j<=m;j++){
            all.push_back(cal(num[i][j],i,j));
        }
    }
    sort(all.begin(),all.end());
    ll sum=0;
    int tot=all.size();
    for(int i=0;i<tot;i++){
        sum+=all[i];
    }
    int cnt=0;
    for(int i=0;i<tot;i++){
        if(cnt>=k) break;
        ll d=-2*all[i];
        if(d<=0) break;
        sum+=d;
        cnt++;
    }
    cout<<sum<<endl;
    return 0;
}
```

## 复盘备注

易错点：
- 贡献值可能很大，需用 long long 存储总和与单格贡献。
- 翻转收益为 -2*c，当 c 为负数时收益为正；排序后从最小 c 开始选。
- 若收益为 0 或负，不应继续选择，因为题目允许选择不超过 k 个。
- 答案可能为负，不要初始化为 0 后只取正收益。
可优化点：可用 nth_element 找第 k 小，但排序已足够。
同类题提示：独立选择、贪心取最大收益的模型。
