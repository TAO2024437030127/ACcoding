## 题目简述

猫猫没打败小蝴蝶，于是超级超级超级超聪明的章鱼和猫猫被关进复杂的地下监狱了。

但是猫猫早已知晓小蝴蝶并不是最终大 BOSS，小蝴蝶只是被压力的悲惨干活蝴蝶类 ，所以故意打不过小蝴蝶进而寻找大 BOSS ，而真正的大 BOSS 是小水獭！

现在猫猫想知道他所处的监狱位置和小水獭 BOSS 房间是否联通。

地下监狱可以表示为一个包含 $n$ 个点、$m$ 条边的无向带权图。点按照 $1$ 到 $n$ 编号，每条边连接两个点，并具有一个表示警戒值的正整数权值。

现在有 $q$ 次查询。每次查询给出三个整数 $x,y,z$。在本次查询中：

- 权值大于等于 $z$ 的边无法通行；
- 只有权值严格小于 $z$ 的边可以通行。

请判断只使用本次查询中可以通行的边时，点 $x$ 和点 $y$ 是否连通。

点与自身始终视为连通。每次查询相互独立，查询不会真正修改原图，也不会影响其他查询。

输入格式
第一行输入三个整数 $n,m,q$（$1\le n\le2\times10^5$，$0\le m\le\min(2\times10^5,\dfrac{n(n-1)}2)$，$1\le q\le2\times10^5$），分别表示点数、边数和查询次数。

接下来 $m$ 行，每行输入三个整数 $u,v,w$（$1\le u,v\le n$，$u\ne v$，$1\le w\le10^9$），表示点 $u$ 和点 $v$ 之间有一条警戒值为 $w$ 的无向边。

接下来 $q$ 行，每行输入三个整数 $x,y,z$（$1\le x,y\le n$，$1\le z\le10^9+1$），表示一次查询。

保证图中不存在自环，并且任意两个点之间至多有一条边。

输出格式
对于每次查询：

- 如果点 $x$ 和点 $y$ 连通，输出 YES；
- 否则输出 NO。

每次查询的答案占一行。

说明/提示
对于第一次查询，只有警戒值小于 $6$ 的边可以通行。猫猫可以沿着以下路径移动：

```
1 -> 2 -> 3
```

因此点 $1$ 和点 $3$ 连通，输出 YES。

对于第二次查询，警戒值为 $5$ 的边无法通行，因此点 $1$ 和点 $3$ 不连通，输出 NO。

对于第三次查询，猫猫可以沿着以下路径移动：

```
3 -> 4 -> 5
```

路径上的边权均小于 $8$，因此输出 YES。

## 解题思路

本题是经典的离线连通性查询，使用并查集（DSU）配合排序解决。

1. 将 m 条边按权值 w 从小到大排序。
2. 将 q 次查询按阈值 z 从小到大排序，并记录原始编号。
3. 维护一个指针 pt 指向当前待加入的边。按 z 递增处理查询：对于每个查询，将所有满足 w < z 的边依次加入并查集（合并两端点）。由于查询按 z 递增，边只会被加入一次，指针单调移动。
4. 加入完所有满足条件的边后，查询 x 与 y 的根是否相同，相同则连通（YES），否则不连通（NO）。
5. 将答案按原始查询编号存储，最后按顺序输出。

正确性要点：并查集维护的是当前已加入边形成的连通分量。由于边按权值排序且查询按阈值排序，处理到某个查询时，并查集中恰好包含所有权值小于 z 的边，因此 find(x)==find(y) 等价于仅用这些边 x 与 y 连通。

## 复杂度分析

- 时间复杂度：O(m log m + q log q + (m+q) α(n))，其中 α 为反阿克曼函数，近似常数。
- 空间复杂度：O(n + m + q)。

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
typedef long long ll;
const int MAX=200005;
int fa[MAX];
int find(int u){
    if(fa[u]!=u) fa[u]=find(fa[u]);
    return fa[u];
}
void unite(int u,int v){
    u=find(u);
    v=find(v);
    if(u!=v) fa[v]=u;
}
struct edge{
    int u,v,w;
}e[MAX];
struct qus{
    int x,y,z,id;
}q[MAX];
bool ans[MAX];
int main(){
    int n,m,q1;
    cin>>n>>m>>q1;
    for(int i=1;i<=n;i++){
        fa[i]=i;
    }
    for(int i=1;i<=m;i++){
        cin>>e[i].u>>e[i].v>>e[i].w;
    }
    sort(e+1,e+1+m,[](edge a,edge b){
        return a.w<b.w;
    });
    for(int i=1;i<=q1;i++){
        cin>>q[i].x>>q[i].y>>q[i].z;
        q[i].id=i;
    }
    sort(q+1,q+1+q1,[](qus a,qus b){
        return a.z<b.z;
    });
    int pt=1;
    for(int i=1;i<=q1;i++){
        int z=q[i].z;
        int x=q[i].x;
        int y=q[i].y;
        int idx=q[i].id;
        while(pt<=m&&e[pt].w<z){
            unite(e[pt].u,e[pt].v);
            pt++;
        }
        if(find(x)==find(y)) {
            ans[idx]=true;
        }else{
            ans[idx]=false;
        }
    }
    for(int i=1;i<=q1;i++){
        if(ans[i]){
            cout<<"YES"<<endl;
        }else{
            cout<<"NO"<<endl;
        }
    }
    return 0;
    
}
```

## 复盘备注

易错点：
- 查询条件为边权严格小于 z，因此 while 循环条件应为 e[pt].w < z，不能取等号。
- 查询的 z 可能为 10^9+1，边权最大 10^9，排序和比较时使用 int 即可，但注意不要溢出。
- 并查集路径压缩后，合并时直接令 fa[find(v)] = find(u) 即可，无需按秩合并。
- 输出量较大，建议使用 '\n' 代替 endl 以提高效率。

同类题提示：此类“只允许边权小于/大于某值的边”的连通性查询，通常采用离线排序 + 并查集，或 Kruskal 重构树 + LCA 在线回答。
