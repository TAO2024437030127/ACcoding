## 题目简述

给出一棵二叉树的中序与后序排列。求出它的先序排列。（约定树结点用不同的大写字母表示，且二叉树的节点个数 $ \le 8$）。

输入格式
共两行，均为大写字母组成的字符串，表示一棵二叉树的中序与后序排列。

输出格式
共一行一个字符串，表示一棵二叉树的先序。

说明/提示
**【题目来源】**

## 解题思路

1. 后序遍历的最后一个字符一定是当前子树的根节点，因此每次取 `post.back()` 作为根并输出（先序要求根最先输出）。
2. 在中序序列中找到根的位置 `pos`，则中序中 `[0, pos)` 为左子树，`(pos, end)` 为右子树。
3. 根据左子树节点个数 `pos`，在后序序列中划分：前 `pos` 个字符为左子树后序，剩余 `post.size()-pos-1` 个字符为右子树后序。
4. 递归处理左子树和右子树，由于先序顺序为“根-左-右”，在递归前输出根即可得到先序序列。
5. 递归终止条件：当前中序（或后序）为空，说明子树为空，直接返回。
正确性要点：后序末尾必为根，中序根位置唯一划分左右子树，递归划分与真实树结构一致，输出顺序符合先序定义。

## 复杂度分析

- 时间复杂度：O(n^2)（每次 `find` 和 `substr` 为 O(n)，递归深度 O(n)，n≤8 可忽略）
- 空间复杂度：O(n)（递归栈深度与临时字符串，n≤8）

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
void build(string mid,string post){
    if(mid.empty()) return ;
    char root=post.back();
    cout<<root;
    int pos=mid.find(root);
    build(mid.substr(0,pos),post.substr(0,pos));
    build(mid.substr(pos+1),post.substr(pos,post.size()-pos-1));
}
int main(){
    string mid,post;
    cin>>mid>>post;
    build(mid,post);
    return 0;
}
```

## 复盘备注

易错点：递归右子树时后序区间起点为 `pos`，长度为 `post.size()-pos-1`，不要写成 `pos+1`；空串判断用 `mid.empty()` 即可。可优化点：可传下标区间避免 `substr` 拷贝，但本题规模极小无需优化。同类题：已知中序+前序求后序（P1305 等），思路对称。
