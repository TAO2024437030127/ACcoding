## 题目简述

给你三个整数 $a,b,p$，求 $a^b \bmod p$。

输入格式
输入只有一行三个整数，分别代表 $a,b,p$。

输出格式
输出一行一个字符串 `a^b mod p=s`，其中 $a,b,p$ 分别为题目给定的值， $s$ 为运算结果。

说明/提示
**样例解释**

$2^{10} = 1024$，$1024 \bmod 9 = 7$。

**数据规模与约定**

对于 $100\%$ 的数据，保证 $0\le a,b < 2^{31}$，$a+b>0$，$2 \leq p \lt 2^{31}$。

## 解题思路

本题是快速幂模板题，核心是把指数 b 按二进制拆分，从而在 O(log b) 次乘法内完成幂运算。

1. 关键观察：a^b = a^(b 的二进制各位权值之和)，例如 b=10=(1010)_2，则 a^10 = a^8 * a^2。
2. 算法选择：使用迭代快速幂。维护底数 a 和答案 ans，初始 ans=1。
3. 循环处理：当 b>0 时，若 b 的最低位为 1，则把当前 a 乘入 ans 并对 p 取模；随后 a 自乘并对 p 取模，b 右移一位。
4. 正确性要点：每一步乘法后都取模，保证中间结果不溢出且最终结果与直接计算 a^b mod p 一致；b 的每个二进制位恰好被处理一次，因此答案正确。
5. 边界处理：b=0 时循环不执行，返回 1，符合 a^0=1（题目保证 a+b>0，故不会出现 0^0 的歧义）。

## 复杂度分析

- 时间复杂度：O(log b)
- 空间复杂度：O(1)

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
typedef long long ll;
ll a,b,p;
ll fp(ll a,ll b,ll mod){
    ll ans=1;
    while(b>0){
        if(b&1){
            ans=(ans*a)%mod;
        }
        a=(a*a)%mod;
        b>>=1;
    }
    return ans;
}
int main(){
    cin>>a>>b>>p;
    int ans=fp(a,b,p);
    cout<<a<<"^"<<b<<" mod "<<p<<"="<<ans<<endl;
    return 0;
}
```

## 复盘备注

易错点：
- 中间乘法可能超过 int 范围，应使用 long long 存储 a、b、p 和 ans。
- 输出格式必须严格为“a^b mod p=s”，注意空格和等号位置。
- 代码中 ans 用 int 接收 fp 的返回值，虽然本题 p<2^31 时结果在 int 范围内，但建议统一用 long long 更稳妥。

可优化点：
- 可将 ans 声明为 long long，避免隐式转换。

同类题提示：快速幂常用于模意义下的幂运算、矩阵快速幂、求逆元（结合费马小定理）等。
