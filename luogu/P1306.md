## 题目简述

对于 Fibonacci 数列：

$$ f_i = \begin{cases}
[i = 1] & i \leq 1 \\
f_{i - 1} + f_{i - 2} & i \gt 1
\end{cases}$$

请求出 $f_n$ 与 $f_m$ 的最大公约数，即 $\gcd(f_n, f_m)$。

输入格式
一行两个正整数 $n$ 和 $m$ 。

输出格式
输出一行一个整数，代表 $f_n$ 和 $f_m$ 的最大公约数。答案请对 $10^8$ 取模。

说明/提示
#### 数据规模与约定

- 对于 $100\%$ 的数据，保证 $1 \leq n, m \leq 10^9$。

## 样例

### 样例 1

输入：
```text
4 7
```

输出：
```text
1
```

## 解题思路

关键观察：斐波那契数列满足恒等式 gcd(f_n, f_m) = f_{gcd(n,m)}，因此问题转化为求第 d = gcd(n,m) 项斐波那契数。由于 d 可达 10^9，不能递推，采用矩阵快速幂加速。斐波那契的转移矩阵为 [[0,1],[1,1]]，有 [[f_{k-1}, f_k], [f_k, f_{k+1}]] = M^k。代码中先计算 d = gcd(n1,n2)，然后对 M 做 d-1 次幂，结果矩阵的 (1,1) 位置即 f_d（0-indexed 行列为 0,1）。乘法时用 __int128 防止中间乘积溢出，每一步对 10^8 取模。正确性由 gcd 恒等式和矩阵幂的数学性质保证。

## 复杂度分析

- 时间复杂度：O(log n + log m)
- 空间复杂度：O(1)

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
typedef long long ll;
const int Mod=1e8;
using mat=vector<vector<ll>>;

mat mal(mat &a,mat &b){
    int n=a.size();
    mat c(n,vector<ll>(n,0));
    for(int i=0;i<n;i++){
        for(int k=0;k<n;k++){
            if(a[i][k]){
                for(int j=0;j<n;j++){
                    c[i][j]=(c[i][j]+(__int128)a[i][k]*b[k][j])%Mod;
                }
            }
        }
    }
    return c;
}

mat qpow(mat a,ll p){
    int n=a.size();
    mat res(n,vector<ll>(n,0));
    for(int i=0;i<n;i++){
        res[i][i]=1;
    }
    while(p){
        if(p&1){
            res=mal(a,res);
        }
        a=mal(a,a);
        p>>=1;
    }
    return res;
}

ll gcd(ll a, ll b) {
    if(b == 0) return a;
    return gcd(b, a % b);
}

int main(){
    mat m={{0,1},{1,1}};
    ll n1,n2;
    cin>>n1>>n2;
    ll d = gcd(n1,n2);   //先求下标gcd
    mat ans=qpow(m, d-1); //求F_d
    ll res = ans[1][1] % Mod;
    cout<<res<<endl;
    return 0;
}
```

## 复盘备注

易错点：1) 矩阵快速幂中乘法顺序需注意，代码中 res=mal(a,res) 与常规写法等价，但需确保矩阵乘法满足结合律；2) 取模数为 10^8，不是质数，但只涉及乘法和加法，无需逆元；3) 当 d=1 时，qpow 返回单位矩阵，ans[1][1]=1，正确输出 f_1=1；4) 使用 __int128 避免 long long 溢出。可优化点：矩阵规模固定为 2x2，可展开为标量运算减少常数。同类题：P1962 斐波那契数列、P1349 广义斐波那契数列。
