## 题目简述

猫猫根据线索发现了宝箱，但是宝箱缺被上锁了，这时，恐龙大王告诉猫猫一个在解密动物园的秘辛：“传说中，宝箱的密码是揭秘动物园里动物的相反度，只有精通 MBTI 的动物才能解开它......”

动物园中共有 $n$ 只动物，每只动物都有一个 MBTI 类型。

一个 MBTI 类型是一个长度为 $4$ 的字符串，其中：

- 第一个字母为 `I` 或 `E`；
- 第二个字母为 `N` 或 `S`；
- 第三个字母为 `F` 或 `T`；
- 第四个字母为 `J` 或 `P`。

对于两只动物，将它们的 MBTI 按照相同位置进行比较。四个位置中字母不同的位置数量，称为这两只动物的相反度。

例如，INFJ 和 INTJ 只有第三个位置的字母不同，因此它们的相反度为 $1$。

现在给定所有动物的 MBTI 类型以及一个整数 $k$。对于每一对满足 $1\le i<j\le n$ 的动物 $i$ 和动物 $j$，计算它们的相反度。

请计算其中有多少对动物的相反度恰好为 $k$。

输入格式
第一行输入两个整数 $n,k$（$2 \le n \le 2\times 10^5$，$0 \le k \le 4$），分别表示动物数量和指定的相反度。

接下来 $n$ 行，每行输入一个长度为 $4$ 的字符串 $s_i$，表示第 $i$ 只动物的 MBTI 类型。

保证每个 $s_i$ 都是符合题目描述中四个位置要求的合法 MBTI 类型。

不同动物的 MBTI 类型可能相同。

输出格式
输出一个整数，表示相反度恰好为 $k$ 的动物对数量。

动物对不考虑顺序，即动物 $i$ 与动物 $j$ 组成的动物对，与动物 $j$ 和动物 $i$ 组成的动物对视为同一对。

说明/提示
满足条件的动物对包括：

- INFJ 和 INTJ，共有 $2$ 对；
- INFJ 和 ENFJ，共有 $2$ 对；
- INTJ 和 ENTJ，共有 $1$ 对；
- ENFJ 和 ENTJ，共有 $1$ 对。

因此，相反度恰好为 $1$ 的动物对共有 $6$ 对。

## 解题思路

关键观察：MBTI 每个位置只有两种取值，因此整个类型只有 2^4=16 种可能。可以把每个字符串编码成 0~15 的整数：四个位置分别用 1 个二进制位表示，例如 E/S/T/P 各置对应位为 1，I/N/F/J 为 0。

算法步骤：
1. 读入 n 个字符串，用 encode 函数转成 0~15 的整数，统计每种编码出现的次数 cnt[0..15]。
2. 枚举所有编码对 (i,j)，其中 0≤i≤j≤15。
3. 用 getdif(i,j) 计算 i 和 j 的二进制表示中不同位的个数，即两只动物的相反度。
4. 若 getdif(i,j)==k：
   - 当 i==j 时，同类内部两两配对，贡献 cnt[i]*(cnt[i]-1)/2；
   - 当 i<j 时，不同类之间配对，贡献 cnt[i]*cnt[j]。
5. 累加所有贡献即为答案。

正确性要点：编码是一一对应的，二进制不同位数恰好等于 MBTI 四个位置的不同字母数；枚举所有编码对并按组合数计数，不重不漏地统计了所有无序动物对。

## 复杂度分析

- 时间复杂度：O(n + 16^2 * 4)，即 O(n)，因为编码种类固定为 16。
- 空间复杂度：O(16)，仅需常数大小的计数数组。

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
typedef long long ll;
int encode(string s){
    int num=0;
    if(s[0]=='E'){
        num+=8;
    }
    if(s[1]=='S'){
        num+=4;
    }
    if(s[2]=='T'){
        num+=2;
    }
    if(s[3]=='P'){
        num+=1;
    }
    return num;
}


int getdif(int a,int b){
    int cnt=0;
    int x=a^b;
    while(x>0){
        if(x%2==1){
            cnt+=1;
        }
        x/=2;
    }
    return cnt;
}

int main(){
    int n,k;
    cin>>n>>k;
    vector<ll> cnt(16,0);
    for(int i=1;i<=n;i++){
        string s;
        cin>>s;
        int num=encode(s);
        cnt[num]++;
    }
    long long ans=0;
    for(int i=0;i<=15;i++){
        for(int j=i;j<=15;j++){
            if(getdif(i,j)!=k){
                continue;
            }
            if(i==j){
                long long t=cnt[i];
                ans=ans+t*(t-1)/2;
            }else{
                ans=ans+cnt[i]*cnt[j];
            }
        }
    }
    cout<<ans<<endl;
    return 0;
}
```

## 复盘备注

易错点：
- 答案可能达到 O(n^2) 量级，必须用 long long 存储。
- 同类配对时要用组合数 t*(t-1)/2，不能直接乘。
- 枚举时 j 从 i 开始，避免重复计数。

可优化点：getdif 可以直接用 __builtin_popcount(a^b) 替代手写循环，更简洁高效。

同类题提示：当状态空间很小时，先压缩状态再枚举状态对是常见技巧，类似“统计异或和”或“统计汉明距离”类问题。
