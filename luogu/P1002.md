## 题目简述

棋盘上 $A$ 点有一个过河卒，需要走到目标 $B$ 点。卒行走的规则：可以向下、或者向右。同时在棋盘上 $C$ 点有一个对方的马，该马所在的点和所有跳跃一步可达的点称为对方马的控制点。因此称之为“马拦过河卒”。

棋盘用坐标表示，$A$ 点 $(0, 0)$、$B$ 点 $(n, m)$，同样马的位置坐标是需要给出的。

![](https://cdn.luogu.com.cn/upload/image_hosting/ipmwl52i.png)

现在要求你计算出卒从 $A$ 点（不经过马的控制点）能够到达 $B$ 点的路径的条数，假设马的位置是固定不动的，并不是卒走一步马走一步。

输入格式
一行四个正整数，分别表示 $B$ 点坐标和马的坐标。

输出格式
一个整数，表示所有的路径条数。

说明/提示
对于 $100 \%$ 的数据，$1 \le n, m \le 20$，$0 \le$ 马的坐标 $\le 20$。

保证起点不是马的控制点。

## 解题思路

1. 用二维布尔数组 block 标记马的位置及其八个跳跃可达点，注意只标记落在 [0,n]×[0,m] 范围内的点。
2. 设 dp[i][j] 表示从 (0,0) 到达 (i,j) 且不经过控制点的路径数。
3. 初始化 dp[0][0]=1（题目保证起点不是控制点，代码中仍做了判断）。
4. 按行优先遍历所有格子：若 (i,j) 是控制点，则 dp[i][j]=0；否则 dp[i][j] 等于上方 dp[i-1][j]（i>0 时）与左方 dp[i][j-1]（j>0 时）之和。
5. 最终 dp[n][m] 即为答案。由于路径数可能较大，使用 long long 存储。

## 代码

```cpp
#include<bits/stdc++.h>
using namespace std;
int grip[25][25]={0};
int n,m,a,b;
int main(){
    cin>>n>>m>>a>>b;
    vector<vector<bool>> block(n+5,vector<bool>(m+5,false));
    block[a][b]=true;
    int dx[8]={-2, -1, 1, 2, 2, 1, -1, -2};
    int dy[8]={1, 2, 2, 1, -1, -2, -2, -1};
    for(int i=0;i<8;i++){
        int nx=a+dx[i];
        int ny=b+dy[i];
        if(nx>=0&&nx<=n&&ny>=0&&ny<=m){
            block[nx][ny]=true;
        }
    }
    vector<vector<long long>> dp(n+1,vector<long long>(m+1,0));
    if (!block[0][0]) {
        dp[0][0] = 1;
    }

    for (int i = 0; i <= n; ++i) {
        for (int j = 0; j <= m; ++j) {
            // 如果是起点，已经初始化过了，跳过
            if (i == 0 && j == 0) continue;

            // 如果当前点是马的控制点，路径数为 0
            if (block[i][j]) {
                dp[i][j] = 0;
            } else {
                // 状态转移：累加从上方走来的路径
                if (i > 0) {
                    dp[i][j] += dp[i - 1][j];
                }
                // 状态转移：累加从左方走来的路径
                if (j > 0) {
                    dp[i][j] += dp[i][j - 1];
                }
            }
        }
    }

    // 输出到达 B 点 (n, m) 的路径总数
    cout << dp[n][m] << endl;
    return 0;

}
```

## 复盘备注

易错点：马的控制点坐标可能为负或超出棋盘，标记前需判断范围；起点 (0,0) 需要单独初始化，循环中要跳过以免重复累加；路径数可能超过 int 范围，需用 long long。可优化点：dp 可压缩为一维数组，按行滚动更新。同类题提示：带障碍的网格路径计数问题，通常用动态规划按行/列递推。
