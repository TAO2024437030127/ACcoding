## 题目简述

有一个 $1 \times n$ 的矩阵，有 $n$ 个整数。

现在给你一个可以盖住连续 $k$ 个数的木板。

一开始木板盖住了矩阵的第 $1 \sim k$ 个数，每次将木板向右移动一个单位，直到右端与第 $n$ 个数重合。

每次移动前输出被覆盖住的数字中最大的数是多少。

输入格式
第一行两个整数 $n,k$，表示共有 $n$ 个数，木板可以盖住 $k$ 个数。

第二行 $n$ 个整数，表示矩阵中的元素。

输出格式
共 $n - k + 1$ 行，每行一个整数。

第 $i$ 行表示第 $i \sim i + k - 1$ 个数中最大值是多少。

说明/提示
对于 $20\%$ 的数据，$1 \leq k \leq n \leq 10^3$。

对于 $50\%$ 的数据，$1 \leq k \leq n \leq 10^4$。

对于 $100\%$ 的数据，$1 \leq k \leq n \leq 2 \times 10^6$，矩阵中的元素大小不超过 $10^4$ 并且均为正整数。

## 解题思路

本题是固定长度滑动窗口最大值问题，使用单调队列（双端队列 deque）维护窗口内元素下标的单调递减序列。

1. 遍历数组每个下标 i：
   - 入队前，从队尾弹出所有对应值小于等于 num[i] 的下标，保证队列中下标对应的值从队头到队尾严格递减；
   - 将当前下标 i 压入队尾；
   - 检查队头下标是否已经滑出窗口（即 q.front() <= i-k），若是则从队头弹出；
   - 当 i >= k-1 时，窗口已完整形成，队头下标对应的值即为当前窗口最大值，输出 num[q.front()]。

2. 正确性要点：
   - 队列中始终保存当前窗口内可能成为最大值的候选下标，且值单调递减，因此队头就是窗口最大值；
   - 弹出队尾时使用 >= 可以保证相同值时保留较新的下标，避免旧下标过早过期导致误删；
   - 先入队再检查过期，保证当前元素参与窗口；过期检查放在入队后，确保队头始终有效。

3. 由于 n 可达 2×10^6，使用 O(n) 的单调队列而非 O(nk) 的暴力扫描，并通过 ios::sync_with_stdio(false) 和 cin.tie(nullptr) 加速输入输出。

## 复杂度分析

- 时间复杂度：O(n)，每个元素最多入队一次、出队一次
- 空间复杂度：O(n)，存储原数组和双端队列

## 代码

```text
#include<iostream>
#include<vector>
#include<deque>
using namespace std;
int main(){
    int n,k;
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin>>n>>k;
    vector<int> num(n);
    for(int i=0;i<n;i++){
        cin>>num[i];
    }
    deque<int> q;
    for(int i=0;i<n;i++){
        while(!q.empty()&&num[i]>=num[q.back()]){
            q.pop_back();
        }
        q.push_back(i);
        while(q.front()<=i-k){
            q.pop_front();
        }
        if(i>=k-1){
            cout<<num[q.front()]<<endl;
        }
    }
    return 0;
}
```

## 复盘备注

易错点：
- 过期判断应使用 q.front() <= i-k，而不是 < i-k；
- 弹出队尾时用 >= 而非 >，否则相同值可能保留旧下标，导致窗口最大值过期后误删；
- 输出条件 i >= k-1 不能漏，否则会提前输出不完整窗口的最大值。

可优化点：
- 本题元素均为正整数且不超过 10^4，也可用分块或计数方法，但单调队列已是最优通用解法；
- 若内存紧张，可边读边处理，但需注意窗口形成前不能输出。
