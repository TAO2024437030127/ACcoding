## 题目简述

小 L 的大学生活很忙碌。现在是这学期**第一周的周六早上 $8:00$**，她在检查自己的作业。

大学里的课程多样，每一门课程会有一个**开课星期 $w(1\le w\le 5)$** 和**开课间隔 $d$**，表示第一周开课后，过 $d$ 周会再次开课，并且每次开课一定在周 $w$。例如，一门 $w=4,d=2$ 的课程会在第一周周四、第三周周四、第五周周四，... 开课。**除第一次课外，每一次课都会要求同学们上交上一次课的作业。**

这学期她报名了 $n$ 个课程，这些课程都有作业。给出所有课程的开课星期和开课间隔，求她再过几天就需要上交第一份作业。

输入格式
输入的第一行有一个正整数 $n$，表示小 L 的课程数量。

之后 $n$ 行，每行有两个正整数 $w$ 和 $d$，表示一门课程的开课星期和开课间隔。

输出格式
输出一行一个正整数，表示小 L 再过几天就要上交第一份作业。

说明/提示

## 解题思路

关键观察：每门课第一次开课在第 1 周的星期 w，之后每隔 d 周开一次，因此第 k 次开课（k≥2）在第 1+(k-1)d 周的星期 w。第一次需要交作业对应第二次开课，即第 1+d 周的星期 w。

从当前时刻（第一周周六早上 8:00）到第 1+d 周星期 w 的天数计算：
- 当前是周六，一周中周六可视为第 6 天（若周一为 1，则周日为 7，周六为 6）。
- 从本周六到本周日需要 1 天，到下周星期一需要 2 天，一般地，到星期 w 需要 (7 - 6 + w) 天？更直接：当前周六之后，到星期 w 的天数为 (w - 6 + 7) % 7，但 w≤5，所以 w-6 为负，加 7 得 w+1 天。例如 w=1（周一）需 2 天，w=4（周四）需 5 天。
- 但目标周是第 1+d 周，比当前周（第 1 周）多 d 周，即多 7d 天。因此总天数 = 7d + (w+1)？验证样例1：w=4,d=2，7*2+(4+1)=19，但答案是 12，不对。

重新理解：当前是第 1 周周六，目标第 1+d 周星期 w。从第 1 周周六到第 1+d 周星期 w 的天数 = 从第 1 周周六到第 2 周星期 w 的天数 + (d-1)*7。从周六到下周星期 w 的天数 = (w - 6 + 7) % 7，但 w≤5，所以 = w+1。因此总天数 = (w+1) + 7(d-1) = 7d + w - 6。验证样例1：w=4,d=2 => 14+4-6=12，正确；w=1,d=3 => 21+1-6=16，正确。样例2：w=1,d=1 => 7+1-6=2，正确。

因此每门课第一次交作业的天数为 7d + w - 6，取所有课程的最小值即可。代码中 gap=6-w，则 7d - gap = 7d - (6-w) = 7d + w - 6，与公式一致。

正确性要点：每门课独立计算第二次开课时间，取最小即为第一份作业时间；公式推导基于周期间隔和星期偏移，无遗漏。

## 代码

```text
#include<iostream>
using namespace std;
int main(){
    int n;
    cin>>n;
    int w,d;
    int ans=1000000;
    while(n--){
        cin>>w>>d;
        int gap=6-w;
        if(7*d-gap<ans){
            ans=7*d-gap;
        }
    }
    cout<<ans;
    return 0;
}
```

## 复盘备注

易错点：注意当前是周六，不是周日；公式 7d + w - 6 中 w 为 1~5，结果恒为正。可优化点：无需存储所有课程，边读边更新最小值。同类题提示：周期事件的最小等待时间，注意起始时刻和周期偏移。
