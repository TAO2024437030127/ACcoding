## 题目简述

给定一个二分图，其左部点的个数为 $n$，右部点的个数为 $m$，边数为 $e$，求其最大匹配的边数。

左部点从 $1$ 至 $n$ 编号，右部点从 $1$ 至 $m$ 编号。

输入格式
输入的第一行是三个整数，分别代表 $n$，$m$ 和 $e$。

接下来 $e$ 行，每行两个整数 $u, v$，表示存在一条连接左部点 $u$ 和右部点 $v$ 的边。

输出格式
输出一行一个整数，代表二分图最大匹配的边数。

说明/提示
#### 数据规模与约定

对于全部的测试点，保证：
- $1 \leq n, m \leq 500$。
- $1 \leq e \leq 5 \times 10^4$。
- $1 \leq u \leq n$，$1 \leq v \leq m$。

**不保证给出的图没有重边**。

## 解题思路

采用匈牙利算法求二分图最大匹配。
- 用邻接表 g[u] 存左部点 u 连向右部点的所有边。
- match[v] 记录右部点 v 当前匹配的左部点编号，0 表示未匹配。
- 对每个左部点 i 依次尝试增广：清空 vis 数组后调用 dfs(i)。
- dfs(u) 枚举 u 的所有邻边 v：若 v 在本轮未被访问，则标记 vis[v]=1；若 v 未匹配或 match[v] 能通过递归找到新的匹配，则令 match[v]=u 并返回成功。
- 每成功增广一次答案加一，最终 res 即最大匹配数。
正确性由增广路定理保证：当不存在增广路时当前匹配即为最大匹配。

## 复杂度分析

- 时间复杂度：O(n·e)
- 空间复杂度：O(n+m+e)

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
typedef long long ll;
const int MAXN=505;
vector<int> g[MAXN];
int match[MAXN];
int vis[MAXN];
int n,m,e;

bool dfs(int u){
    for(int v:g[u]){
        if(vis[v]) continue;
        vis[v]=1;
        if(match[v]==0||dfs(match[v])){
            match[v]=u;
            return true;
        }
    }
    return false;
}


int hungarian(){
    int res=0;
    for(int i=1;i<=n;i++){
        memset(vis,0,sizeof(vis));
        if(dfs(i)) res++;
    }
    return res;
}
void add_edge(int u,int v){
    g[u].push_back(v);
    
}
int main(){
    cin>>n>>m>>e;

    for(int i=1;i<=e;i++){
        int u,v;
        cin>>u>>v;
        add_edge(u,v);
        
    }
    int ans=hungarian();
    cout<<ans;

    
    
}
```
