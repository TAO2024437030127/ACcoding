## 题目简述

给出一组包含 $m$ 个不等式，有 $n$ 个未知数的形如：

$$ \begin{cases} x_{c_1}-x_{c'_1}\leq y_1 \\x_{c_2}-x_{c'_2} \leq y_2 \\ \cdots\\ x_{c_m} - x_{c'_m}\leq y_m\end{cases}$$

的不等式组，求任意一组满足这个不等式组的解。

输入格式
第一行为两个正整数 $n,m$，代表未知数的数量和不等式的数量。

接下来 $m$ 行，每行包含三个整数 $c,c',y$，代表一个不等式 $x_c-x_{c'}\leq y$。

输出格式
一行，$n$ 个数，表示 $x_1 , x_2 \cdots x_n$ 的一组可行解，如果有多组解，请输出任意一组，无解请输出 `NO`。

说明/提示
**样例解释**

$\begin{cases}x_1-x_2\leq 3 \\ x_2 - x_3 \leq -2 \\ x_1 - x_3 \leq 1 \end{cases}$

一种可行的方法是 $x_1 = 5, x_2 = 3, x_3 = 5$。

$\begin{cases}5-3 = 2\leq 3 \\ 3 - 5 = -2 \leq -2 \\ 5 - 5 = 0\leq 1 \end{cases}$

**数据范围**

对于 $100\%$ 的数据，$1\leq n,m \leq 5\times 10^3$，$-10^4\leq y\leq 10^4$，$1\leq c,c'\leq n$，$c \neq c'$。

**评分策略**

你的答案符合该不等式组即可得分，请确保你的答案中的数据在 `int` 范围内。

如果并没有答案，而你的程序给出了答案，SPJ 会给出 `There is no answer, but you gave it`，结果为 WA；
如果并没有答案，而你的程序输出了 `NO`，SPJ 会给出 `No answer`，结果为 AC；
如果存在答案，而你的答案错误，SPJ 会给出 `Wrong answer`，结果为 WA；
如果存在答案，且你的答案正确，SPJ 会给出 `The answer is correct`，结果为 AC。

## 解题思路

1. 将不等式 x_c - x_c' ≤ y 转化为有向边 c' → c，边权为 y，表示 dis[c] ≤ dis[c'] + y。
2. 引入超级源点 0，向每个节点 i 连一条权值为 0 的边，保证图连通且所有节点可达。
3. 从源点 0 跑 SPFA 求最短路。若图中存在负环，则不等式组无解；否则 dis[i] 即为 x_i 的一组可行解。
4. 正确性：最短路满足三角不等式 dis[v] ≤ dis[u] + w，对应原不等式；负环意味着存在 x_c - x_c' ≤ y 的循环约束矛盾，故无解。
5. 代码中 cnt[v] 记录节点入队次数，超过 n+1 判定负环；dis 初始化为 INF，源点 dis[0]=0。

## 复杂度分析

- 时间复杂度：O(nm)（SPFA 最坏情况，n,m ≤ 5×10^3）
- 空间复杂度：O(n+m)

## 代码

```cpp
#include<bits/stdc++.h>
using namespace std;
typedef long long ll;
const int MAXN=1e4+10;
const int INF=0x3f3f3f3f;
int dis[MAXN],cnt[MAXN],inq[MAXN];
vector<pair<int,int>> g[MAXN];
int n,m;
void add_edge(int u,int v,int ww){
    g[u].push_back({v,ww});
}
bool diff_constraint(){
    queue<int> q;
    for(int i=0;i<=n;i++){
        dis[i]=INF;
        cnt[i]=0;
        inq[i]=0;
    }
    dis[0]=0;
    for(int i=1;i<=n;i++){
        add_edge(0,i,0);
        
    }
    q.push(0);
    inq[0]=1;
    while(!q.empty()){
        int u=q.front();
        q.pop();
        inq[u]=0;
        for(auto ed:g[u]){
            int v=ed.first;
            int w=ed.second;
            if(dis[v]>dis[u]+w){
                dis[v]=dis[u]+w;
                if(!inq[v]){
                    q.push(v);
                    inq[v]=1;
                    if(++cnt[v]>n+1){
                        return false;
                    }
                }
            }
            
        }
    }
    return true;
}

int main(){
    cin>>n>>m;
    for(int i=1;i<=m;i++){
        int u,v,w;
        cin>>u>>v>>w;
        add_edge(v,u,w);
        
    }
    if(diff_constraint()){
        for(int i=1;i<=n;i++){
        cout<<dis[i]<<" ";
    }
    }else{
        cout<<"NO";
    }
    
    return 0;
    
}
```

## 复盘备注

易错点：
- 边方向不要建反：x_c - x_c' ≤ y 对应边 c' → c，权值 y。
- 超级源点 0 到所有点连权值 0 的边，保证每个点都能被松弛到。
- 负环判定阈值用 n+1（含源点共 n+1 个点），入队次数超过 n+1 即无解。
- 输出时 dis 在 int 范围内，无需 long long。
可优化点：
- 可将 SPFA 换成 Bellman-Ford 或队列优化，本题规模 SPFA 足够。
- 若需输出非负解，可整体平移，但题目只要求任意解。
同类题：P3275 糖果、P1993 小 K 的农场等差分约束模板题。
