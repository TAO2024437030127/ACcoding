## 题目简述

要保护环境。

木材厂有 $n$ 根原木，现在想把这些木头切割成 $k$ 段长度**均**为 $l$ 的小段木头（木头有可能有剩余）。

当然，我们希望得到的小段木头越长越好，请求出 $l$ 的最大值。

木头长度的单位是 $\text{cm}$，原木的长度都是正整数，我们要求切割得到的小段木头的长度也是正整数。

例如有两根原木长度分别为 $11$ 和 $21$，要求切割成等长的 $6$ 段，很明显能切割出来的小段木头长度最长为 $5$。

输入格式
第一行是两个正整数 $n,k$，分别表示原木的数量，需要得到的小段的数量。

接下来 $n$ 行，每行一个正整数 $L_i$，表示一根原木的长度。

输出格式
仅一行，即 $l$ 的最大值。

如果连 $\text{1cm}$ 长的小段都切不出来，输出 `0`。

说明/提示
#### 数据规模与约定

对于 $100\%$ 的数据，有 $1\le n\le 10^5$，$1\le k\le 10^8$，$1\le L_i\le 10^8(i\in[1,n])$。

## 解题思路

1. 关键观察：若长度 l 能切出至少 k 段，则任意更小的长度也能切出至少 k 段，答案具有单调性。
2. 算法选择：对 l 在 [1, max(L_i)] 上二分答案。
3. 判定函数 check(len)：遍历所有原木，累加每根能切出的段数 a[i]/len，若总和 ≥ k 则可行。
4. 二分细节：可行时记录 ans 并向右半区间收缩（l = mid + 1），不可行时向左收缩（r = mid - 1）。
5. 正确性要点：check 统计的是每根原木独立切割的段数之和，符合题意；二分保证最终 ans 是满足条件的最大整数长度。
6. 边界处理：初始 ans = 0，若没有任何长度可行则输出 0。

## 复杂度分析

- 时间复杂度：O(n log(max L_i))
- 空间复杂度：O(n)

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
typedef long long ll;

ll check(const vector<ll>& a, ll len){
    ll cnt = 0;
    int sz = (int)a.size()-1;
    for(int i = 1; i <= sz; i++){
        cnt += a[i]/len;
    }
    return cnt;
}

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    ll n,k;
    cin >> n >> k;
    vector<ll> mt(n+1,0);
    ll r = 0;
    for(int i = 1; i <= n; i++){
        cin >> mt[i];
        r = max(r, mt[i]);
    }
    ll l = 1;
    ll ans = 0;
    while(l <= r){
        ll mid = (l + r)/2;
        ll res = check(mt, mid);
        if(res >= k){
            ans = mid;
            l = mid + 1;
        }else{
            r = mid - 1;
        }
    }
    cout << ans << endl;
    return 0;
}
```

## 复盘备注

易错点：段数累加可能超过 int 范围，需用 long long；二分区间上界取 max(L_i) 即可，无需更大。可优化点：读入时同步维护最大值。同类题：二分答案求最大化最小值或最小化最大值，如砍树、跳石头。
