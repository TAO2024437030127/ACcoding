## 题目简述

给定一个正整数 $a$，分别按以下两种顺序执行操作，输出结果：
- **小Y的顺序**：$a \leftarrow a+5$，然后 $a \leftarrow a \times 3$，输出 $a$
- **小L的顺序**：$a \leftarrow a \times 3$，然后 $a \leftarrow a+5$，输出 $a$

输出小Y和小L的结果。

输入格式
- 一行一个正整数 $a$

输出格式
- 一行两个整数，分别表示小Y的结果和小L的结果，用空格分隔

说明/提示
- $1 \le a \le 28$，且 $a$ 为正整数
- **样例1解释**：
- 小Y：$(4+5) \times 3 = 27$
- 小L：$4 \times 3 + 5 = 17$

## 样例

### 样例 1

输入：
```text
4
```

输出：
```text
27 17
```

## 解题思路

1. 读入整数 a，并用临时变量 temp 保存原始值，因为计算小Y结果后 a 已被修改。
2. 小Y顺序：先执行 a = a + 5，再执行 a = a * 3，合并为 a = (a + 5) * 3，输出该结果。
3. 恢复 a = temp，再按小L顺序计算 a * 3 + 5，输出该结果。
4. 两次输出之间用空格分隔，末尾无需多余空格。
正确性要点：利用临时变量保存原始输入，保证两次计算基于同一个初始 a；运算顺序与题目描述严格一致。

## 代码

```text
#include<iostream>
using namespace std;
int main(){
    int a;
    cin>>a;
    int temp=a;
    a=(a+5)*3;
    cout<<a<<" ";
    a=temp;
    cout<<a*3+5;
    return 0;
}
```

## 复盘备注

易错点：计算小Y结果后 a 已被覆盖，若不保存原始值会导致小L结果错误；输出格式要求两个整数间一个空格。可优化点：也可用两个变量分别计算，避免恢复操作。
