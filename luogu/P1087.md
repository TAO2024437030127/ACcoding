## 题目简述

我们可以把由 0 和 1 组成的字符串分为三类：全 0 串称为 B 串，全 1 串称为 I 串，既含 0 又含 1 的串则称为 F 串。

FBI 树是一种二叉树，它的结点类型也包括 F 结点，B 结点和 I 结点三种。由一个长度为 $2^N$ 的 01 串 $S$ 可以构造出一棵 FBI 树 $T$，递归的构造方法如下：

1. $T$ 的根结点为 $R$，其类型与串 $S$ 的类型相同；
2. 若串 $S$ 的长度大于 $1$，将串 $S$ 从中间分开，分为等长的左右子串 $S_1$ 和 $S_2$；由左子串 $S_1$ 构造 $R$ 的左子树 $T_1$，由右子串 $S_2$ 构造 $R$ 的右子树 $T_2$。

现在给定一个长度为 $2^N$ 的 01 串，请用上述构造方法构造出一棵 FBI 树，并输出它的后序遍历序列。

输入格式
第一行是一个整数 $N(0 \le N \le 10)$，

第二行是一个长度为 $2^N$ 的 01 串。

输出格式
一个字符串，即 FBI 树的后序遍历序列。

说明/提示
对于 $40\%$ 的数据，$N \le 2$；

对于全部的数据，$N \le 10$。

## 解题思路

1. 观察构造规则：每个结点对应原串的一个连续区间，根对应 [0, 2^N-1]，左右子结点分别对应区间对半分的两段。
2. 后序遍历要求先左子树、再右子树、最后根结点，因此递归函数 dfs(l, r) 先递归处理 [l, mid] 和 [mid+1, r]，再输出当前区间的类型。
3. 当前区间类型只需判断是否含 0 和是否含 1：全 0 输出 B，全 1 输出 I，两者都有输出 F。
4. 递归边界为 l == r，此时区间长度为 1，直接根据该字符输出 B 或 I，无需再分裂。
5. 正确性：递归划分与题目构造完全一致，后序输出顺序与后序遍历定义一致，因此输出序列正确。

## 复杂度分析

- 时间复杂度：O(2^N)
- 空间复杂度：O(2^N)

## 代码

```text
#include<iostream>
#include<string>
using namespace std;
string s;

void dfs(int l,int r){
    int mid=(l+r)>>1;
    if(l<r){
        dfs(l,mid);
        dfs(mid+1,r);
    }
    bool has0=false;
    bool has1=false;
    for(int i=l;i<=r;i++){
        if(s[i]=='0') has0=true;
        else has1=true;
        if(has0&&has1) break;
    }
    // 循环结束再输出当前区间对应的节点
    if(!has1) cout<<'B';
    else if(!has0) cout<<'I';
    else cout<<'F';
}

int main() {
    int n;
    cin >> n >> s;
    int len = 1 << n;
    dfs(0, len - 1);
    return 0;
}
```

## 复盘备注

易错点：输出必须在递归左右子树之后进行，否则变成先序遍历；区间划分时 mid=(l+r)>>1，右区间从 mid+1 开始。可优化点：可在递归返回时向上合并区间类型，避免每层重复扫描区间，但本题 N≤10 无需优化。同类题：线段树建树、分治递归输出类题目。
