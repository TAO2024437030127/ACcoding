## 题目简述

做完饭后，从消毒柜里取出筷子准备吃饭是一件十分有趣的事情。

消毒柜中有n种不同的筷子，这些筷子的种类从1开始编号。第i种筷子有$a_i$只。两只筷子能组成一对筷子当且仅当这两只筷子属于同一个种类。每一只筷子最多属于一对。

你的家里一共有m个人。于是，你需要组m双筷子。

你想知道最小的整数k，使得无论怎么取k只筷子，一定能组成至少m双。如果无解，请输出`-1`。

输入格式
第一行一个整数T (1&le;T&le;$10^6$)，表示数组组数。
对于每组数据：

- 第一行两个整数n,m (1&le;n&le;$10^6$,1&le;m&le;$10^{15}$),表示筷子的种类数，需要取出的筷子对数。
- 第二行n个整数 $a_1$,$a_2$,$a_3$,…,$a_n$ (1&le;$a_i$&le;$10^9$)，表示每种筷子的只数。

保证所有数据中n的和不会超过1&le;n&le;$10^6$。

输出格式
对于每组数据，输出一个整数k，表示最小的整数，使得无论如何都能组成至少m双筷子。

## 解题思路

关键是把“任意取 k 只都至少能配 m 双”转化为“最多能取多少只却仍配不出 m 双”，答案即该最大值加 1。

1. 先判断可行性：每种筷子最多贡献 floor(a_i/2) 双，总对数 total = Σ floor(a_i/2)。若 total < m，则全取也不够，输出 -1。

2. 设最多取 max_take 只仍配不出 m 双。若只配出 p = m-1 双，则最多可保留 2p 只“已配对”的筷子；此外还能加入一些“未配对”的筷子而不增加可配对数。

3. 未配对筷子来源有两类：每种奇数只筷子会剩下 1 只奇余；以及从可配对部分中拆出的一双只取 1 只。总可用的未配对筷子数为 s + (total - p)，其中 s 是 a_i 为奇数的种类数。但未配对筷子最多只有 n 只（每种至多 1 只），因此 Rmax = min(n, s + total - p)。

4. 于是 max_take = 2p + Rmax，答案 ans = max_take + 1。

正确性要点：取到 max_take 只时，可以构造出恰好 p 双且剩余全为不同种类，因此配不出 m 双；而再多取 1 只时，未配对筷子数超过 n 或已配对部分被迫增加，必然能配出第 m 双。

## 复杂度分析

- 时间复杂度：O(Σn)，每组数据线性扫描一次
- 空间复杂度：O(n)，用于存储每组 a_i（可优化为 O(1)）

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
using ll=long long;
int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T;cin>>T;
    while(T--){
        int n;ll m;
        cin>>n>>m;
        vector<ll> a(n);
        ll total=0;
        int s=0;
        for(int i=0;i<n;i++){
            cin>>a[i];
            total += a[i]/2;
            if(a[i]%2==1) s++;
        }
        if(total < m){
            cout<<"-1\n";
            continue;
        }
        ll p = m-1;
        ll rest = total - p;
        ll Rmax = min(1LL*n, 1LL*s + rest);
        ll max_take = 2*p + Rmax;
        ll ans = max_take + 1;
        cout<<ans<<'\n';
    }
    return 0;
}
```

## 复盘备注

易错点：
- m 可达 10^15，total、p、rest 等必须用 long long。
- 判断无解要用 total < m，而不是总只数。
- Rmax 要取 min(n, ...)，因为未配对筷子每种最多 1 只。
- 答案可能超过 int 范围，需用 long long 输出。

可优化点：读入 a_i 时直接统计 total 和奇数个数 s，无需存储数组，空间可降为 O(1)。
