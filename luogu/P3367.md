## 题目简述

**本题数据范围已经更新到 $1\le N\le 2\times 10^5$，$1\le M\le 10^6$。**

如题，现在有一个并查集，你需要完成合并和查询操作。

输入格式
第一行包含两个整数 $N,M$ ,表示共有 $N$ 个元素和 $M$ 个操作。

接下来 $M$ 行，每行包含三个整数 $Z_i,X_i,Y_i$ 。

当 $Z_i=1$ 时，将 $X_i$ 与 $Y_i$ 所在的集合合并。

当 $Z_i=2$ 时，输出 $X_i$ 与 $Y_i$ 是否在同一集合内，是的输出
`Y` ；否则输出 `N` 。

输出格式
对于每一个 $Z_i=2$ 的操作，都有一行输出，每行包含一个大写字母，为 `Y` 或者 `N` 。

说明/提示

对于 $35\%$ 的数据，$N \le 100$，$M \le 10^3$。

对于 $50\%$ 的数据，$1\le N \le 10^4$，$1\le M \le 2\times 10^5$。

对于 $100\%$ 的数据，$1\le N\le 2\times 10^5$，$1\le M\le 10^6$，$1 \le X_i, Y_i \le N$，$Z_i \in \{ 1, 2 \}$。

## 解题思路

本题是并查集模板题，核心是高效维护集合的合并与查询。

1. 初始化：每个元素自成一个集合，parent[i]=i，秩 rank[i]=0。
2. 查找：递归实现 find(x)，若 parent[x] != x 则递归查找根并令 parent[x] 指向根，实现路径压缩，使后续查询接近 O(1)。
3. 合并：先分别找到 x、y 的根，若相同则无需合并；否则按秩合并，将秩小的树根挂到秩大的树根下，秩相等时合并后秩加一，保证树高为 O(log N)。
4. 查询：对 Z=2 的操作，比较 find(X) 与 find(Y) 是否相等，相等输出 Y，否则输出 N。

正确性要点：路径压缩不改变集合划分，只优化结构；按秩合并保证树高平衡；两者结合使单次操作均摊接近常数。

## 复杂度分析

- 时间复杂度：O(M α(N))，其中 α 为反阿克曼函数，近似常数
- 空间复杂度：O(N)

## 代码

```text
#include <iostream>
using namespace std;

const int MAXN = 200005; // 对应 2×10^5
int parent[MAXN];
int rank_[MAXN]; // 用 rank_ 避免和关键字冲突

// 查找根节点（带路径压缩）
int find(int x) {
    if (parent[x] != x) {
        parent[x] = find(parent[x]);
    }
    return parent[x];
}

// 合并两个集合（按秩合并）
void unite(int x, int y) {
    x = find(x);
    y = find(y);
    if (x == y) return;
    if (rank_[x] < rank_[y]) {
        parent[x] = y;
    } else {
        parent[y] = x;
        if (rank_[x] == rank_[y]) {
            rank_[x]++;
        }
    }
}

int main() {
    ios::sync_with_stdio(false); // 关闭同步，加速 cin/cout
    cin.tie(nullptr);

    int N, M;
    cin >> N >> M;

    // 初始化并查集
    for (int i = 1; i <= N; ++i) {
        parent[i] = i;
        rank_[i] = 0;
    }

    while (M--) {
        int Z, X, Y;
        cin >> Z >> X >> Y;
        if (Z == 1) {
            unite(X, Y);
        } else {
            if (find(X) == find(Y)) {
                cout << "Y\n";
            } else {
                cout << "N\n";
            }
        }
    }

    return 0;
}
```

## 复盘备注

易错点：
- 初始化时 parent 数组需从 1 到 N 赋值，不能遗漏。
- 合并前必须先对 x、y 调用 find 取根，不能直接比较原值。
- 使用 rank 数组时注意变量名不要与 C++ 关键字冲突（代码中用 rank_ 规避）。
- 输入输出量较大，建议关闭同步并使用 '\n' 而非 endl。

可优化点：
- 可将递归 find 改为迭代写法，避免极端情况下递归深度过大（路径压缩后深度很小，通常安全）。
- 若内存紧张，可用 short 存储 rank。

同类题提示：并查集常用于连通性判断、Kruskal 最小生成树、种类并查集、带权并查集等。
