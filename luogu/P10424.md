## 题目简述

一个整数如果按从低位到高位的顺序，奇数位（个位、百位、万位……）上的数字是奇数，偶数位（十位、千位、十万位……）上的数字是偶数，我们就称之为“好数”。

给定一个正整数 $N$，请计算从 $1$ 到 $N$ 一共有多少个好数。

输入格式
一个整数 $N$。

输出格式
一个整数代表答案。

说明/提示
### 样例 1 解释

$24$ 以内的好数有 $1,3,5,7,9,21,23$，一共 $7$ 个。

### 数据规模与约定

- 对于 $10\%$ 的测试数据，$1 \leq N \le 100$。
- 对于全部的测试数据，$1 \le N \leq 10^7$。

## 解题思路

**关键观察**：题目对“好数”的定义只与每个数字所在的位置（从个位开始编号为 1）的奇偶性有关，与数字大小无关。

**算法选择**：由于 N ≤ 10^7，直接枚举 1 到 N 的每个数并逐位判断即可，总操作量约为 7×10^7 次取模与除法，在常规时限内可以接受。

**逐位判断**：对每个数 x，用 pos 记录当前处理的是第几位（个位为 1），每次取 x % 10 得到当前最低位数字：
- 若 pos 为奇数且 digit 为偶数，则不是好数；
- 若 pos 为偶数且 digit 为奇数，则不是好数；
- 否则 x /= 10、pos++ 继续检查下一位。

**正确性要点**：循环从个位开始依次向高位推进，位置编号与题目定义完全一致；一旦发现某一位不满足条件立即返回 false，全部位检查通过才返回 true，因此 check 函数恰好判定一个数是否为好数。外层枚举 1..N 并累加计数，结果正确。

## 复杂度分析

- 时间复杂度：O(N log N)，每个数最多检查其十进制位数（≤7 位），可视为 O(N)
- 空间复杂度：O(1)

## 代码

```cpp
#include <iostream>
using namespace std;

// 判断一个数 x 是否符合：奇数位是奇数，偶数位是偶数
bool check(int x) {
    int pos = 1;  // 从个位开始，是第 1 位
    while (x > 0) {
        int digit = x % 10;  // 取最后一位数字
        
        // 奇数位 → 数字必须是奇数
        if (pos % 2 == 1 && digit % 2 == 0)
            return false;
        
        // 偶数位 → 数字必须是偶数
        if (pos % 2 == 0 && digit % 2 == 1)
            return false;
        
        x /= 10;
        pos++;
    }
    return true;
}

int main() {
    int n, cnt = 0;
    cin >> n;
    
    for (int i = 1; i <= n; i++) {
        if (check(i)) cnt++;
    }
    
    cout << cnt << endl;
    return 0;
}
```

## 复盘备注

**易错点**：
- 位置编号必须从个位开始算第 1 位，不要从最高位开始数；
- 判断条件要区分“奇数位要求数字为奇数”和“偶数位要求数字为偶数”，不要写反；
- 循环中先取 digit 再更新 x 和 pos，顺序不能乱。

**可优化点**：本题 N 较小，暴力枚举已足够。若 N 更大，可考虑数位 DP 或按位构造计数，避免逐个枚举。

**同类题提示**：涉及“按数位位置奇偶性”的计数问题，可优先考虑数位 DP 或直接按位构造。
