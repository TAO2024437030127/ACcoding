## 题目简述

该铁路经过 $N$ 个城市，每个城市都有一个站。不过，由于各个城市之间不能协调好，于是乘车每经过两个相邻的城市之间（方向不限），必须单独购买这一小段的车票。第 $i$ 段铁路连接了城市 $i$ 和城市 $i+1(1\leq i<N)$。如果搭乘的比较远，需要购买多张车票。第 $i$ 段铁路购买纸质单程票需要 $A_i$ 博艾元。

虽然一些事情没有协调好，各段铁路公司也为了方便乘客，推出了 IC 卡。对于第 $i$ 段铁路，需要花 $C_i$ 博艾元的工本费购买一张 IC 卡，然后乘坐这段铁路一次就只要扣 $B_i(B_i<A_i)$ 元。IC 卡可以提前购买，有钱就可以从网上买得到，而不需要亲自去对应的城市购买。工本费不能退，也不能购买车票。每张卡都可以充值任意数额。对于第 $i$ 段铁路的 IC 卡，无法乘坐别的铁路的车。

Uim 现在需要出差，要去 $M$ 个城市，从城市 $P_1$ 出发分别按照 $P_1,P_2,P_3,\cdots,P_M$ 的顺序访问各个城市，可能会多次访问一个城市，且相邻访问的城市位置不一定相邻，而且不会是同一个城市。

现在他希望知道，出差结束后，至少会花掉多少的钱，包括购买纸质车票、买卡和充值的总费用。

输入格式
第一行两个整数，$N,M$。

接下来一行，$M$ 个数字，表示 $P_i$。

接下来 $N-1$ 行，表示第 $i$ 段铁路的 $A_i,B_i,C_i$。

输出格式
一个整数，表示最少花费。

说明/提示
$2$ 到 $3$ 以及 $8$ 到 $9$ 买票，其余买卡。

对于 $30\%$ 数据 $M=2$。

对于另外 $30\%$ 数据 $N\leq1000$，$M\leq1000$。

对于 $100\%$ 的数据 $M,N\leq 10^5$，$A_i,B_i,C_i\le10^5$。

## 解题思路

关键观察：每段铁路的乘坐次数只取决于相邻访问城市之间的区间覆盖次数，与具体顺序无关。

1. 对 M 个访问城市，相邻两个城市 P_i 与 P_{i+1} 之间的行程会经过编号从 min 到 max-1 的所有铁路段。
2. 用差分数组统计每段铁路被经过的次数：对区间 [l, r] 执行 diff[l]++, diff[r+1]--，最后前缀和得到每段次数 cnt。
3. 对第 i 段铁路，若乘坐 cnt 次：买纸质票总花费为 A_i * cnt；买 IC 卡总花费为 C_i + B_i * cnt。取两者较小值累加。
4. 正确性：各段铁路独立决策，且每段选择最小花费不会影响其他段，因此贪心逐段取 min 得到全局最优。

- 时间复杂度：O(N + M)

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
typedef long long ll;

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int n,m;
    cin>>n>>m;
    vector<int> p(m+1);
    for(int i=1;i<=m;i++){
        cin>>p[i];
    }
    vector<ll> diff(n+2,0);
    for(int i=1;i<m;i++){
        int l=min(p[i],p[i+1]);
        int r=max(p[i],p[i+1])-1;
        diff[l]++;
        diff[r+1]--;
    }
    ll cnt=0;
    ll ans=0;
    ll a,b,c;
    for(int i=1;i<=n-1;i++){
        cnt += diff[i];
        cin>>a>>b>>c;
        ll ic = c + b * cnt;
        ll cash = a * cnt;
        ans += min(ic, cash);
    }
    cout<<ans<<endl;
    return 0;
}
```

## 复盘备注

易错点：
- 区间端点：从城市 l 到城市 r 经过的是 l 到 r-1 段，差分右端点应为 max-1，对应 diff[r+1] 减一。
- 答案和计数需用 long long，防止 A_i * cnt 溢出 int。
- 输入顺序：先读入 M 个城市，再读 N-1 行铁路参数；代码在统计完差分后边读边计算，注意不要提前读入。
- 可优化：差分数组和铁路参数可边读边处理，但当前写法已足够。
