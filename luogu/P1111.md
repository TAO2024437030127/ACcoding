## 题目简述

A 地区在地震过后，连接所有村庄的公路都造成了损坏而无法通车。政府派人修复这些公路。

给出 A 地区的村庄数 $N$，和公路数 $M$，公路是双向的。并告诉你每条公路的连着哪两个村庄，并告诉你什么时候能修完这条公路。问最早什么时候任意两个村庄能够通车，即最早什么时候任意两条村庄都存在至少一条修复完成的道路（可以由多条公路连成一条道路）。

输入格式
第 $1$ 行两个正整数 $N,M$。

下面 $M$ 行，每行 $3$ 个正整数 $x,y,t$，告诉你这条公路连着 $x,y$ 两个村庄，在时间 $t$ 时能修复完成这条公路。

输出格式
如果全部公路修复完毕仍然存在两个村庄无法通车，则输出 $-1$，否则输出最早什么时候任意两个村庄能够通车。

说明/提示
$1\leq x, y\leq N \le 10 ^ 3$，$1\leq M, t \le 10 ^ 5$。

## 解题思路

1. 题目本质是求使图连通的最小时间，等价于按时间从小到大加入边，当图首次连通时的时间即为答案。
2. 使用并查集维护连通分量，初始每个村庄独立。
3. 将所有公路按修复时间 t 升序排序。
4. 依次处理每条公路：合并两个端点所在的集合，并维护根节点的集合大小 sz。
5. 每次合并后检查当前边的一个端点所在集合的大小是否等于 N，若等于则说明所有村庄已连通，当前边的 t 即为答案，立即输出并结束。
6. 若遍历完所有边仍未出现大小为 N 的集合，说明图不连通，输出 -1。
正确性要点：按时间顺序加边保证首次连通时的时间最小；并查集合并与大小维护正确反映连通分量。

## 复杂度分析

- 时间复杂度：O(M log M + M α(N))
- 空间复杂度：O(N + M)

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
using p3 = pair<int,pair<int,int>>;

vector<int> fa;
vector<int> sz;

int find(int x){
    if(fa[x] != x) fa[x] = find(fa[x]);
    return fa[x];
}

void unite(int x,int y){
    x = find(x);
    y = find(y);
    if(x == y) return;
    fa[y] = x;
    sz[x] += sz[y];
}

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n,m;
    cin >> n >> m;
    fa.resize(n+1);
    sz.resize(n+1);
    vector<p3> edge(m);
    for(int i = 0; i < m; i++){
        int x,y,t;
        cin >> x >> y >> t;
        edge[i] = {x, {y, t}};
    }
    // 按第三维t升序排序
    sort(edge.begin(), edge.end(), [](const p3&a, const p3&b){
        return a.second.second < b.second.second;
    });
    for(int i = 1; i <= n; i++){
        fa[i] = i;
        sz[i] = 1;
    }
    int ans = -1;
    for(auto &e : edge){
        int u = e.first;
        int v = e.second.first;
        int t = e.second.second;
        unite(u, v);
        int rt = find(u);
        if(sz[rt] == n){
            ans = t;
            break;
        }
    }
    cout << ans << endl;
    return 0;
}
```

## 复盘备注

易错点：
- 合并后应检查合并后根节点的 sz 是否为 N，而不是检查两个端点是否直接相连。
- 若 N=1，初始即连通，但本题 N≥1 且 M≥1，代码中未特判 N=1 的情况，此时不会进入循环输出 -1，但根据题意 N=1 时应输出 0（不过题目约束 N≤10^3 且样例未涉及，可忽略或特判）。
- 并查集路径压缩与按大小合并可进一步优化，但本题数据范围较小，直接合并也可通过。
可优化点：使用按秩合并（如 sz 较小者合并到较大者）可降低树高。
同类题提示：最小生成树 Kruskal 算法、连通时间问题。
