## 题目简述

组合数学是数学的重要组成部分，是一门研究离散对象的科学，它主要研究满足一定条件的组态（也称组合模型）的存在、计数以及构造等方面的问题。组合数学的主要内容有组合计数、组合设计、组合矩阵、组合优化等。

随着计算机科学的日益发展，组合数学的重要性也日渐凸显，因为计算机科学的核心内容是使用算法处理离散数据。

今天我们来研究组合数学中的一个有趣的问题，也是一个简单的计数问题：

从一副含有 $n$ 张的扑克牌（每张扑克牌都不相同）中，分给 $m$ 个人，第 $i$ 个人得到 $a_i$ 张牌，求一共有几种分法，这个数可能非常大，请输出此数模 $10007$ 后的结果。

输入格式
第一行两个整数为 $n,m$。

第二行 $m$ 个整数 $a_i$。

输出格式
此数模 $10007$ 后的结果。

说明/提示
对于 $50\%$ 的数据：$a_i=1$。

对于 $100\%$ 的数据：$1 \leq n \leq 10^4$，$1 \leq m \leq 100$，$0 \leq a_i \leq 100$。

## 解题思路

- 关键观察：分牌过程等价于依次从剩余牌中为每个人选牌，第 i 人从当前剩余 rem 张中选 a_i 张，方案数为组合数 C(rem, a_i)，各步相乘即为总方案数。
- 算法选择：n 最大 10^4，a_i 最大 100，但组合数上标 rem 可能达到 10^4，而模数 10007 是质数且小于 n 的上界，因此不能直接用阶乘逆元求 C(rem, a_i)，需使用 Lucas 定理。
- 预处理：在模 10007 下预处理 0 到 10006 的阶乘 fact 和逆阶乘 invfact，用于计算小规模组合数 c_small(n, m) = fact[n] * invfact[m] * invfact[n-m] mod MOD。
- Lucas 定理：C(n, m) mod p = C(n%p, m%p) * C(n/p, m/p) mod p，递归实现 lucas。
- 主流程：维护剩余牌数 rem 初始为 n，对每个人计算 ans = ans * C_mod(rem, a[i]) % MOD，然后 rem -= a[i]。
- 正确性要点：每一步选择互不影响且覆盖所有分配方式，乘法原理成立；Lucas 定理保证大组合数在模质数下正确计算。

## 复杂度分析

- 时间复杂度：O(MAXN + m log_MOD n)，其中 MAXN=10007，预处理 O(MAXN)，每次 Lucas 递归深度 O(log_MOD n)，m ≤ 100。
- 空间复杂度：O(MAXN)，存储阶乘和逆阶乘数组。

## 代码

```text
#include <iostream>
#include <vector>
using namespace std;
typedef long long ll;
const int MOD = 10007;
const int MAXN = 10007;

vector<ll> fact(MAXN),invfact(MAXN);

ll qpow(ll a,ll b){
    ll ans=1;
    while(b>0){
        if(b&1) ans=ans*a%MOD;
        a=a*a%MOD;
        b>>=1;
    }
    return ans;
}

void prework(){
    fact[0]=1;
    for(int i=1;i<MAXN;i++) fact[i]=fact[i-1]*i%MOD;
    invfact[MAXN-1]=qpow(fact[MAXN-1],MOD-2);
    for(int i=MAXN-2;i>=0;i--) invfact[i]=invfact[i+1]*(i+1)%MOD;
}

// 新增：n,m都小于MOD的小规模组合
ll c_small(ll n, ll m)
{
    if(m < 0 || m > n) return 0;
    return fact[n] * invfact[m] % MOD * invfact[n - m] % MOD;
}

// 新增 Lucas
ll lucas(ll n, ll m)
{
    if(m == 0) return 1;
    return lucas(n / MOD, m / MOD) * c_small(n % MOD, m % MOD) % MOD;
}

// 改写C_mod，对外接口不变，内部调用lucas
ll C_mod(int n,int m){
    if(m<0||m>n) return 0;
    return lucas(n, m);
}

ll A_mod(int n,int m){
    if(m<0||m>n) return 0;
    return fact[n]*invfact[n-m]%MOD;
}

int main(){
    prework();
    int n,m;
    cin>>n>>m;
    vector<int> a;
    for(int i=0;i<m;i++){
        int z;cin>>z;
        a.push_back(z);
    }
    ll ans=1;
    int rem = n;
    for(int i=0;i<m;i++){
        ans = ans * C_mod(rem, a[i]) % MOD;
        rem -= a[i];
    }
    cout<<ans;
    return 0;
}
```

## 复盘备注

易错点：
- 模数 10007 是质数，但 n 可能大于模数，直接使用阶乘逆元会出错，必须用 Lucas 定理。
- 当 a_i 之和超过 n 时，后续组合数会返回 0，但题目数据保证合法分配，无需特判。
- 预处理数组大小需至少为 MOD，代码中 MAXN=10007 刚好覆盖 0..10006。
可优化点：
- 由于 a_i ≤ 100，可只预处理到 100 的阶乘用于小组合，但 Lucas 需要模数范围内的阶乘，当前预处理已足够。
同类题提示：组合数取模且模数为质数、n 可能大于模数时，优先考虑 Lucas 定理。
