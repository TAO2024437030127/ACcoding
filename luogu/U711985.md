## 题目简述

给定一个正整数 $n$，求 $1$ 到 $n$ 之间所有整数的和。

即计算：

$$S = 1 + 2 + 3 + \dots + n$$

注意答案可能很大，需要使用 `long long` 类型。

输入格式
第一行包含一个正整数 $T$（$1 \le T \le 10^5$），表示测试用例的数量。

接下来 $T$ 行，每行一个正整数 $n$（$1 \le n \le 10^9$）。

输出格式
对于每个测试用例，输出一行一个整数，表示答案。

说明/提示
十年算竞一场空，不开longlong见祖宗

## 样例

### 样例 1

输入：
```text
4
1
10
100
2026
```

输出：
```text
1
55

2053351
```

## 解题思路

1. 观察求和公式：1 到 n 的整数和可直接用等差数列求和公式 S = n(n+1)/2 计算，无需循环累加。
2. 由于 n 最大可达 10^9，n(n+1) 最大约为 10^18 量级，在 long long 范围内（约 9.22×10^18），因此用 long long 存储 n 和答案即可避免溢出。
3. 每组数据读入 n 后，直接计算 ans = n*(n+1)/2 并输出。
4. 正确性要点：公式对任意正整数 n 成立；先乘后除保证整除，因为 n 与 n+1 必有一个偶数，乘积能被 2 整除。
5. 注意输入输出量较大（T 可达 10^5），使用 cin/cout 并关闭同步或使用 scanf/printf 可提高效率，但本题数据规模下普通 cin/cout 也可通过。

## 复杂度分析

- 时间复杂度：O(T)

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
typedef long long ll;

int main(){

    int t;
    cin>>t;
    while(t--){
        ll n;
        cin>>n;
        ll ans = n*(n+1)/2;
        cout<<ans<<"\n";
    }
    return 0;
}
```

## 复盘备注

易错点：1) 必须使用 long long 存储 n 和答案，否则 n 较大时 n*(n+1) 会溢出 int；2) 公式中先乘后除，不要写成 n/2*(n+1) 或 n*(n+1/2)，否则可能丢失精度；3) 输出换行建议用 '\n' 而非 endl 以提高效率。同类题提示：等差数列求和、前缀和等题目注意数据范围与溢出问题。
