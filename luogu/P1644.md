## 题目简述

中国象棋半张棋盘如图 $1$ 所示。马自左下角 $(0,0)$ 向右上角 $(m,n)$ 跳。规定只能往右跳，不准往左跳。比如图 $1$ 中所示为一种跳行路线，并将路径总数打印出来。

![](https://cdn.luogu.com.cn/upload/image_hosting/8gkasdvs.png)

输入格式
只有一行：两个数 $n$，$m$。

输出格式
只有一个数：总方案数 $total$。

说明/提示
对于 $100\%$ 的数据：$n, m\leq 18$

### 样例 1

输入：

4 8

## 解题思路

1. 观察马的走法：马走“日”字，共有 8 个方向，但题目规定只能向右跳，因此横坐标必须增加，只保留横坐标增量为正的方向。
2. 代码中定义了四个方向：dx={1,2,1,2}，dy={2,1,-2,-1}，对应横坐标增加 1 或 2，纵坐标变化 ±1 或 ±2，恰好覆盖所有向右跳的走法。
3. 使用深度优先搜索（DFS）从起点 (0,0) 开始，每次尝试四个方向，若新位置 (nx, ny) 满足 0 ≤ ny ≤ n 且 nx ≤ m（同时 nx 自然 ≥ 0），则继续递归搜索。
4. 当到达终点 (m,n) 时，方案数 ans 加一，并返回。
5. 由于 n, m ≤ 18，搜索空间有限，直接 DFS 枚举所有合法路径即可在时限内完成。
6. 正确性：DFS 枚举了所有只向右跳的合法路径，且不重复、不遗漏，因此 ans 即为总方案数。

## 复杂度分析

- 时间复杂度：O(4^(m+n))，最坏情况下每步有 4 种选择，但实际受棋盘边界限制，远小于该上界。
- 空间复杂度：O(m+n)，递归栈深度最大为路径长度。

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
int dx[]={1,2,1,2};
int dy[]={2,1,-2,-1};
int m,n;
int ans=0;
void dfs(int x,int y){
    if(x==m&&y==n){
        ans++;
        return ;
    }
    for(int i=0;i<4;i++){
        int nx=x+dx[i];
        int ny=y+dy[i];
        if(ny>=0&&nx<=m&&ny<=n){
            dfs(nx,ny);
        }
    }
}
int main(){
    cin>>n>>m;
    dfs(0,0);
    cout<<ans<<endl;
    return 0;
}
```

## 复盘备注

易错点：输入顺序为 n, m，而坐标中 m 是横坐标上限、n 是纵坐标上限，代码中先读 n 再读 m，并令 x 对应横坐标、y 对应纵坐标，需注意不要混淆。可优化点：由于状态 (x,y) 的方案数具有重叠子问题性质，可用记忆化搜索或动态规划优化，但本题数据范围小，DFS 已足够。同类题提示：若数据范围增大，可考虑 DP，状态转移为 dp[x][y] = sum(dp[x-dx][y-dy])。
