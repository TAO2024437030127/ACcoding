## 题目简述

又是一年秋季时，陶陶家的苹果树结了 $n$ 个果子。陶陶又跑去摘苹果，这次他有一个 $a$ 公分的椅子。当他手够不着时，他会站到椅子上再试试。

这次与 NOIp2005 普及组第一题不同的是：陶陶之前搬凳子，力气只剩下 $s$ 了。当然，每次摘苹果时都要用一定的力气。陶陶想知道在 $s<0$ 之前最多能摘到多少个苹果。

现在已知 $n$ 个苹果到达地上的高度 $x_i$，椅子的高度 $a$，陶陶手伸直的最大长度 $b$，陶陶所剩的力气 $s$，陶陶摘一个苹果需要的力气 $y_i$，求陶陶最多能摘到多少个苹果。

输入格式
第 $1$ 行：两个数 苹果数 $n$，力气 $s$。

第 $2$ 行：两个数 椅子的高度 $a$，陶陶手伸直的最大长度 $b$。

第 $3$ 行~第 $3+n-1$ 行：每行两个数 苹果高度 $x_i$，摘这个苹果需要的力气 $y_i$。

输出格式
只有一个整数，表示陶陶最多能摘到的苹果数。

说明/提示
对于 $100\%$ 的数据，$n\leq 5000$, $a\leq 50$, $b\leq 200$, $s\leq 1000$, $x_i\leq 280$, $y_i\leq 100$。

## 解题思路

1. 先筛选出能够到的苹果：只有高度 x_i ≤ a+b 的苹果才可能被摘到。
2. 对于能够到的苹果，若摘取力气 y_i = 0，则摘它不消耗力气，一定可以全部摘到，直接累加到答案 cnt0 中。
3. 对于 y_i > 0 的苹果，问题转化为：在总力气 s 的限制下，从若干物品（每个物品重量 y_i、价值 1）中选取，使总价值最大。这是 0/1 背包问题。
4. 用一维数组 dp[j] 表示消耗力气不超过 j 时能摘到的最大苹果数，初始为 0。对每个苹果按重量 y_i 做逆序更新：dp[j] = max(dp[j], dp[j-y_i] + 1)，保证每个苹果只选一次。
5. 最终答案为 cnt0 + dp[s]。

## 复杂度分析

- 时间复杂度：O(n·s)
- 空间复杂度：O(s)

## 代码

```text
#include<bits/stdc++.h>
using namespace std;

int main(){
    int n,s;
    cin>>n>>s;
    int a,b;
    cin>>a>>b;
    vector<pair<int,int>> ap;
    int cnt0=0;
    for(int i=1;i<=n;i++){
        pair<int,int> apple;
        cin>>apple.first>>apple.second;
        if(apple.first<=a+b){
            if(apple.second==0){
                cnt0++;
            }else{
                ap.emplace_back(apple.first,apple.second);
            }
        }
    }
    vector<int> dp(s+1,0);
    for(int i=0;i<ap.size();i++){
        int w=ap[i].second;
        for(int j=s;j>=w;j--){
            dp[j]=max(dp[j],dp[j-w]+1);
        }
    }
    cout<<cnt0+dp[s]<<endl;
    return 0;
}
```

## 复盘备注

易错点：
- 高度判断应为 x_i ≤ a+b，而不是 x_i ≤ a 或 x_i ≤ b。
- 力气为 0 的苹果要单独处理，否则在背包中可能因逆序更新被重复计算或遗漏。
- 背包内层循环必须逆序，否则会变成完全背包。
- 题目要求 s<0 之前，即力气可以恰好用完为 0，因此 dp 容量为 s 即可。
可优化点：
- 由于每个苹果价值均为 1，也可按力气从小到大贪心选取，复杂度 O(n log n)，但背包做法同样简洁且正确。
同类题提示：0/1 背包求最大物品数，注意零重量物品的特殊处理。
