## 题目简述

在正式解题之前，你需要先了解比赛中常见的评测状态。这些状态将出现在你的每次提交结果中。![](https://cdn.luogu.com.cn/upload/image_hosting/xfc3z98g.png)

输入格式
输入只有一行，包含一个字符串 $s$，表示评测状态的缩写。

$s$ 只可能是以下 6 种之一：

| 缩写 | 完整含义 |
| :--- | :--- |
| ac | answer correct |
| wa | wrong answer |
| tle | time limit exceeded |
| mle | memory limit exceeded |
| re | runtime error |
| ce | compile error |

输出格式
如果 $s$ 是上表中的缩写，输出对应的完整含义，**带双引号**。

如果 $s$ 不在上表中，输出 `"unknown"`

## 解题思路

本题是简单的字符串条件判断。

1. 读入字符串 s。
2. 依次将 s 与 6 个合法缩写比较：ac、wa、tle、mle、re、ce。
3. 若匹配到某个缩写，则输出对应的完整含义，并在完整含义两侧加上双引号。
4. 若所有条件均不满足，则输出 "unknown"（同样带双引号）。

正确性要点：
- 每个缩写与完整含义一一对应，条件分支互斥，不会重复输出。
- 输出双引号需用转义字符 \" 表示，避免被 C++ 当作字符串边界。
- 题目保证输入只可能是 6 种缩写之一或其它字符串，因此 else 分支处理未知情况即可。

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
int main(){
    string s;
    cin>>s;
    if(s=="ac"){
        cout<<"\"answer correct\"";
    }else if(s=="wa"){
        cout<<"\"wrong answer\"";
    }else if(s=="tle"){
        cout<<"\"time limit exceeded\"";
    }else if(s=="mle"){
        cout<<"\"memory limit exceeded\"";
    }else if(s=="re"){
        cout<<"\"runtime error\"";
    }else if(s=="ce"){
        cout<<"\"compile error\"";
    }else{
        cout<<"\"unknown\"";
    }
    return 0;
}
```

## 复盘备注

易错点：输出必须带双引号，C++ 中需写成 \" 进行转义；不要漏掉 unknown 分支的双引号。
可优化点：可用 map 或数组映射简化代码，但本题分支少，直接 if-else 已足够清晰。
