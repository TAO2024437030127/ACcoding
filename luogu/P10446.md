## 题目简述

求 $a$ 乘 $b$ 对 $p$ 取模的值。

输入格式
第一行输入整数 $a$，第二行输入整数 $b$，第三行输入整数 $p$。

输出格式
输出一个整数，表示 `a*b mod p` 的值。

说明/提示
$1 \le a,b,p \le 10^{18}$

## 样例

### 样例 1

输入：
```text
3
4
5
```

输出：
```text
2
```

## 解题思路

- 关键观察：a 和 b 最大为 10^18，直接相乘会溢出 64 位整数，因此不能写 `a*b%p`。
- 算法选择：使用「快速乘」（二进制拆分乘法），思想与快速幂一致，把 b 拆成二进制位，用加法代替乘法。
- 具体做法：先令 `a %= mod`，答案 `ans = 0`。当 `b > 0` 时循环：若 `b` 的最低位为 1，则把当前的 a 累加到 ans 中并取模；然后令 `a = (a + a) % mod` 实现 a 的倍增，`b >>= 1` 右移一位。
- 正确性要点：循环中 a 始终等于「原 a 乘以 2 的当前位权」对 mod 取模的结果，ans 累加的是 b 的二进制分解中为 1 的那些位对应的 a 的倍数，因此最终 ans 恰好等于 a*b mod p。每次加法后都取模，保证中间结果不超过 2*mod，不会溢出。
- 边界情况：b 为 0 时循环不执行，返回 0，符合 0 mod p = 0。

## 复杂度分析

- 时间复杂度：O(log b)
- 空间复杂度：O(1)

## 代码

```cpp
#include<bits/stdc++.h>
using namespace std;
typedef long long ll;
ll a,b,p;
ll mul(ll a,ll b,ll mod){
    ll ans=0;
    a%=mod;
    while(b>0){
        if(b&1){
            ans=(a+ans)%mod;
        }
        a=(a+a)%mod;
        b>>=1;
            
    }
    return ans;
}
int main(){
    cin>>a>>b>>p;
    ll ans=mul(a,b,p);
    cout<<ans<<endl;
    return 0;
}
```

## 复盘备注

- 易错点：忘记在函数开头对 a 取模；累加时写成 `ans += a` 而不取模，虽然本题 mod 可达 10^18，`ans + a` 仍可能接近 2*10^18，在 long long 范围内，但养成取模习惯更安全。
- 可优化点：本题也可用 `__int128` 直接计算 `( __int128)a * b % p`，代码更短；快速乘方法更具通用性，适用于不支持 128 位整数的场景。
