## 题目简述

Farmer John's $N$ cows are standing in a row, as they have a tendency to do from time to time. Each cow is labeled with a distinct integer ID number so FJ can tell them apart. FJ would like to take a photo of a contiguous group of cows but, due to a traumatic childhood incident involving the numbers $1 \ldots 6$, he only wants to take a picture of a group of cows if their IDs add up to a multiple of 7.

Please help FJ determine the size of the largest group he can photograph.

输入格式
The first line of input contains $N$ ($1 \leq N \leq 50,000$). The next $N$ lines each contain the $N$ integer IDs of the cows (all are in the range $0 \ldots 1,000,000$).

输出格式
Please output the number of cows in the largest consecutive group whose IDs sum to a multiple of 7. If no such group exists, output 0.

说明/提示
In this example, $5+1+6+2+14 = 28$.

## 解题思路

1. 使用前缀和思想：设 S[i] 为前 i 个元素之和，则子段 (l+1..r) 的和为 S[r]-S[l]，它能被 7 整除当且仅当 S[r] ≡ S[l] (mod 7)。
2. 因此只需记录每个余数 r ∈ [0,6] 第一次出现的前缀下标 first[r] 和最后一次出现的下标 last[r]。
3. 初始化 first[0]=0（空前缀余数为 0），其余 first 置 -1；遍历序列时累加前缀和，对当前余数 rem，若 first[rem] 未记录则记录当前下标，并始终更新 last[rem]=当前下标。
4. 遍历所有余数，若 first[r] 和 last[r] 均存在，则候选长度为 last[r]-first[r]，取最大值即为答案。
5. 正确性：任意满足条件的子段对应两个相同余数的前缀下标，其长度等于两下标之差；对每个余数取最左和最右出现位置可得到该余数下的最大长度，全局取最大即最优。

## 复杂度分析

- 时间复杂度：O(N)
- 空间复杂度：O(1)（仅常数个数组）

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
typedef long long ll;

int main(){
    int n;
    cin>>n;
    vector<int> first(7,-1);
    vector<int> last(7,-1);
    ll sum=0;
    first[0]=0;
    for(int i=1;i<=n;i++){
        int x;
        cin>>x;
        sum+=x;
        int rem=sum%7;
        if(first[rem]==-1){
            first[rem]=i;
        }
        last[rem]=i;
    }
     int ans = 0;
    for(int r = 0; r < 7; r++)
    {
        if(first[r] != -1 && last[r] != -1)
        {
            ans = max(ans, last[r] - first[r]);
        }
    }
    cout << ans << endl;
    return 0;
    
        
}
```

## 复盘备注

易错点：前缀和可能超过 int 范围，需用 long long；first[0] 必须初始化为 0，否则会漏掉从开头开始的子段；若某余数只出现一次，last-first=0，不影响答案。可优化点：无需存储整个数组，边读边处理即可。同类题：前缀和+同余性质求最长/最短子段。
