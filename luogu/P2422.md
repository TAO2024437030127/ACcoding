## 题目简述

kkk 做了一个人体感觉分析器。每一天，人都有一个感受值 $A_i$，$A_i$ 越大，表示人感觉越舒适。在一段时间 $\left[i, j\right]$ 内，人的舒适程度定义为 $\left[i, j\right]$ 中最不舒服的那一天的感受值 $\times$ $\left[i, j\right]$中每一天感受值的和。现在给出 kkk 在连续 $N$ 天中的感受值，请问，在哪一段时间，kkk 感觉最舒适？

输入格式
第一行为 $N$，代表数据记录的天数。

第二行 $N$ 个整数，代表每一天的感受值。

输出格式
一行，表示在最舒适的一段时间中的舒适程度。

说明/提示
kkk 最舒适的一段时间是第 $3$ 天到第 $5$ 天，舒适程度：$(6+4+5)\times4=60$。

对于 $30\%$ 的数据，$1\le N\le 100$。

对于 $70\%$ 的数据，$1\le N\le 2000$。

对于 $100\%$ 的数据，$1\le N\le 10^5$，$1\le A_i\le 10^6$。

## 解题思路

关键观察：最优区间的“最小值”一定等于区间中某个元素 A_i，且该区间应尽可能向左右扩展到 A_i 仍为最小值的极限位置。

1. 预处理前缀和 sum，便于 O(1) 求任意区间和。
2. 对每个位置 i，用单调栈求：
   - leftedge[i]：i 左边第一个严格小于 A_i 的位置（不存在则为 0）；
   - rightedge[i]：i 右边第一个严格小于 A_i 的位置（不存在则为 n+1）。
   这样以 A_i 为最小值的最大合法区间是 (leftedge[i], rightedge[i])。
3. 枚举 i，区间和 = sum[rightedge[i]-1] - sum[leftedge[i]]，用 A_i 乘区间和更新答案。

正确性要点：任一最优区间的最小值出现在某位置 i，该区间必包含在 (leftedge[i], rightedge[i]) 内；而扩展到这个最大区间不会引入更小值，区间和只增不减，因此以 A_i 为最小值的最优区间就是该极大区间。枚举所有 i 即可覆盖最优解。

注意代码中左边界栈从 0 开始，且弹出条件为 >=，保证 leftedge 是严格小于的位置，避免重复计算相等元素时区间交叉导致错误。

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
typedef long long ll;

int main(){
    int n;
    cin>>n;
    vector<ll> num(n+1);
    vector<ll> sum(n+1,0);
    for(int i=1;i<=n;i++){
        cin>>num[i];
        sum[i]=sum[i-1]+num[i];
    }
    vector<int> leftedge(n+1,0);
    vector<int> rightedge(n+1,n+1);
    stack<int> st;
    for(int i=0;i<=n;i++){
        while(!st.empty()&&num[st.top()]>=num[i]){
            st.pop();
        }
        if(!st.empty()){
            leftedge[i]=st.top();
        }
        st.push(i);
    }
    while(!st.empty()) st.pop();
    for(int i=n;i>=1;i--){
        while(!st.empty()&&num[st.top()]>=num[i]){
            st.pop();
        }
        if(!st.empty()){
            rightedge[i]=st.top();
        }
        st.push(i);
    }
    ll ans=0;
    for(int i=1;i<=n;i++){
        ll t=sum[rightedge[i]-1]-sum[leftedge[i]];
        ans=max(ans,num[i]*t);
        
    }
    cout<<ans;
    return 0;
}
```

## 复盘备注

易错点：
- 区间和可能达到 10^11 量级，必须用 long long。
- 单调栈弹出条件用 >= 还是 > 会影响相等元素的处理；本题用 >= 配合 leftedge/rightedge 的严格小于定义，能保证每个 i 的极大区间正确，且不会漏解。
- 左边界栈中先压入 0 作为哨兵，num[0] 默认为 0，可简化边界处理。

可优化点：
- 可以只做一次从左到右的单调栈，在弹出时直接计算右边界并更新答案，减少一次遍历和数组。

同类题：LeetCode 84 柱状图中最大的矩形、P1901 发射站等单调栈求极大区间问题。
