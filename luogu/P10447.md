## 题目简述

给定一张 $n$ 个点的带权无向图，点从 $0 \sim n-1$ 标号，求起点 $0$ 到终点 $n-1$ 的最短 Hamilton 路径。

Hamilton 路径的定义是从 $0$ 到 $n-1$ 不重不漏地经过每个点恰好一次。

输入格式
第一行输入整数 $n$。

接下来 $n$ 行每行 $n$ 个整数，其中第 $i$ 行第 $j$ 个整数表示点 $i-1$ 到 $j-1$ 的距离（记为 $a[i-1,j-1]$）。

对于任意的 $x,y,z$，数据保证 $a[x,x]=0，a[x,y]=a[y,x]$ 并且 $a[x,y]+a[y,z] \ge a[x,z]$。

输出格式
输出一个整数，表示最短 Hamilton 路径的长度。

说明/提示
对于所有测试数据满足 $1 \le n \le 20$，$0 \le a[i,j] \le 10^7$

## 解题思路

这是经典的状压 DP（TSP 问题）。

- **状态定义**：`dp[state][u]` 表示已经访问过的点集为 `state`（二进制位表示），且当前停留在点 `u` 时的最短路径长度。
- **初始化**：`dp[1][0] = 0`，即只访问了起点 0 且停在 0 的代价为 0；其余状态初始化为 INF。
- **转移**：按 `state` 从小到大枚举（保证子集先被计算）。对每个 `state` 中出现的点 `u`，令 `pre = state ^ (1<<u)` 表示到达 `u` 之前访问的点集。枚举 `pre` 中的点 `v`，用 `dp[pre][v] + dist[v][u]` 更新 `dp[state][u]`。
- **正确性**：Hamilton 路径的最后一个点 `u` 之前必然经过 `pre` 中的全部点并停在某个 `v`，枚举所有可能的 `v` 取最小即为最优子结构；按集合大小递增计算保证无后效性。
- **答案**：`dp[(1<<n)-1][n-1]`，即访问全部点且停在终点 n-1 的最短长度。

注意代码中 `pre == 0` 时跳过（只有 `state` 仅含起点 0 的情况），此时 `dp[1][0]` 已单独初始化。

## 复杂度分析

- 时间复杂度：O(2^n · n^2)
- 空间复杂度：O(2^n · n)

## 代码

```cpp
#include<bits/stdc++.h>
using namespace std;
const int N=20;
const int INF =0x3f3f3f3f;//超大整数
int n;
int dist[N][N];
int dp[1<<N][N];//dp[状态][当前点]

int main(){
    cin>>n;
    for(int i=0;i<n;i++){
        for(int j=0;j<n;j++){
            cin>>dist[i][j];
        }
    }
    memset(dp,0x3f,sizeof(dp));
    dp[1][0]=0;
    for(int state=1;state<(1<<n);state++){
        for(int u=0;u<n;u++){
            if(!(state&(1<<u))) continue;
            int pre=state^(1<<u);
            if(pre==0)continue;
            for(int v=0;v<n;v++){
                if(pre&(1<<v)){
                    dp[state][u]=min(dp[state][u],dp[pre][v]+dist[u][v]);
                }
                
            }
        }
    }
    cout<<dp[(1<<n)-1][n-1]<<endl;
    return 0;
}
```

## 复盘备注

易错点：
- `dp` 数组大小需为 `1<<n` 行、`n` 列，n=20 时约 2×10^7 个 int，注意内存（约 80MB，需确认题目内存限制）。
- INF 用 `0x3f3f3f3f` 时，累加边权最大约 20×10^7=2×10^8，不会溢出 int，但若用更大 INF 需注意加法溢出。
- 必须按 `state` 递增枚举，保证 `pre < state` 已被计算。
- 起点固定为 0、终点固定为 n-1，不能直接套用任意起点的 TSP 模板。

可优化点：
- 可只枚举 `state` 中含 `u` 的位，用 `lowbit` 或预存合法状态减少常数。
- 若内存紧张，可滚动或只保留必要状态，但本题 n≤20 通常直接开数组即可。
