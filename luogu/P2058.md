## 题目简述

NOIP2016 普及组 T3

小 K 是一个海港的海关工作人员，每天都有许多船只到达海港，船上通常有很多来自不同国家的乘客。

小 K 对这些到达海港的船只非常感兴趣，他按照时间记录下了到达海港的每一艘船只情况；对于第 $i$ 艘到达的船，他记录了这艘船到达的时间 $t_i$ (单位：秒)，船上的乘客数 $k_i$，以及每名乘客的国籍 $x_{i,1}, x_{i,2},\dots,x_{i,k_i}$。

小 K 统计了 $n$ 艘船的信息，希望你帮忙计算出以每一艘船到达时间为止的 $24$ 小时（$86400$ 秒）内所有乘船到达的乘客来自多少个不同的国家。

形式化地讲，你需要计算 $n$ 条信息。对于输出的第 $i$ 条信息，你需要统计满足 $t_i-86400<t_p \le t_i$ 的船只 $p$，在所有的 $x_{p,j}$ 中，总共有多少个不同的数。

输入格式
第一行输入一个正整数 $n$，表示小 K 统计了 $n$ 艘船的信息。

接下来 $n$ 行，每行描述一艘船的信息：前两个整数 $t_i$ 和 $k_i$ 分别表示这艘船到达海港的时间和船上的乘客数量，接下来 $k_i$ 个整数 $x_{i,j}$ 表示船上乘客的国籍。

保证输入的 $t_i$ 是递增的，单位是秒；表示从小 K 第一次上班开始计时，这艘船在第 $t_i$ 秒到达海港。

输出格式
输出 $n$ 行，第 $i$ 行输出一个整数表示第 $i$ 艘船到达后的统计信息。

## 解题思路

1. 使用队列维护当前 24 小时窗口内的所有乘客记录，每条记录为 (到达时间, 国籍)。
2. 用数组 cnt[x] 记录国籍 x 在当前窗口内出现的次数，ans 维护当前窗口内不同国籍的数量。
3. 处理第 i 艘船时：先将该船所有乘客依次入队，若 cnt[x] 从 0 变为 1，则 ans 加一，然后 cnt[x] 加一。
4. 入队后，检查队首：若队首乘客的到达时间 ≤ t_i - 86400，说明其已超出 24 小时窗口，将其出队，cnt[x] 减一；若 cnt[x] 减为 0，则 ans 减一。重复直到队首时间满足条件。
5. 输出 ans 即为当前船到达后的答案。
正确性要点：队列按时间递增，出队操作保证窗口内恰好是满足 t_i-86400 < t_p ≤ t_i 的乘客；cnt 与 ans 同步维护，因此 ans 始终等于窗口内不同国籍数。

## 复杂度分析

- 时间复杂度：O(n + ∑k_i)，每个乘客最多入队、出队各一次
- 空间复杂度：O(∑k_i + max(x))，队列最多存储窗口内所有乘客，cnt 数组大小为国籍最大值

## 代码

```text
#include<bits/stdc++.h>
using namespace std;
typedef long long ll;
const int MAX=100010;
int cnt[MAX]={0};
queue<pair<int,int>> q;
int main(){
    int n;
    cin>>n;
    int ans=0;
    while(n--){
        int t,k;
        cin>>t>>k;
        for(int i=1;i<=k;i++){
            int x;
            cin>>x;
            q.push({t,x});
            if(cnt[x]==0) ans++;
            cnt[x]++;
        }
        while(!q.empty()&&q.front().first<=t-86400){
            int x=q.front().second;
            cnt[x]--;
            if(cnt[x]==0) ans--;
            q.pop();
        }
         cout<<ans<<endl;
    }
   
    return 0;

}
```

## 复盘备注

易错点：
- 时间窗口是严格大于 t_i-86400，因此出队条件为 q.front().first <= t-86400。
- 国籍编号可能较大，但不超过 10^5，数组大小需开够；若编号范围更大可改用哈希表。
- 使用 long long 存储时间并非必须，但 t_i 可达 10^9，用 int 也足够（t_i-86400 不会溢出）。
- 队列中存储的是每个乘客，总元素数 ∑k_i ≤ 3×10^5，不会超内存。
可优化点：无需优化，已是最优线性做法。
同类题提示：滑动窗口 + 计数数组维护不同元素个数，如“区间内不同整数个数”类问题。
